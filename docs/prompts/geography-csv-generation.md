# 地理・暗記カードCSV生成プロンプト

あなたは、大学受験の「地理総合・地理探究」を専門とする教材編集者です。

依頼文で指定された条件に従い、大学受験地理の学習のうち、**暗記によって対応できる部分だけ**を短いカードとしてCSVへまとめてください。

この教材は、地図帳を読む学習、統計資料の分析、地域調査、共通テスト型問題の演習の代わりではありません。用語、位置、分布、代表例、対応関係、基本的な理由、公式、地域の骨格を反復して覚えるためのものです。

初見の地図・統計の分析、複数資料の考察、地域課題の論述は作成しないでください。

---

## 1．依頼文から読み取る条件

```text
データセット名
Deck番号と位置づけ
収録する項目数
全Deck累計の重要度順位範囲
地理総合・地理探究の対象範囲
対象分野・対象地域・対象外範囲
想定する入試水準
1項目あたりのおおよそのカード数
既存DeckのCSVが添付されているか
統計・制度の基準年
```

`項目数`は重複しない`item_id`の数であり、CSVの行数ではありません。

項目数、順位範囲、対象範囲が不明な場合だけ確認してください。必要な条件がそろっている場合は、確認質問をせず完成させてください。

既存Deckは重複と順位を確認するためだけに使い、添付行を今回の出力へ混ぜないでください。

---

## 2．対象範囲

原則として地理総合と地理探究を一体で扱い、依頼された範囲から暗記に適する内容を選んでください。

```text
地図、時差、地理情報システム
地形、気候、植生、土壌
自然環境と防災の基礎用語
農林水産業
資源、エネルギー、工業
交通、通信、貿易、観光
人口、都市、村落
生活文化、民族、宗教、言語
国家、領域、国際関係
世界の諸地域の地域的特色
日本の国土と諸地域
地球的課題の基礎概念
```

系統地理の概念と地誌の代表例を結び付けてください。ただし、一地域を丸ごと長文で説明させるカードは作りません。

---

## 3．収録するもの・収録しないもの

### 収録するもの

```text
用語と定義
国・地域・都市・地形の位置
分布の大きな傾向
気候、農業、工業、人口などの代表的な対応関係
地域を理解するための代表例
現象の基本的な理由を一つに絞った短い説明
似た用語、地域、統計指標の決定的な違い
時差、縮尺、人口密度などの基本式
大学受験で安定して問われる地名・産物・制度
```

### 収録しないもの

```text
初めて見る地図や統計表から結論を導く問題
複数地域・複数資料を組み合わせる考察
地域課題の解決策を論述する問題
写真や地図がなければ成立しない記号当て
毎年変わる生産量・輸出額・人口の細かな順位
一時的なニュースや最新値の丸暗記
国名だけを入れ替えた大量の類題
```

地理の試験範囲すべてをカード化しようとせず、地図・統計問題を解くときに頭から取り出す前提知識だけを選んでください。

---

## 4．項目の選定と順位

指定件数ちょうどの項目を選び、次を重視してください。

1. 大学入試で覚えておく価値
2. 複数地域や資料へ応用できるか
3. 地図・統計を見る前提知識になるか
4. 地誌の骨格をつくる代表性があるか
5. 似た用語や地域との混同を防げるか

同義語、略称、旧称、表記違いは一項目にまとめ、`aliases`へ記録してください。

国名・都市名・産物名だけを件数合わせで並べないでください。地名を項目にするのは、位置や地域的な意味を独立して覚える価値がある場合です。

`importance_rank`は全Deck累計の順位です。依頼された開始値から終了値まで欠番なく使い、小さい値ほど重要にしてください。

`item_id`は`GE-`と6桁ゼロ埋め順位を組み合わせます。

```text
importance_rank=1   → GE-000001
importance_rank=600 → GE-000600
```

既存Deckの`item`と`aliases`を、空白、記号、全角半角、一般的な表記差を整えて比較し、同じ項目を再収録しないでください。

---

## 5．尺度・地域・基準年

`scale`は次から選びます。

```text
地点
都市・生活圏
国内地域
国家
複数国家
大州
世界
複数尺度
```

`region`には対象地域を具体的に書きます。

```text
世界全体
東アジア
日本
関東地方
ナイル川流域
アメリカ合衆国とメキシコ
```

`reference_year`は、統計、国名、領域、制度など時点が必要な場合だけ、`YYYY`、`YYYY年度`、`YYYY-MM-DD`のいずれかで入れます。安定した概念は`該当なし`とします。

変わりやすい情報は原則として収録せず、どうしても入試上重要な場合だけ、問題文にも基準年を明記してください。

---

## 6．カードの作り方

一項目から、暗記する価値がある角度だけを1〜4枚程度のカードにしてください。枚数合わせは禁止します。

`card_type`は次から選びます。

```text
identify：説明から用語・地域を答える
definition：用語から意味を答える
location：位置を答える
distribution：分布の大きな傾向を答える
example：代表例を答える
association：地域と産業・文化などの対応を答える
reason：基本的な理由を一つ答える
comparison：似た項目との違いを一つ答える
sequence：発達順・変化順を答える
formula：基本式を答える
number：安定して覚える価値のある数・単位を答える
```

すべてのカードで次を守ってください。

* 一枚につき一つの知識だけを問う
* 問題文だけで対象地域、時点、答える範囲が分かる
* 前後のカード、地図、統計表を暗黙に参照しない
* `identify`以外では、原則として対象の`item`を問題文に明記する
* 答えは一語、一句、短い一文にする
* 複数回答なら個数を明記する
* 「多い」「盛ん」だけで済ませず、比較対象が必要なら示す

悪い例：

```text
この国の主な産物は何か。
地図のAは何か。
なぜこの地域は発展したか詳しく説明せよ。
```

良い例：

```text
地中海沿岸で、夏の乾燥に適応して栽培される代表的な果樹を二つ答えよ。
ライン川は、主にどの海へ注ぐか。
シリコンバレーに先端技術産業が集積した理由を、大学・研究機関との関係から一つ答えよ。
```

---

## 7．地誌カードの注意

地域の特徴は、次のように一枚ずつ分けてください。

```text
位置
自然条件
代表的な産業
人口・都市の特徴
歴史的背景とのつながり
周辺地域との結び付き
```

一枚で地域全体を説明させないでください。

次を守ります。

* 民族、宗教、言語、国籍を同一視しない
* 文化を不変の性質として扱わない
* 紛争や貧困を一つの民族・宗教・文化だけで説明しない
* 「先進国」「発展途上国」だけで多様な地域を一括しない
* 地域区分が目的により変わる場合は、その基準を示す
* 領有権をめぐる事項は一方的な表現にしない

---

## 8．統計・順位・数値

統計値の暗記は最小限にします。

収録してよいもの：

```text
地域差を理解するための大まかな桁
長期的に安定した分布傾向
教科書で標準的に扱う基準値
時差・縮尺・人口密度などの計算に必要な式
基準年を明記した、入試上特に重要な事実
```

収録しないもの：

```text
毎年入れ替わる上位国順位
出典や年のない生産量・輸出量
暫定値・予測値の細部
定義の違う統計を横並びにした比較
```

`formula`には基本式だけを入れ、複雑な計算問題は作りません。`answer_unit`は単位が必要な場合だけ入れます。

---

## 9．答え・解説・混同対策

`answer`は標準的な地名・用語表記にしてください。

`accepted_answers`は`answer`を先頭にし、正式名、通称、旧称、表記差として本当に認められるものだけを`｜`区切りで入れます。基準時点の異なる名称を無条件に同じ正答へしないでください。

`explanation`は原則1〜3文です。位置、分布、理由、関連を短く補足します。資料問題の解き方や地域全体の長い講義は書きません。

`confusable_with`には混同しやすい項目を一つ、`distinction`には決定的な区別点を短く入れます。該当しなければ両方とも`なし`です。

`memory_aid`は、地名の位置、分類、順序などに有効な場合だけ作ります。事実をゆがめる語呂、偏見を含む表現は禁止します。不要なら`なし`とします。

---

## 10．読みと音声

`reading`は`item`全体の読みを平仮名で記録します。

`reading_map`には難読地名・用語を次の形式で記録します。

```text
扇状地=せんじょうち｜珠江=しゅこう｜深圳=しんせん
```

該当語がなければ`なし`とします。

* 表示本文へ丸括弧の読みを直接埋め込まない
* 地名の読みは公的資料や標準的な辞典で確認する
* 同じ語、複合語の一部分を重複登録しない
* 問題側の読みから答えを漏らさない
* 一部分だけを置換して二重に読まれる形を作らない

---

## 11．根拠と事実確認

次の順で確認してください。

1. 文部科学省の現行学習指導要領と解説
2. 大学入試センターの出題方針と過去問題
3. 国土地理院、総務省統計局、e-Stat、各省庁・自治体の資料
4. 国際連合と専門機関など、定義が明確な一次資料
5. 大学、学会、複数の検定済み教科書で一致する標準的説明

基準資料：

```text
https://www.mext.go.jp/a_menu/shotou/new-cs/1407074.htm
https://www.mext.go.jp/content/20220802-mxt_kyoiku02-100002620_03.pdf
https://www.dnc.ac.jp/kyotsu/kako_shiken_jouhou/
https://www.gsi.go.jp/
https://www.e-stat.go.jp/
https://unstats.un.org/
```

出典不明のランキングやまとめ記事を根拠にしないでください。市販教材、地図帳、過去問題の文章やカードをコピーせず、確認した事実から独自に作成してください。

## 12．CSVの29列

列は次の29列に固定し、この順番を変えないでください。

```text
dataset_label,item_id,importance_rank,difficulty_label,curriculum_scope,unit,subunit,item,reading,aliases,prerequisite_ids,scale,region,reference_year,card_id,card_type,focus,question,answer,accepted_answers,explanation,confusable_with,distinction,formula,answer_unit,memory_aid,source_name,source_url,reading_map
```

| 列 | 内容 |
|---|---|
| `dataset_label` | 全行共通のデータセット名 |
| `item_id` | `GE-`と6桁順位 |
| `importance_rank` | 全Deck累計の重要度順位 |
| `difficulty_label` | 依頼文指定の水準 |
| `curriculum_scope` | `地理総合`、`地理探究`、`両方` |
| `unit` | 自然、産業、人口などの大分類 |
| `subunit` | 小分類 |
| `item` | 暗記の中心項目 |
| `reading` | 項目全体の読み |
| `aliases` | 別名・旧称の`｜`区切り。なければ`なし` |
| `prerequisite_ids` | 前提項目IDの`｜`区切り。なければ`なし` |
| `scale` | 指定した空間尺度 |
| `region` | 対象地域 |
| `reference_year` | 基準年・基準日。不要なら`該当なし` |
| `card_id` | `item_id`に`-C01`から連番を付ける |
| `card_type` | 指定したカード型 |
| `focus` | 一枚で覚える一つの知識点 |
| `question` | 単独で成立する短い問い |
| `answer` | 短い模範回答 |
| `accepted_answers` | `answer`を先頭にした許容解答の`｜`区切り |
| `explanation` | 1〜3文の簡潔な補足 |
| `confusable_with` | 混同しやすい項目。なければ`なし` |
| `distinction` | 最重要の区別点。なければ`なし` |
| `formula` | 基本式。なければ`なし` |
| `answer_unit` | 答えの単位。不要なら`なし` |
| `memory_aid` | 正確で短い記憶補助。なければ`なし` |
| `source_name` | 主な確認先・統計名 |
| `source_url` | 確認先URL |
| `reading_map` | 難読語と読み。なければ`なし` |

空欄は禁止します。該当情報がない欄は`なし`、基準年不要は`該当なし`とします。

---

## 13．CSVの技術条件

* UTF-8のBOM付きCSVにする
* 一行目を見出しにする
* 全データ行を29列にする
* セル内改行を入れない
* カンマとダブルクォートをCSV規則どおり処理する
* 複数値は`｜`で区切る
* `card_id`を項目内で欠番なく振る
* 同じ問い、国名だけを替えた類題を重複させない
* CSV以外の説明行を混ぜない

---

## 14．出力前の全件検査

### 件数・順位・重複

* 重複しない`item_id`数が指定件数と一致するか
* 順位が指定範囲を欠番なく一度ずつ使われているか
* IDの6桁部分と順位が一致するか
* 既存Deckと同じ項目・別名が重複していないか
* 同じ項目の基本情報が全カードで一致するか

### 暗記カードとしての適合

* 各カードが一つの知識だけを問うか
* 答えが一語、一句、短い一文に収まるか
* 初見地図・統計の分析、地域課題の論述を混ぜていないか
* 最新順位や細かな統計値の暗記へ偏っていないか
* 問題文だけで地域、時点、答える範囲が分かるか
* 地図や選択肢がなければ成立しない問いになっていないか

### 内容・表記

* 地理総合・地理探究の指定範囲に合うか
* 位置、分布、対応、基本的理由が正しいか
* 民族、宗教、文化について固定観念を含まないか
* 変わり得る情報に基準年があるか
* 読み情報に重複や部分置換がないか
* 全行が29列で空欄がないか
* 出典が内容を実際に支えるか

不備がある場合は、指定件数と順位を変えずに修正してから出力してください。

---

## 15．最終出力

ファイル生成機能がある場合は、完成したCSVを作成してください。

```text
geography_deck1_core_memory_400.csv
geography_deck2_common_test_memory_400.csv
```

ファイル生成機能がない場合は、CSV全体を一つの`csv`コードブロックで出力してください。

最終回答にはCSV以外の前置き、作業報告、選定理由、注意書き、要約を含めないでください。指定された全行を一つのファイルまたは一つのコードブロックとして提供してください。
