## 取り込み方

- ファイル名は `第01回_01_古代オリエント世界の特徴_3語.csv` の形式。回番号・パート番号・見出しを目次と照合し、末尾の用語数と実際の用語数も確認する。
- CSVの所属欄は従来の `世界史探究_第1章_第01回_01_…` と第3章の `第3章 古代の東アジア｜第8回 …｜1 …` 、第4章の `第4章 中世ヨーロッパ｜第11回 1 …` の形式を受け付け、章・回・パート番号を目次と照合する。
- 既存の25列形式を読み込み、全行を独立した一問一答として扱う。通常問題・逆向きの問題・統合説明問題を、他の問題の習熟を待たずに選択できる。
- 問題文・回答・太字指定・問題の種類・別解・補足・語呂・出典は維持する。元の用語・読み・時期・地域・分類も保持する。
- 一問ごとに世界史SO専用の番号を付け、章・回・パート・元の問題番号で区別する。他科目や別のファイルに同じ `WH-000001-B01` があっても学習履歴を混同しない。元の用語番号・問題番号・出題段階は出典情報に残す。
- 内部の保存単位は `book-01-01-01` のようなパート番号。画面上は「第1章 オリエント・インドの古代文明」一つのデッキにまとめる。
- 第6章の既存のパート番号・問題番号・履歴版・画像は維持する。地図がない別章の問題に、イスラーム史の地図や地図の読込エラーを表示しない。
- 複数章や全パートの組合せでも途中経過を保存できるよう、従来形式が100文字を超える組合せだけ固定長の識別子を使う。従来の100文字以内の保存名と第6章の保存先は維持する。

## 今後の追加手順

1. 利用者から指定された新しいCSVを確認し、`data/source/world-history-so/book/` へ保存する。目次が更新された場合は、目次の写しも指定された原本に合わせる。
2. `npm run preview:book:world-history-so` を実行する。Cloudflare上の現行索引・既存全パートを読み、新規分の件数と構成を `.wrangler/so-book/report.json` と `plan.json` へ出力する。
3. `npm run check` と `npm run test:so-book:browser` で確認する。ブラウザー試験は自動読み上げをOFFにし、音声を再生しない。
4. 画面の変更が必要な場合は先に公開し、新しい章の情報を扱える状態にする。
5. `npm run publish:book:world-history-so` で登録する。新しい分割データとパート索引をCloudflareへ先に登録・全文照合し、取得時の全体索引の版を条件として科目一覧を更新する。既存の全パートの索引・本文も再照合する。

登録先はR2 `anki-world-history` の `subjects/world-history-so/imports/`。登録前の全体索引をR2の `imports/history/` へ保存し、作業用の認証付き保存窓口は終了時に削除する。D1の学習記録、他科目、既存画像・音声には書き込まない。本番のデータ読み書きはすべてCloudflareを通す。

同じ資料を再実行した場合は、登録済みの本文と一致することを確認して何も追加しない。既存パートと番号が同じで本文が異なる場合は、登録後の編集を上書きしないよう中止する。この処理は新規パートの追加専用であり、既存問題の改訂はアプリの問題編集画面など別の手順で行う。

`npm run build:data` による手元の確認用データ生成にも追加分を含める。ただし本番への章追加には上記の専用処理を使い、手元の索引でCloudflare上の編集内容を置き換えない。
