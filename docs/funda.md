# ファンダ

v0.272で新しい科目「ファンダ」を追加。収録内容は次の1問のみ。

- 問題：FOMC（連邦公開市場委員会）は、どのくらいの頻度で開催されるか。
- 回答：原則年8回、約1か月半に1回。

## 保存と登録

科目の識別名は `funda`、問題番号は `FUNDA-0001-B01`、履歴版は `funda-v1`。
Cloudflare R2の `anki-world-history` 内の全体索引と `subjects/funda/imports/` 配下から読み込む。
科目選択、学習、設定は既存の共通画面を使用する。ローカルの問題集は本番の読み書きに使わない。

確認は `node scripts/publish-funda.mjs`、登録は `node scripts/publish-funda.mjs --apply` で行う。
登録処理は利用者指定の1問を作成し、Cloudflareの現行索引に新科目のみを追加する。
既存12科目とその問題・履歴版を維持し、問題データの登録・照合後に索引を条件付き更新する。
同時編集や登録後の変更を検出すると上書きせず中断する。再実行時に登録内容が完全一致する場合は何も変更しない。
作業用の認証付き保存窓口は処理終了時に削除する。
