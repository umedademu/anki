# 逆一問一答学習アプリ 仕様書

## 概要

このアプリは、最初に用語を示し、その用語に関する複数の質問を順番に確認する「逆一問一答」形式の学習アプリです。
個別の知識を思い出したあとに統合説明を読むことで、用語に対する理解と記憶を深めることを目的とします。

## 提供形態

- パソコンやスマートフォンのブラウザで利用するWebアプリ
- Vercel上での公開を想定
- 学習内容はCloudflare R2から読み込む構成を想定

## 現在の実装

- 「大学受験・最重要」の世界史100用語・333問を学習できる画面
- 回答前の手掛かりを避けるため、問題画面には用語のみを表示
- 用語ごとに複数の質問を順番に表示
- 「答えを見る」を押すまで答えを隠す
- 全質問の終了後に統合用の問い、統合説明、重要語句を表示
- 回答と統合説明に含まれる重要語を太字で表示
- 次の用語へ進み、50用語ごとに次の分割データを読み込む
- パソコンとスマートフォンの画面幅に対応

## 学習の流れ

1. 学習する用語を表示する
2. その用語に関する質問を1つ表示する
3. 利用者が考えたあと、「答えを見る」で答えを表示する
4. 次の質問へ進み、登録されている質問がなくなるまで繰り返す
5. 全質問の終了後、個別の知識をつないだ統合説明を表示する
6. 次の用語へ進む

質問数は3問などの固定値にしません。CSVに`q1_question`、`q2_question`のように連番で用意された質問を、存在する分だけすべて表示します。用語ごとに質問数が異なる場合にも対応します。

## 出題順

- 通常モードでは、元データに登録された順番で用語を表示する
- シャッフルモードでは、分割データの順番と分割内の用語順をそれぞれ入れ替える
- シャッフルの切替時は用語1件目から新しい学習を開始する
- 質問は理解の流れを崩さないよう、シャッフル中も登録順で表示する
- 質問の登録順は用語ごとに決め、時期質問を必ず1問目にする固定規則は設けない
- 前の質問文や表示済みの回答が後続質問の核心を先に教える場合は、質問順または質問文を調整する
- 全データを一度に読み込まず、分割単位で読み込む方式を維持する

## 画面配置

- スマートフォンの横向き表示では、用語を上、質問・回答を下に並べる
- 高さに余裕のある大画面の横向き表示では、用語と質問・回答の左右配置を使用する
- 縦向き表示では、用語、質問・回答の順に上下へ並べる
- 用語名は問題文と同じ文字サイズにし、どちらか一方だけが強くならないようにする
- 質問と回答は、考える内容と解説を読みやすい文字サイズにする
- 横向きで高さが小さい端末では、余白やボタンの高さを縮めて画面内の情報量を確保する
- 横向きスマートフォンではサイト見出しを省略し、進捗・シャッフル・用語・質問・回答を1画面内へ圧縮する
- 横向き時は用語名の右側に「用語数・シャッフル状態・質問数」を一行でまとめる
- 横向き時はページ自体をスクロールさせず、回答まで画面内に表示する
- 回答と統合説明は文字量に応じて文字サイズと行間を段階的に縮小する
- それでも内容がカード高を超える場合は、実際の表示高を測って収まるまで本文を追加縮小する
- 横向き時の重要語句は統合説明本文と重複するため、タグ表示を省略する
- 横向き時は左右の操作ボタンを表示せず、画面の左半分を押すと一手戻り、右半分を押すと一手進む
- シャッフルボタンなどの操作部品を押した場合は、左右半分の進む・戻る操作を発動させない
- 縦向きでは画面左端の戻る矢印と右端の進む矢印を同じ位置へ固定し、ボタン名は画面に表示しない
- 進む操作は、現在の状態に応じて「答えを見る」「次の質問へ」「統合説明へ」「次の用語へ」を実行する
- 戻る操作は単純な一手戻しとし、回答表示中は同じ質問の回答を隠し、質問切り替え直後は前の質問の回答表示へ戻る
- 統合説明から戻った場合は、最後の質問を回答表示済みの状態で開く
- 縦向きの1問目でも戻る矢印の位置は変えず、操作できない状態で表示する
- 縦向きの両矢印には読み上げ機能向けの操作名を設定する

## 学習データ

### 元データ

- 保存場所：`data/source/world-history/world_history_university_essential_100.csv`
- 現在の件数：100用語、333問
- データセット名：大学受験・最重要
- 1行を1用語として扱う
- 元CSVの列構成は`docs/prompts/world-history-csv-generation.md`に定める形式を使用する
- 世界史の元データ置き場には、現在使用するCSVを1ファイルだけ配置する
- 読み、別名、難易度、カテゴリ、年代、地域、関連語、出典、確認状態を保持する
- 年代・地域などは回答前の問題画面には表示せず、答えの手掛かりになることを防ぐ
- `q番号_question`、`q番号_answer`、`q番号_type`、`q番号_keywords`を1組の質問として扱う
- `question_count`と実際に入力された質問数が一致しない場合は生成を中止する
- `q番号_type`は「時期」「場所」「要点」「原因」などの日本語へ変換して表示する
- `integrated_question`と`total_explanation`を統合部分に使用する
- 回答と統合説明の`**重要語**`は、安全に太字要素へ変換して表示する
- `total_keywords`は半角パイプで分割し、統合説明の重要語句として表示する

### Web表示用データ

- `npm run build:data`でCSVからJSONを生成する
- 科目一覧、科目情報、用語データに分ける
- 公開用データ形式は第2版とし、新CSVの42列を学習用の構造へ変換する
- 用語データは50件ごとに分割し、必要な分だけ読み込む
- 元CSVと生成後の全用語・全質問が一致することを自動検証する
- 現在は`public/data`へ生成し、Cloudflare R2への登録前でも動作確認できる
- Cloudflare R2の公開URLを設定したあとは、WebアプリがR2上の同じ構成を直接読み込む
