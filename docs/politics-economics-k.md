## 問題の作り方

利用者の指定したルールは次の３つ。

1. 原文を読んでいれば答えられる内容にする（原文が土台）。
2. 共通テストの政治・経済の対策として価値が高いこと。
3. 全問をマスターすれば共通テストで9割以上が安定すること。

ただし「原文を読んでいないと答えられない」問題にはしない。**共通テスト対策をしっかりした人なら、原文を読んでいなくても答えられる一般的な問題・回答**にする（v0.364で追加）。

- 講義の口調・たとえ話・小ネタ（「大変なことになる」「100％守ってくれる保証がない」「石原都知事の視察」など）は問題にも答えにも使わない。教科書や一般的な一問一答と同じ言い回しで書く。自動検査で講義口調の語を拒否する。
- 問題文は「排他的経済水域とはどんな水域？」「宇宙条約は何を定めた？」のような普通の疑問文にする（世界史SOの「護民官はどんな官職？」と同じ形。「用語」：…？ の形は使わない）。対象の用語を必ず含め、一問だけで意味が通じるようにする。「原文」「上記」など元資料や別の問題に頼る表現は使わない。
- 共通テストで問われる区別（例：領海と排他的経済水域、領空と宇宙空間、大陸棚と深海底、主権の３つの意味と用例）を優先し、全問の習得で原文の重要事項を漏れなく説明できる量にする。原文にしかない細部（北方領土の安全操業枠組み協定など）は出題しない。
- 外部の知識・数値・評価を正答に足さない。回答の重要語（用語・数値）を太字にし、解説に原文の頁と根拠の引用を表示する。
- 小見出しの範囲は本文の見出しで区切る。同じ項目のコラムとチェック問題は、内容が対応する小見出しのパートに含める。1-1では沖ノ鳥島のコラム（22頁）とチェック問題１（23頁）を含めた。
- 細かな数値（1カイリ＝1852mなど）は解説にだけ書き、暗記条件にしない場合がある。各原稿の `source.note` に判断を記録する。

## 原稿と自動検査

原稿は `data/source/politics-economics-k/<項目>-<小見出し>.json`（例：`01-01.json`）。原文全体（`sources/seikei/*.md`）は公開リポジトリへ入れず、日本史Kと同じく小見出しごとの抜粋 `sources/seikei/抜粋/01-01_民主政治と国家・主権_原文抜粋.md` だけを保存する。抜粋は `npm run prepare:excerpts:politics-economics-k` で、原稿の `source.ranges`（見出しで区切った範囲）から頁番号つきで書き出す。原文全体がある端末では、抜粋が原文の範囲と一字一句一致することも検査する。

`scripts/politics-economics-k.mjs` が次を検査してから登録用のデータを作る。

- 根拠の引用が、抜粋の指定した頁に実在する。色・下線・振り仮名・強調の装飾は除いて照合する。同じ頁でも次の小見出しの記述は根拠にできない。
- 全問が `reverse` の段階・種類で、問題文に用語を含み、元資料に依存しない。
- 太字の語と重要語の一覧が一致する。
- 引用した根拠をすべてどれかの問題で使う（根拠の取りこぼしを防ぐ）。

問題番号は `PEK-01-01-U01-R01`（パート・用語・問題）、パートは `pek-01-01`、学習履歴版は `politics-economics-k-pek-01-01-v<revision>`。原稿の `revision`（省略時1）を上げると学習履歴を分ける。

## Cloudflareへの登録

1. `npm run preview:data:politics-economics-k` でCloudflareの現行一覧を読み、追加内容を確認する。
2. `npm run publish:data:politics-economics-k` で新しいパートだけを登録する。初回は科目を新設し、以後は未登録のパートを追加する。他科目・登録済みパート・学習記録は変更しない。登録後に編集されたパートは上書きしない。
3. 問題の登録後、`npm run preview:images:politics-economics-k` → `npm run publish:images:politics-economics-k` で関連画像を登録する。

どちらも作業用の保存窓口を一時的に公開し、確認時の内容から変わっていない場合だけ索引を切り替え、終了後に窓口を削除する。

### 作り直し（置き換え）

試作を作り直すときは、原稿の `revision` を上げてから `--replace` を付ける。

- `npm run preview:data:politics-economics-k -- --replace` → `npm run publish:data:politics-economics-k -- --replace`：確認時の政治経済Kから変わっていない場合だけ、手元の原稿全体で科目を置き換える。他科目は変更しない。旧版のデータはCloudflareに残るが索引からは外れる。
- `npm run preview:images:politics-economics-k -- --replace` → `npm run publish:images:politics-economics-k -- --replace`：共通の画像一覧から政治経済K（`PEK-` で始まる問題）の割り当てだけを外して付け直す。他科目の割り当てと既存の画像は順序ごと保持し、保存窓口でも照合する。
