# 世界史学習アプリ用CSV生成プロンプト【件数・範囲可変版】

あなたは、**大学受験世界史の教材編集者・学習アプリのデータ設計者**です。

このプロンプト単体では、収録する用語数・難易度・対象地域・対象カテゴリを固定しません。

必ず、**このプロンプトより前、または同じメッセージ内に書かれている依頼文**を読み、そこから今回の実行条件を取得してください。

---

## 1．最初に外側の依頼文から読み取る変数

CSVを作成する前に、以下を内部的に確定してください。

```text
requested_count
selection_scope
difficulty_scope
category_scope
region_scope
era_scope
dataset_label
```

### requested_count

依頼文で指定された収録件数です。

例：

```text
世界史の大学受験で特に重要な○語
基礎レベルの○語
人物に絞って○語
中国史から○語
```

依頼文に書かれた件数を、そのまま使用してください。

**このプロンプト内で件数を固定してはいけません。**

指定件数を勝手に増減したり、別の件数へ変更したりしないでください。

### selection_scope

どのような基準で用語を選ぶかを、依頼文から判断してください。

例：

* 世界史で特に重要な用語
* 歴史の骨格となる用語
* 基礎レベル
* 標準頻出レベル
* 難関大学レベル
* 最難関大学レベル
* マニアックレベル
* 特定大学の入試に重要な用語
* 特定地域・時代・カテゴリの用語

### difficulty_scope

依頼文で指定された難易度を使用してください。

明示されていない場合は、依頼文全体から最も自然な難易度ラベルを付けてください。

例：

```text
大学受験・最重要
歴史の骨格
基礎
標準頻出
難関大
最難関大
マニアック
```

### category_scope

人物、国家・王朝、戦争などのカテゴリ指定がある場合は、それに従ってください。

指定がない場合は、重要度を優先しつつ、必要なカテゴリを幅広く選んでください。

### region_scope

中国史、イスラーム史、ヨーロッパ史など、地域指定がある場合は、それに従ってください。

指定がない場合は、件数の許す範囲で世界の主要地域を幅広く含めてください。

### era_scope

古代、近代、戦後など、時代指定がある場合は、それに従ってください。

指定がない場合は、先史・古代から現代までの歴史的な重要度を考慮してください。

### dataset_label

今回のデータセットを表す短い名称を、依頼文から作成してください。

例：

```text
大学受験・最重要
世界史・歴史の骨格
中国史・基礎
人物・難関大
近代ヨーロッパ・頻出
```

## 2．用語選定の基本原則

外側の依頼文で指定された条件に従い、指定件数ちょうどの用語を選んでください。

「大学受験で重要」「歴史の骨格」などの指定がある場合は、以下を総合して選定してください。

1. 世界史の大きな流れを説明するうえで重要か
2. 他の重要用語とのつながりが多いか
3. 大学入試で扱われる可能性が高いか
4. 原因・結果・時代・地域を理解する中心用語か
5. その用語を知らないと通史理解に大きな穴が開くか
6. 人物名や事件名を単独で知るだけでなく、他の出来事へ接続できるか
7. 大学受験世界史として優先して説明できるようになる価値があるか

件数が少ない場合は、カテゴリや地域を無理に均等配分せず、重要度を優先してください。

件数が多い場合は、地域・時代・カテゴリの偏りを抑えてください。

同じ内容を表す重複用語や、単なる表記違いを別用語として水増ししないでください。

## 3．用語カテゴリ

各用語には、以下から最も適切なカテゴリを1つ設定してください。

```text
人物
国家・王朝
地域・都市
事件・革命
戦争
条約・会議
制度・政策・法律
思想・主義
宗教・宗派
民族・身分・社会集団
組織・政党
文化・技術・学問
経済・交易
文書・作品
時代・歴史区分
運動
```

外側の依頼文でカテゴリが指定されている場合は、そのカテゴリを優先してください。

カテゴリごとの件数を無理に均等にしないでください。

---

## 4．この教材の最重要目的

このCSVは、通常の一問一答のように、

> 説明文を見て、対応する用語名を当てる

ための教材ではありません。

用語名を見た学習者が、

* いつの話か
* どこの話か
* 何をした人物・国家なのか
* 何が起きた事件なのか
* どんな制度・政策・思想なのか
* 何が原因だったのか
* 何につながったのか
* どの重要用語と結び付くのか

を自分の頭から引き出し、最終的に**その用語を自分の言葉で説明できるようになること**が目的です。

したがって、固定された質問文と固定された単語だけを反射的に覚えさせる設計にしないでください。

---

## 5．質問数

各用語について、**1〜4問**の重要質問を作成してください。

4問作ること自体を目的にしてはいけません。

* 1問で十分なら1問
* 2問で十分なら2問
* 3問必要なら3問
* 本当に必要な場合だけ4問

としてください。

標準は2〜3問程度ですが、機械的にそろえないでください。

質問選定の基準は、

> その質問すべてに答えられる人なら、その用語についてほぼ説明できるか

です。

単なる雑学、細かすぎる数字、説明に必須でないプロフィール情報は原則として除外してください。

また、質問数を確保するために、**用語名を見れば歴史知識がなくても答えられる質問**を追加してはいけません。

質問を1問ずつ、次の基準で確認してください。

> この質問は、用語名や一般常識からの推測ではなく、その用語についての世界史知識を思い出すために必要か

答えが用語名に含まれている、自明に推測できる、または答えても用語の理解が深まらない場合は、その質問を削除してください。その結果が1〜2問でも問題ありません。

## 6．時期に関する質問

時期を知ることが用語の理解や前後関係の把握に役立つ場合は、時期を問う質問を入れてください。

ただし、用語名に年・世紀・時代が明記されており、そのまま同じ内容を答えさせるだけになる場合は、時期質問を作らないでください。時期を聞くこと自体を目的にせず、学習上の価値がある場合だけ採用してください。

ただし、単純に、

```text
いつ？
```

とだけ聞くと、人物の場合は出生年なのか活動時期なのか分かりません。

一方、

```text
いつ頃？
```

と聞くと、年号ではなく大まかな時代で答えてよいというヒントになります。

そのため、**何の時期を尋ねているかは分かるが、答えの精度は推測できない質問文**にしてください。

### 推奨例

| カテゴリ         | 時期質問                  |
| ------------ | --------------------- |
| 人物           | 主に活動したのはいつ？           |
| 国家・王朝        | 存在したのはいつ？             |
| 建国時期が特に重要な国家 | 成立したのはいつ？             |
| 地域・都市        | 特に繁栄したのはいつ？           |
| 事件・革命        | 起きたのはいつ？              |
| 戦争           | 戦われたのはいつ？             |
| 条約           | 結ばれたのはいつ？             |
| 会議           | 開かれたのはいつ？             |
| 制度           | 始まったのはいつ？             |
| 政策           | 実施されたのはいつ？            |
| 法律           | 制定されたのはいつ？            |
| 思想・宗教        | 成立したのはいつ？／広がったのはいつ？   |
| 文書・作品        | 発表されたのはいつ？／刊行されたのはいつ？ |
| 運動           | 盛んだったのはいつ？            |

回答の精度は用語ごとに最も適切なものを使用してください。

例：

```text
1789年
前3世紀
16世紀前半
14〜16世紀
前221〜前206年
第二次世界大戦後〜1991年
```

すべてを無理に単年へ変換しないでください。

## 7．場所に関する質問

場所・地域を問う質問は、用語を頭の中の世界地図に配置したり、活動範囲・広がり・複数地域の関係を理解したりする価値がある場合だけ入れてください。

**用語名や一般常識だけで場所を答えられる場合は、場所質問を作らないでください。**

禁止例：

```text
キューバ革命 → どこで起きた？ → キューバ
明治維新 → どこで起きた？ → 日本
```

このような質問は世界史知識を思い出さなくても答えられ、用語への理解も深めないため不要です。

名称から国・地域を推測できても、より具体的な主戦場、活動範囲、伝播経路、関係地域を学ぶことに意味がある場合は、その内容を問って構いません。ただし、細かい地名を無理に作らず、回答が用語の説明に必要な場合に限ってください。

### 推奨例

| カテゴリ  | 場所質問                |
| ----- | ------------------- |
| 人物    | 主にどこで活動した？          |
| 国家・王朝 | どこ？                 |
| 地域・都市 | どこ？                 |
| 事件・革命 | どこ？                 |
| 戦争    | 主な舞台はどこ？            |
| 条約    | どこで結ばれた？／主にどこに関係する？ |
| 会議    | どこで開かれた？            |
| 制度・政策 | どこで行われた？            |
| 思想・主義 | 主にどこで広がった？          |
| 宗教・宗派 | どこで成立した？／どこへ広がった？   |
| 経済・交易 | どこを結んだ？             |
| 運動    | どこ？                 |

特定の場所を答えさせる意味が薄い場合や、答えが自明な場合は省略してください。場所質問を機械的な必須項目として扱ってはいけません。

世界規模の場合は、

```text
ヨーロッパを中心に世界各地
アメリカとソ連を中心とする世界規模
アジア・アフリカの新興独立国
東地中海・西アジア・エジプト
```

など、歴史的に意味のある範囲を答えにしてください。

## 8．質問文の作り方

質問は、学習者が用語の説明を自分で組み立てられるように、**短く、広めで、過度に答えを示さない形**にしてください。

### 自明な質問は禁止

質問に答えるためには、必ずその用語についての歴史知識や歴史的理解が必要でなければなりません。

次のいずれかに当てはまる質問は作成しないでください。

* 用語名、読み、別名の中に答えがそのまま含まれている
* 用語名の文字、数字、国名、地名を読み取るだけで答えられる
* 歴史を知らなくても、日本語の意味や一般常識だけでほぼ確実に答えられる
* 答えても用語の説明に新しい情報が加わらない
* 時期・場所・人数・順番などの欄を埋めるためだけに作られている

禁止例：

```text
キューバ革命 → どこで起きた？ → キューバ
明治維新 → どこで起きた？ → 日本
三国同盟 → 何か国の同盟？ → 3か国
第一次世界大戦 → 何回目の世界大戦？ → 1回目
```

これらは一例です。場所に限らず、**答えが自明かどうかをすべての質問で確認**してください。

自明な質問を除いた結果、規定の上限より質問数が少なくなっても構いません。代わりの質問を無理に追加せず、原因・内容・結果・歴史的意義・他の用語との関係など、本当に理解に必要な観点がある場合だけ採用してください。

### 基本的に推奨する質問

```text
何をした？
何が起きた？
なぜ起きた？
何につながった？
どんな制度？
どんな政策？
どんな法律？
どんな考え？
どんな宗教？
何を決めた？
何が書かれている？
```

### 避ける質問

以下は、質問文自体が答えの方向を教えすぎたり、知識を細かく分断したりするため、原則として避けてください。

```text
何を批判した？
何を主張した？
何を発表した？
国内では何をした？
ヨーロッパに何を広げた？
統一後に何をした？
どのように統一を進めた？
なぜ仏教と結び付く？
誰と誰が戦った？
どの条約で終わった？
何で終わった？
どんな制度が重要？
```

これらの内容は、原則として、より広い質問の回答内にまとめてください。

### 例：ルター

悪い質問：

```text
何を発表した？
何を批判した？
何を主張した？
```

良い質問：

```text
何をした？
```

良い回答：

```text
1517年に**九十五か条の論題**を発表して**贖宥状販売**を批判し、**信仰義認**を重視して**宗教改革**の大きなきっかけを作った。
```

### 例：始皇帝

悪い質問：

```text
中国統一後に何をした？
```

良い質問：

```text
何をした？
```

良い回答：

```text
前221年に**中国を初めて統一**し、**郡県制**を全国に広げ、文字・貨幣・度量衡などを統一した。
```

### 例：ナポレオン

悪い質問：

```text
国内では何をした？
ヨーロッパに何を広げた？
```

良い質問：

```text
何をした？
```

良い回答：

```text
フランス革命後に皇帝となり、**ナポレオン法典**などを整備しながらヨーロッパ各地を征服し、革命後の近代的制度を広げた。
```

### 例：戦争

悪い質問：

```text
誰と誰が戦った？
何で終わった？
```

良い質問：

```text
何が起きた？
```

良い回答：

```text
神聖ローマ帝国内の宗教対立から始まり、デンマーク・スウェーデン・フランスなどが介入する国際戦争へ発展し、**ウェストファリア条約**で終結した。
```

参戦国、重要人物、終結条約は、意味のある説明の中に含めてください。

## 9．広すぎる質問も避ける

質問文を曖昧にしすぎてもいけません。

以下のような質問は、何を答えればよいか分からないため避けてください。

```text
どんな人物だった？
どんな国家だった？
どんな帝国だった？
何が重要？
詳しく説明して
```

人物・国家・王朝・組織については、基本的に、

```text
何をした？
```

を使用してください。

回答内で、成立、重要人物、制度、領域、文化、影響などの核心をまとめてください。

ただし、一つの回答が長くなりすぎる場合は、意味のある論点に分けて構いません。

その場合も最大4問までとしてください。

---

## 10．一問一答化を避ける

時期や場所の回答は、短い年号・地域名で構いません。

それ以外の回答は、原則として単語1つだけで終わらせず、**1〜3文程度の短い説明文**にしてください。

悪い例：

```text
茶法
```

良い例：

```text
イギリスが**東インド会社**に北米植民地への茶の直接販売を認め、茶を安く販売できるようにする一方、茶への税は残した法律。
```

悪い例：

```text
南京条約
```

良い例：

```text
イギリスが清に勝利し、清に**南京条約**を結ばせて、香港割譲や五港開港を認めさせた。
```

回答は模範文を一字一句暗記させるものではありません。

重要なキーワードと因果関係を覚え、自分の言葉で再構成できる文章にしてください。

---

## 11．関連重要語をマインドマップ的に含める

その用語を説明するために重要な関連語は、積極的に回答文へ含めてください。

重要語を細かな一問一答としてバラバラに覚えさせるのではなく、用語同士の関係が分かる形にしてください。

### ルター

```text
九十五か条の論題
→ 贖宥状販売の批判
→ 信仰義認
→ 宗教改革
```

### ボストン茶会事件

```text
茶法
→ 東インド会社の優遇
→ ボストン茶会事件
→ アメリカ独立戦争
```

### 三十年戦争

```text
宗教対立
→ 列強の介入
→ 国際戦争化
→ ウェストファリア条約
```

### ビスマルク

```text
鉄血政策
→ プロイセン中心のドイツ統一
→ ドイツ帝国
→ フランス孤立化を軸とする外交
```

回答内には、用語から自然に連想できるようになるべき重要語を含めてください。

ただし、大学受験上の優先度が低い雑学や、説明に不要な細部を詰め込まないでください。

## 12．重要キーワードの強調

質問への回答と統合説明では、特に重要なキーワードをMarkdown形式の太字で囲んでください。

例：

```text
1517年に**九十五か条の論題**を発表して**贖宥状販売**を批判し、**宗教改革**のきっかけを作った。
```

強調対象は主に以下です。

* 人物名
* 国家・王朝名
* 事件名
* 戦争名
* 条約・会議名
* 制度・政策・法律名
* 文書・作品名
* 思想・宗教上の核心語
* 因果関係をつなぐ重要語

文章の大部分を太字にしないでください。

各回答について、太字にした重要語を別途キーワード列にも記録してください。

キーワード列ではMarkdown記号を使わず、半角パイプで区切ってください。

例：

```text
九十五か条の論題|贖宥状販売|信仰義認|宗教改革
```

## 13．統合説明

各用語について、すべての分解質問への回答を統合した説明文を作成してください。

これは、

```text
「ルター」について説明せよ。
```

のように突然問われた場合の、簡潔な模範回答です。

### 統合説明の条件

1. 分解質問すべてに答えられれば、自力で再構成できる
2. 統合説明だけに新しい重要情報を追加しない
3. 分解質問の回答を自然につなげて作る
4. 時期・地域・核心内容が分かる
5. 必要に応じて原因・結果・影響も分かる
6. 原則として1〜3文程度
7. 重要語を太字にする
8. 模範文の丸暗記ではなく、説明の骨格として使える

統合問題は、答え方を誘導しすぎないようにしてください。

```text
「用語名」について説明せよ。
```

という形式を使用してください。

## 14．質問の基本構成

多くの用語では、以下の構成を基本としてください。

```text
核心となる内容
時期（前後関係の理解に役立ち、答えが自明でない場合）
場所（地理的理解に役立ち、答えが自明でない場合）
必要な場合だけ原因・結果・影響
```

ただし、機械的に4問作らないでください。

### 典型例

人物：

```text
主に活動したのはいつ？
何をした？
必要な場合だけ、主にどこで活動した？
```

国家・王朝：

```text
存在したのはいつ？
何をした？
必要な場合だけ、どこに存在した？
```

事件・革命：

```text
起きたのはいつ？
なぜ起きた？
何が起きた？
必要な場合だけ、主な舞台はどこ？
```

戦争：

```text
戦われたのはいつ？
なぜ起きた？
何が起きた？
必要な場合だけ、主な舞台はどこ？
```

法律：

```text
制定されたのはいつ？
どんな法律？
何につながった？
必要な場合だけ、どこに関係する法律？
```

時期と場所を機械的に追加せず、用語の説明に本当に必要で、歴史知識を使わなければ答えられない質問だけを残してください。

## 15．すべての用語に内部年代データを持たせる

Webアプリ内で、

* 古い順に並べる
* 新しい順に並べる
* 年表上へ配置する
* 同時代の用語を表示する
* 特定時代だけを出題する
* 前後関係を出題する

といった処理ができるように、**すべての用語に内部的な西暦データを必ず設定してください。**

年代が曖昧な思想・宗教・地域・文化・身分などについても空欄にしないでください。

世界史上、その用語が成立・活動・繁栄・普及した主要時期を設定してください。

### 必須年代列

```text
date_basis
display_period
start_year
end_year
sort_year
date_precision
date_note
```

### date_basis

年代データが何を表しているかを書いてください。

例：

```text
主な活動時期
存続期間
成立時期
事件発生時期
戦争期間
締結時期
実施時期
普及時期
繁栄時期
刊行時期
歴史区分
歴史上の主要時期
```

### display_period

学習者に表示する自然な日本語表現です。

例：

```text
前3世紀
前221〜前206年
618〜907年
14〜16世紀
18世紀末〜19世紀初頭
第二次世界大戦後〜1991年
```

時期質問の回答と、原則として一致させてください。

### start_year

開始年を整数で記録してください。

紀元前は負の整数を使用してください。

例：

```text
前221年 → -221
1776年 → 1776
```

### end_year

終了年を整数で記録してください。

単年の事件は、start_yearと同じ値にしてください。

例：

```text
フランス革命開始 → start_year=1789、end_year=1789
アヘン戦争 → start_year=1840、end_year=1842
```

### 世紀の変換

世紀表現の場合は、その世紀の実際の範囲を整数で設定してください。

例：

```text
前3世紀 → start_year=-300、end_year=-201
1世紀 → start_year=1、end_year=100
14世紀 → start_year=1301、end_year=1400
14〜16世紀 → start_year=1301、end_year=1600
```

西暦には0年がないことに注意してください。

### sort_year

古い順に並べるための代表年です。

原則としてstart_yearと同じ値を使用してください。

ただし、人物や長期的思想などで、開始年よりも別の代表年の方が年表上自然な場合は調整して構いません。

### date_precision

以下から選択してください。

```text
exact_year
exact_range
approximate_year
approximate_range
century
historical_period
```

### date_note

年代設定の補足です。

例：

```text
人物の生没年ではなく主な政治活動期を設定
王朝の統一王朝としての存続期間を設定
思想がヨーロッパで特に普及した時期を設定
都市が歴史上特に繁栄した時期を設定
```

人物の場合、生没年ではなく、原則として**大学受験世界史で重要となる主な活動時期**を入力してください。

## 18．CSVの列構成

以下の順番で列を作成してください。

```text
dataset_label
term_id
importance_rank
difficulty_label
category
term
reading
aliases
era
macro_region
region_detail
date_basis
display_period
start_year
end_year
sort_year
date_precision
date_note
question_count
q1_type
q1_question
q1_answer
q1_keywords
q2_type
q2_question
q2_answer
q2_keywords
q3_type
q3_question
q3_answer
q3_keywords
q4_type
q4_question
q4_answer
q4_keywords
integrated_question
total_explanation
total_keywords
relation_edges
source_1
source_2
verification_status
```

### 列の詳細

#### dataset_label

外側の依頼文から作成したデータセット名です。

#### term_id

用語ごとの一意なIDです。

指定件数にかかわらず十分な桁数を持たせてください。

例：

```text
WH-000001
WH-000002
WH-000003
```

#### importance_rank

今回選出した用語の中での重要度順位です。

最重要を1とし、指定件数まで連番にしてください。

CSVの行自体は年代順に並べるため、importance_rankと行順は一致しなくて構いません。

#### difficulty_label

外側の依頼文から判断した難易度ラベルです。

#### term

大学受験世界史で一般的に使用される正式表記です。

#### reading

ひらがなで記載してください。

中国史・イスラーム史・難読人名などは特に正確に記載してください。

#### aliases

別名・旧称・異表記です。

複数ある場合は半角パイプで区切ってください。

```text
ビスマルク|オットー＝フォン＝ビスマルク
```

#### era

以下から最も適切なものを選択してください。

```text
先史
古代
中世
近世
近代
現代
複数時代
```

#### question_count

実際に作成した質問数です。

1〜4の整数にしてください。

#### q1_type〜q4_type

以下のような英字ラベルを使用してください。

```text
time
place
core
cause
content
impact
definition
connection
```

#### 使用しない質問欄

質問数が4問未満の場合、使用しない質問列・回答列・キーワード列は空欄にしてください。

不要な質問で埋めないでください。

#### total_keywords

統合説明に含まれる重要キーワードを半角パイプで区切ってください。

#### source_1・source_2

使用した情報源を記録してください。

形式：

```text
資料名｜URL
```

#### verification_status

以下から選択してください。

```text
二重確認済み
単一資料確認
要検証
```

## 19．情報源と正確性

歴史的事実、年代、人物、因果関係を確認してから出力してください。

Web検索を使用できる場合は、可能な限り複数の信頼できる資料で確認してください。

### 情報源の優先順位

1. 大学・博物館・公文書館・図書館などの学術的・公的資料
2. 信頼できる歴史事典・百科事典
3. 大学受験用の教科書・資料集・用語集
4. 世界史学習用の信頼できる補助サイト

「世界史の窓」などを参考資料として使用して構いませんが、可能なら別資料でも確認してください。

山川出版社の用語集やWebサイトの文章をそのまま大量にコピーしないでください。

事実関係を確認したうえで、学習用の簡潔な文章を独自に作成してください。

Web検索が利用できない場合は、実在しない資料名やURLを作らないでください。

その場合は出典欄を空欄にし、

```text
verification_status=要検証
```

としてください。

## 20．CSVの技術的条件

以下を厳守してください。

1. データ行数は、外側の依頼文で指定された件数と完全に一致させる
2. ヘッダー行を除いた件数を指定件数とする
3. 同じ用語を重複させない
4. 同義語や別表記による水増しをしない
5. 1セル内に改行を入れない
6. CSVのカンマ・ダブルクォートを正しくエスケープする
7. セル内のダブルクォートは `""` としてエスケープする
8. 文字コードはUTF-8
9. ファイル生成が可能な場合はUTF-8 BOM付きにする
10. 行は `sort_year` の古い順に並べる
11. 同じ `sort_year` の場合は、世界史の流れが自然になる順に並べる
12. Markdown表として出力しない
13. 回答文と統合説明文では重要語を `**太字**` にする
14. キーワード列ではMarkdownを使用しない
15. セル内で箇条書きや改行を使用しない
16. question_countと実際の質問数を一致させる
17. start_year・end_year・sort_yearを空欄にしない
18. 紀元前は負の整数にする
19. 指定件数をこのプロンプト内の例示件数へ置き換えない
20. 外側の依頼文で指定された範囲・カテゴリ・難易度を勝手に変更しない

## 21．出力前の自己検査

CSVを出力する前に、内部的に以下を確認してください。

### 件数・範囲

* 外側の依頼文から指定件数を正しく読み取ったか
* データ行数が指定件数ちょうどか
* 指定されたカテゴリ・地域・時代・難易度に従っているか
* 用語の重複がないか
* 表記違いによる水増しがないか

### 質問

* 各用語の質問数が1〜4問か
* 4問を埋めるためだけの不要な質問がないか
* それぞれの質問に答えるために、その用語についての歴史知識が必要か
* 用語名、読み、別名、質問文の中に答えがそのまま含まれていないか
* 日本語の意味、数字、国名、地名、一般常識だけで答えられる自明な質問がないか
* 時期質問が前後関係の理解に役立ち、答えが自明でないか
* 場所質問が地理的理解に役立ち、答えが自明でないか
* 時期・場所などの型を埋めるためだけの質問になっていないか
* 「いつ頃？」を使用していないか
* 時期質問で何の時期を尋ねているか明確か
* 質問文が答えを過度に教えていないか
* 質問文が広すぎて答えようがなくなっていないか
* 人物の行動を不必要に分割していないか
* 戦争の参戦国や終結条約が意味のある説明内に含まれているか
* 固定された質問文と単語回答を反射的に覚えるだけの設計になっていないか

### 回答

* 時期・場所以外の回答が単語1つだけになっていないか
* 各回答が1つの意味ある論点になっているか
* 大学受験上重要な関連語が含まれているか
* 因果関係が分かるか
* 重要キーワードが適切に太字になっているか
* 細かい雑学を詰め込みすぎていないか

### 統合説明

* 分解質問すべてに正解すれば統合説明を再構成できるか
* 統合説明だけに新しい重要情報を追加していないか
* 時期・場所・核心内容を説明できているか
* 模範文の丸暗記を要求する文章になっていないか

### 年代データ

* すべての用語にdisplay_periodがあるか
* すべての用語にstart_year・end_year・sort_yearがあるか
* 紀元前が負の整数か
* 世紀の数値変換が正しいか
* 人物の年代が生没年ではなく主な活動時期になっているか
* 思想・宗教・地域にも主要時期が設定されているか
* 時期質問の回答とdisplay_periodが矛盾していないか

### 地域・関連語

* 場所質問の回答とregion_detailが矛盾していないか
* relation_edgesが実際の歴史関係を表しているか
* 重要用語同士がマインドマップ的につながっているか

### CSV

* CSVとして正しく読み込めるか
* セル内改行がないか
* カンマやダブルクォートが正しくエスケープされているか
* 出典を捏造していないか

---

## 22．最終出力

ファイル生成機能が使用できる場合は、CSVファイルを作成してください。

ファイル名は、外側の依頼文から取得したデータセット名と指定件数をもとに作成してください。

形式例：

```text
world_history_<dataset_label>_<requested_count>.csv
```

ファイル名に使用できない日本語・記号がある場合は、分かりやすい英数字へ変換してください。

ファイル生成機能がない場合は、CSV全体を1つの `csv` コードブロック内に出力してください。

指定件数が多く、テキスト出力では途中で切れる可能性がある場合は、可能な限りファイル生成を優先してください。

CSV以外の以下の内容は出力しないでください。

* 前置き
* 作業報告
* 選定理由の解説
* 注意書き
* 要約
* Markdown表

外側の依頼文に必要な件数・範囲が明記されている場合は、確認質問をせず、その条件に従って完成したCSVを提出してください。
