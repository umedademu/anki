# 単語集のCloudflare利用方針

単語集の読み込みと書き込みは、必ずCloudflare経由で行います。

リポジトリ内の`public/data`や、Webアプリと同じ場所にある`/data`は手元の動作確認にだけ使用し、本番の単語集の読み書きには使用しません。

Cloudflareの接続先や操作方法が分からない場合は、ローカルの単語集で代用せず、必要な情報を利用者へ確認します。

## 学習記録と復習設定

- 問題集本体は従来どおりR2の`anki-world-history`から読み込む
- 問題ごとの評価、復習予定日時、習得済み状態、復習間隔はD1の`anki-progress`へ保存する
- 問題ごとの記録は問題集の版を保存範囲に含め、別版の問題集と混在させない
- WebアプリからD1へ直接接続せず、`anki-progress-api`を通して読み書きする
- 保存窓口は一人用アクセスキーで保護し、キーはGitや公開ファイルへ書かない
- CORSは本番Webアプリ`https://anki-ume.vercel.app`だけを許可する
- 端末内にはアクセスキーと表示設定だけを置き、学習記録の正本はCloudflareとする
- 一手戻しと記録初期化もCloudflare上の記録へ反映する

## 音声読み上げ

- 自然さを優先する音声は`anki-progress-api`からAzure AI Speechを呼び出して生成する
- Azureの接続キーはCloudflare Workerの秘密情報`AZURE_SPEECH_KEY`としてだけ保存し、ブラウザーやGitへ含めない
- Azureのリージョンは`japaneast`とし、許可した日本語音声7種類だけを使用する
- 生成済み音声は文章とAzure音声の組み合わせごとに分けて保存する
- 音声生成も一人用アクセスキーで保護し、本番Webアプリ以外からの通信を許可しない
- 生成済み音声はR2の`anki-world-history`内の`speech-cache`へ保存し、同じ文章では再生成しない
- 無料枠超過、通信失敗、生成失敗時は、利用者が端末ごとに選択した日本語音声へ切り替える
- 優先音声、端末音声、速度は端末ごとに利用可能な声が異なるため、学習記録とは分けて端末内へ保存する
