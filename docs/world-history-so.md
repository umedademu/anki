## 問題を追加する形式

**目次に沿って今後の章を追加する場合**は、25列形式の資料を `data/source/world-history-so/book/` へ保存し、`npm run preview:book:world-history-so` → `npm run publish:book:world-history-so` の専用手順を使います。新しいデッキを追加するために既存の問題集を作り直したり、下記の旧4列CSVへ混ぜたりしません。

登録用CSVは `data/source/world-history-so/questions.csv` です。見出しは「問題,回答,解説,カテゴリ」で、３列目は「説明」も使用できます。今後は同じファイルに行を追加し、４列目へ分野名を指定します。解説は空欄も使用できますが、問題・回答・カテゴリは必須です。カンマ・改行・引用符を含む値はCSVの引用規則に従います。

３列形式を読み取る関数は取り込み側がカテゴリを指定した場合だけ受け付けます。通常の登録用ファイルは、将来別分野を誤分類しないよう４列形式に統一します。元のダウンロードファイルは変更しません。

## 保存と更新

章・パートの追加には [追加専用のCloudflare登録手順](world-history-so-book.md) を使用します。以下の旧登録手順は元の自作問題CSV向けです。複数章の本番データを旧CSVだけで置き換えることはできず、既存番号の欠落を検知すると処理を中止します。既存問題の編集はアプリの問題編集画面を利用します。

本番ではCloudflare R2の `anki-world-history` 内の `subjects/world-history-so/` から読み込みます。手元の生成物は検査・登録用であり、本番の読み込み先にはしません。問題ごとの履歴は既存の保存窓口を経由してD1へ保存します。

教科の識別名は `world-history-so`、パート別の履歴版は、旧01・02・03・05・07・08・09・12・13章の保存範囲を維持します。統合・移動分は問題ごとの明示的な対応に従い現行13章の履歴を優先して複写します。旧履歴版 `world-history-so-deck-1-v1` の既存問題の記録は、明示した対応表に従って新しい保存範囲へ複写します。元の記録・日別時間・日別件数・旧一周は削除しません。新しいデッキの一周と周回数は新しく開始します。問題文から安定した識別番号を作り、行の追加・並べ替え・回答や解説やカテゴリの修正では履歴を維持します。同じ問題文の重複は拒否します。問題文の変更や削除には、旧識別番号からの履歴移行を別途検討する必要があります。登録処理も既存番号の欠落を拒否します。

1. `npm run build:data` と `npm run check` で生成・検査します。
2. `npm run preview:data:world-history-so` でCloudflare上の現在の科目一覧と対象件数を確認します。
3. `npm run publish:data:world-history-so` で世界史SOの分割データ、科目索引、全体索引の順に登録・照合します。

専用の登録処理はCloudflare上の現在の全体索引に世界史SOだけを追加・更新します。他科目の索引、問題、画像、音声、D1の履歴は書き換えません。世界史SOの習熟度複写は `scripts/world-history-so-progress.mjs` が担当し、複写前後の記録を非公開の `.wrangler/so-progress/` に保存して照合します。新しい保存範囲に存在する記録は上書きしません。作業中に全体索引が更新されていた場合は反映を中断します。

### 解答地図の生成

`scripts/create-answer-map.mjs`が出題用SVGの番号と空欄の位置を読み、CSVの回答から文字サイズを調整して解答用SVGを生成します。長いカリフ領の表示は２行にします。`writeSubjectData`で`-answer.svg`を生成し、専用の登録処理が出題用・解答用の両方をCloudflareへ登録・照合します。アプリは回答の表示状態に応じて画像の保存先と説明文を切り替えます。出題用SVGには答えを加えません。

章別の分割データと索引は内容ごとの保存先へ先に登録し、全デッキの照合と習熟度の複写後に全体索引を切り替えます。旧問題集はCloudflare上に残すため、公開途中の新旧混在や旧画面の参照切れを避けます。

各章のパート欄には「全パートを選択」「全パートを解除」を並べる。解除はその章だけを対象とし、一覧を残して選び直せるようにする。全章で未選択の間は学習開始・再開を無効にし、選び直す前の一時状態として扱う。1パート以上を選び直した時に既存のCloudflare保存へ反映する。
