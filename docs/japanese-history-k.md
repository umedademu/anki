# 日本史K

完成後の品質点検の範囲と修正内容は[品質点検](japanese-history-k-quality-review.md)を参照。第１回では第６章前半６小項目・307問を全文精読し、全141小項目の原文引用と公開内容の照合も行った。

日本史の原文に沿って小項目ごとに学ぶ科目。第1章「原始」全15小項目、第2章「古代」全27小項目、第3章「中世」全17小項目、第4章「近世」全23小項目、第5章「近代」全44小項目、第6章「現代」全15小項目を、451学習項目・3591問で収録する。基礎2173問、逆向きの説明967問、統合説明451問からなり、世界史と同じ仕組みで習熟度に応じて段階が進む。原文全６章・141小項目への問題集追加が完了し、未収録の小項目はない。

## 習熟度に応じた出題

開始画面の初期設定は「習熟度に応じて自動」。未学習では基礎のみを出題し、各学習項目の基礎問題を習得すると、その項目の逆向きの説明へ進む。項目内のすべての逆向きの説明を習得してから、統合説明へ進む。ほかの学習項目は自身の習熟度に従う。世界史の共通処理を利用し、正解・難しいの連続評価2回、または簡単の評価で問題を習得したと判定する。復習予定も既存の評価・間隔設定を使う。

未学習の場合、141小項目をすべて選んだ初期設定の3406問に対して最初の出題対象は基礎1988問。「すべて選択」の3591問では最初の対象は基礎2173問となる。収録数は説明問題も含めた数であり、初回に一斉に出題する数ではない。段階や問題種類を手動で絞った場合は、その選択に従う。「一項目につき一問」も世界史と同じ方式で利用できる。時期問題を除いた設定でも、統合で必要な年は基礎の内容説明または逆向きの説明で既出にする。

世界史SOと同じく、章を選び、その章に属する小項目の問題集を選択する。日本史Kでは、基礎・逆向きの説明・統合説明のすべてで、上部の大きな用語名・読み・段階名を置く枠を表示しない。回答表示後も同じ扱いとする。どの問題文も単独で意味が分かるため、問題文から学習し、回答と解説をその下で確認する。暗記・聞き流し、4段階評価、復習、途中再開は既存の仕組みを使う。日本史と世界史SOとは別の学習履歴を持つ。解説下の長い時期表示も、画面幅に応じて折り返す。

問題原稿の各問いに固定の番号、学習段階、重要語、原文根拠を記録する。新しい問いは未使用の番号を付け、既存の番号を並び順の変更で再割当てしない。生成時に引用が該当ページに存在すること、根拠番号、問題文と番号の重複、各項目の三段階、段階と問題種類の一致を検査する。基礎の用語特定以外の問いには項目名を含め、元資料や別の問題に依存する定型表現も検出する。同じ小項目に日本とヨーロッパの出来事がある場合も、統合問題の前置きは学習項目ごとの時代・地域に合わせる。個別の指定がない既存問題の前置きは維持する。

さらに、回答の太字と重要語一覧の一致、統合説明の誘導しない問題文、回答本文の時期・場所、回答の長さを検査する。統合説明にだけ現れる根拠・重要語・時期は拒否する。引用の原文は保持し、画面では脚注番号の表示指定を取り除き、年表の引用は表の区切りや改行の記号を読みやすく整える。自動検査だけでは意味上の妥当性や独立性を保証できないため、問い・解答も原文と照合して確認する。

作問後は別担当が全問を元の資料と照合し、名称から答えられる問い、重大な前問の手掛かり、重複、資料外の因果や追加情報を除く。

手元確認用の全科目生成と検査にも日本史Kの全141小項目を含め、世界史SOは追加章を含む全原稿と照合する。試験用の生成は`npm run build:data`、一式の検査は`npm run check`で行う。本番追加には手元の生成結果を代用せず、次の専用処理でCloudflare上の現行問題集へ反映する。

## Cloudflareへの反映

確認は`npm run preview:data:japanese-history-k`、登録は`npm run publish:data:japanese-history-k`で行う。本番の読み書きはCloudflare経由とし、手元の`public/data`は本番の代用にしない。手元の問題原稿は新規問題の作成用とする。

小項目の追加では、Cloudflare上の現行日本史Kの全索引・分割データを取得し、既存の問題集情報・問題・履歴版・科目設定を保持する。新規小項目の原稿だけを生成し、未使用の保存先へ登録・全文照合した後、取得時の全体索引の版を条件に一括で追加する。確認後の既存問題変更や同時編集を検知した場合は中止する。追加済みの小項目は一致確認だけを行い、登録後の本文編集を上書きしない。

追加登録の設定はUTF-8で4000バイト以内ずつに分割してCloudflareへ渡し、保存窓口で復元する。科目や問題集が増えても、一つの設定値の大きさが上限を超えないようにする。
