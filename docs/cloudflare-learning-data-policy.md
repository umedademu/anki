# 単語集のCloudflare利用方針

単語集の読み込みと書き込みは、必ずCloudflare経由で行います。

リポジトリ内の`public/data`や、Webアプリと同じ場所にある`/data`は手元の動作確認にだけ使用し、本番の単語集の読み書きには使用しません。

Cloudflareの接続先や操作方法が分からない場合は、ローカルの単語集で代用せず、必要な情報を利用者へ確認します。

## 学習記録と共通設定

- 世界史、日本史、英単語、地理、政治・経済、生物基礎を含む問題集本体はR2の`anki-world-history`から科目別に読み込む
- 問題集に関連画像が用意されている場合は、画像、説明、作者、利用条件もR2の`anki-world-history`から読み込む
- 関連画像一覧は問題CSVと分け、画像追加だけでは問題集の版と学習履歴の保存範囲を変更しない
- 画像一覧には用語の標準画像と問題ごとの固定画像を記録し、同じ用語でも問いの内容に応じて画像を切り替える
- 問題ごとの評価、復習予定日時、習得済み状態、進行中の一周、学習時間、復習間隔、音声設定、聞き流しの回答待ち時間、開始前の全選択項目、科目別の自動音声対象はD1の`anki-progress`へ保存する
- 最後の科目、科目ごとの複数Deckと学習方法、Deckごとの地域・カテゴリ・問題スタイル・出題量、シャッフル、自動読み上げを開始前の共通設定として保存し、次回の開始画面と別端末へ復元する
- 問題ごとの記録はDeckごとの安定した学習履歴版`version`を保存範囲に含め、別の問題集と混在させない
- CSV内容の更新検知には`contentVersion`を使用し、語呂合わせ・表記・解説などを更新しても`version`は変えず、既存の学習履歴を維持する
- 問題IDの意味や学習対象を互換性なく変更するときだけ新しい`version`を割り当て、科目・Deck追加時も既存Deckの`version`を維持する
- WebアプリからD1へ直接接続せず、`anki-progress-api`を通して読み書きする
- 保存窓口は一人用アクセスキーで保護し、キーはGitや公開ファイルへ書かない
- CORSは本番Webアプリ`https://anki-ume.vercel.app`だけを許可する
- 端末内にはアクセスキーと、Cloudflareから取得した音声設定の一時的な写しだけを置き、学習記録と共通設定の正本はCloudflareとする
- 一手戻しと記録初期化もCloudflare上の記録へ反映する
- 進行中の一周は選択したDeckの組合せと暗記・聞き流しの学習方法ごとに分けて保存し、端末内の一時保存を正本にしない
- 聞き流しの最後の問題完了時は日別件数の追加と途中記録の削除を同時に確定し、完了済みの一周を「前回の続きから」に残さない
- 複数Deckをまとめて学習する場合も、問題ごとの評価と復習予定は問題が所属するDeckの学習履歴版へ保存する
- 日別件数と学習時間は問題が所属するDeck名で保存し、組合せ用の途中記録とは保存先を分ける
- 各学習方法の「はじめから」は選択中の途中記録だけを置き換え、もう一方の途中記録は削除しない
- 暗記モードの評価確定と聞き流しの回答完了を1問として、科目、Deck、学習方法を含む日別学習記録をD1へ保存する
- 日別学習記録の学習日はCloudflareでの保存時刻から日本時間の午前4時区切りで決め、端末が送る日時には依存しない
- 学習時間も科目、Deck、学習方法、問題を含む独立した識別情報でD1へ保存し、日本時間の午前4時区切りで集計する
- 同じ問題画面の時間は最大30秒とし、同じ識別情報の再送時は最大秒数だけを保存して二重計上を防ぐ
- 一手戻りで問題完了の日別記録を取り消しても、実際に経過した学習時間は削除しない
- 暗記モードの評価確定を戻した時と、聞き流しで次の問題から前の問題へ戻った時は、対応する日別学習記録と進行中の一巡をCloudflare上で同時に戻す
- 問題別記録の初期化では日別学習記録を削除しない
- 問題集を更新するときは、新しい画像・分割データを登録・照合し、Deck索引、画像一覧、全体索引の順に各段階を登録・照合した後だけ、旧問題集にしかない索引・分割データ・関連画像を削除する
- 画像一覧に同じ内容識別名がある登録済み画像は再送せず、新規画像と問題集データだけを更新する
- 公開URLからの照合は取得間隔を空けて回数制限時に再試行し、画像・分割データの登録後に照合だけが中断した場合は`--resume-after-asset-upload`で照合段階から再開する
- 同じバケツの`speech-cache`とD1の学習履歴は削除対象に含めない
- 既存の世界史・日本史語呂を「語呂合わせマスター」と照合するときは、`npm run sync:mnemonics:goroawase-master`でCloudflare上の現行デッキを読み、年号と出来事が一致する対象だけを確認する
- 照合結果の元CSVへの反映は`npm run sync:mnemonics:goroawase-master:apply`で行い、その後に通常の生成・検査・Cloudflare置換を行う
- `npm run preview:data:cloudflare`で件数を確認してから、`npm run replace:data:cloudflare`で置換する

## 音声読み上げ

- 自然さを優先する音声は`anki-progress-api`からAzure AI Speechを呼び出して生成する
- Azureの接続キーはCloudflare Workerの秘密情報`AZURE_SPEECH_KEY`としてだけ保存し、ブラウザーやGitへ含めない
- Azureのリージョンは`japaneast`とし、許可した日本語音声7種類と英語音声4種類だけを使用する
- 生成済み音声は文章とAzure音声の組み合わせごとに分けて保存する
- 音声生成も一人用アクセスキーで保護し、本番Webアプリ以外からの通信を許可しない
- 生成済み音声はR2の`anki-world-history`内の`speech-cache`へ保存し、同じ文章では再生成しない
- 無料枠超過、通信失敗、生成失敗時は、利用者が設定した端末音声へ切り替える
- 優先音声、Azure音声、端末音声、速度はD1へ保存し、同じアクセスキーを登録した端末間で共有する
- 世界史の問題・回答・語呂合わせ・解説と、英単語の英語・日本語・例文英語・例文日本語のオン・オフは科目別にD1へ保存し、次回の学習と別端末へ共有する
- 日本語音声と英語音声を別々に保存し、文章の言語に応じて自動的に読み分ける
- 共有された端末音声が現在の端末に存在しない場合は、言語ごとに端末の推奨音声へ切り替える
- 世界史・日本史の読み上げを全件確認するときは、`npm run audit:speech:cloudflare`でCloudflare上の現行デッキを読み、問題・回答・解説・語呂合わせを検査する
