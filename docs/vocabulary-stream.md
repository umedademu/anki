# 英単語の3語表示

## 利用方法と表示

英単語の開始画面で、学習方法は「暗記モード」「聞き流し」の2つから選び、その下の「3語表示」スイッチをオン・オフにします。「暗記モード＋3語表示」「聞き流し＋3語表示」のどちらも選べます。他の科目にはこのスイッチを表示しません。

- 英語から日本語の意味を答える問題だけを対象にし、左に英単語、右に日本語訳を配置します。
- 英単語は右寄せ、日本語訳は左寄せにし、両方を画面の中央へ近づけます。左右の欄の間隔は12pxとし、短い単語でも訳との間に広い空白が残らないようにします。
- 最初は英単語だけを表示します。暗記モードでは「答えを表示」を押すと右側へ日本語訳を出し、評価できるようになります。聞き流しでは「答えを表示」を出さず、既存の回答待ち時間と読み上げの進行に合わせて訳を表示します。「次へ」は訳の表示後に操作できます。
- 各単語の下に「不正解・難しい・正解・簡単」の4つのボタンを置きます。訳の公開前もボタンは表示し、操作だけ無効にします。
- 暗記モードでは評価すると、聞き流しでは自動で次の問題へ進むと、新しい単語を最上段へ追加し、前の単語を下へ移動します。直近3回分を表示し、上から4番目以降の表示は画面から外します。画面から外れた単語も10個前までは途中記録に残し、スワイプで呼び戻せます。学習記録は消しません。
- 開始直後は1行、次は2行、その後は3行と12個の評価ボタンになります。
- 単語欄の上で上へスワイプすると、画面に出ている3行を1つずつ過去の単語へずらします（v0.425）。行の高さを超える長いスワイプではその分だけまとめて動き、下へスワイプすると新しい側へ戻ります。最新の単語と10個前までが対象で、表示できるのは常に3行・12ボタンです。長い単語や訳の欄で始めた操作は従来どおり欄の中身を上下に動かし、表示位置は変えません。パソコンではマウスのホイールでも1つずつ動かせます。
- 過去の単語を表示中は、一番上の行の左上に「2〜4つ前の単語を表示中 ▼ 最新へ戻る」のような表示を重ね、押すと最新の3行へ戻ります。過去を表示中に聞き流しが次の単語へ進んでも、見ている行はそのまま残します。表示を動かすだけでは保存通信を行いません。
- 新しい単語を追加するときだけ、約0.28秒で上から下へ押し出す動きを付けます。端末の「動きを減らす」設定が有効な場合も、切り替わる方向が分かるよう約0.16秒の短い動きを残します。単語欄を再利用するため、音声や保存状態の更新で進行中の動きを打ち切りません。答えの公開・評価訂正・一手戻り・再開では新たな動きを付けません。
- 例文、品詞などの補足、解説、画像は表示しません。自動音声も英単語と日本語の意味だけを対象にします。
- スマートフォン横画面を最優先にし、パソコンでも操作できます。長い単語や訳は各欄の中で上下に動かして確認できます。縦画面への個別最適化は行いません。
- スマートフォン横画面では、上端の余白を端末固有の安全な範囲または6pxまで詰め、空いた高さを3行へ配分します。英単語・日本語訳を大きくし、高さ500px以下では評価ボタンの文字と押せる高さも広げます。3行と12個のボタンは引き続き画面内に収めます。
- スマートフォン横画面では、通常表示と同じく上部のメニューの文字や印を隠し、上部中央をタップして開きます。幅は画面の中央3分の1で共通とし、単語欄や操作ボタンが重なる部分では学習の操作を優先します。メニュー専用の空白は設けません。パソコンや縦画面では従来のメニューボタンを表示します。

## 評価の訂正と再開

下に残った単語は4つのボタンで評価を訂正できます。聞き流しで評価せず進んだ単語にも、表示されている間は後から評価できます。選択中の評価には枠を付けます。訂正しても現在の問題や訳の公開状態は変えず、回答した回数と日時も増やしません。評価の内訳、習得状態、復習予定、不正解の再出題、指定問題数の達成数、毎日のメニューの達成数を合わせて修正します。同じ単語が再び上に表示された場合、その古い表示の評価は無効にして新しい学習記録の上書きを防ぎます。

操作できる評価ボタンを押すと、最新の単語・下に残った単語のどちらも、4段階それぞれの設定済み評価音をすぐに鳴らします。選択中の評価（枠付き）をもう一度押すと押下を取り消し、その単語を未評価へ戻します（v0.428）。取り消しでは枠を消し、学習記録をその回答の前の内容へ戻し、評価の内訳・習得状態・復習予定・不正解の再出題・指定問題数の達成数・毎日のメニューの達成数も評価なしで進んだ時と同じ扱いに直します。回答履歴は消さず評価なしのまま残すため、回答した回数と日時は変わらず、後から4つのボタンで評価し直せます。取り消せるのは、その行が表示されている間（最新の単語から10個前まで）に限り、同じ単語が再び上に表示された後や表示から外れた後は取り消せません。最新の単語は評価すると直ちに下へ移るため、取り消しは下に移った行で行います。取り消しの時も音で反応し、学習記録は増やしません。答えの公開前など操作できないボタンでは鳴らしません。

評価の保存を待つ間に止めるのは、評価した行の4つのボタンだけです（v0.433）。ほかの行の評価、最新の単語の「答えを表示」、一手戻り、一時停止・再生・次へは保存中もそのまま押せます。保存中に押した操作は音をすぐ鳴らし、記録はその保存が終わってから押した順に行います。保存に失敗して巻き戻した時は、待っていた操作を捨てます。

初期音・登録音とも、現在の読み上げ速度が1倍を超える場合は同じ倍率で速く鳴らします。1倍未満の設定でも評価音は遅くせず1倍を下限にします。学習中に速度を変更した場合も、次の評価から反映します。

過去の行の評価は、画面に出ている3行だけでなく、スワイプで呼び戻した10個前までの行でも同じ手順で訂正できます。「一手戻る」は答えの公開と現在の回答を一手ずつ取り消します。聞き流しでは再生・一時停止・次へも操作できます。過去行の評価を訂正した場合は、その前の一手戻りの履歴を区切り、確定した訂正を古い状態で上書きしません。

3語表示のオン・オフを学習方法と独立してCloudflareへ保存します。直近11行（表示する3行とスワイプで戻れる10個前まで）、公開済みの訳、評価も途中記録へ保存し、開始画面からの再開と学習画面の再読み込みで復元できます。保存窓口と画面側は11行を超える分を受け付けません。別の学習方法へ切り替えてもスイッチの選択を保持し、既存の共通の一周と学習記録を利用します。表示行は切り替え後の学習方法で新たに積み上げ、前の方法の回答履歴を変更しません。聞き流しの過去行の評価は自動進行と順番に保存し、正常時は再生を続けます。聞き流しでは訳を表示するたびには途中記録を送らず、次の単語へ進んだ時の1回の保存にまとめます。再読み込み時は表示中の単語の訳を隠して読み直すため、公開済みかどうかを都度保存する必要はなく、送ると1語あたりの通信が2倍になって保存待ちで次の読み上げが遅れるためです（v0.415）。さらにv0.424からは、途中記録を前回保存した内容との差分だけで送るため、単語集が多くても1語あたりの通信は上り約2KB・下り約0.5KBに収まり、単語を重ねても読み上げの間が伸びません。v0.425で表示行を11行に増やした際も、表示行は「消す行・先頭へ足す行」の差分で送るため1語あたりの通信は増えません。保存に失敗した場合は表示・評価・進行・毎日のメニューを操作前へ戻し、未保存のまま進むことを防ぎます。

## 保存と確認

問題集は既存のCloudflare R2から取得し、学習記録はCloudflare D1へ保存します。学習記録上の方法は選択した暗記モードまたは聞き流しのまま、開始設定と途中記録に3語表示のオン・オフを保存します。過去行の評価訂正では同じ学習方法の既存の回答履歴を更新し、回答履歴を追加しません。同じ評価の押し直しによる取り消しは`reviseRating`を空にして送り、保存窓口は回答履歴の評価を空にし、問題記録を回答前の内容（なければ削除）にします。`reviseRating`を省いた従来の訂正は問題記録の評価をそのまま回答履歴へ写します。単語集本体や他科目は変更しません。

- `node scripts/test-vocabulary-stream-persistence.mjs`：開始設定・11行の途中記録・不正な修正の拒否・回答履歴訂正・同じ評価の押し直しによる取り消しを確認します。
- `node scripts/test-study-session-patch.mjs`と`node scripts/test-study-session-save.mjs`：途中記録の差分の作成と当てはめ、保存窓口での拒否、画面側の差分送信と全体の送り直しを確認します。
- `npm run test:listening-gap:browser`：2,000語の聞き流しをスマートフォン相当の処理速度と携帯回線相当の通信速度で30語分進め、読み上げと読み上げの間が単語を重ねても伸びないことと、1語ごとの保存通信が小さいことを実測します。音声は鳴らさず、本物の保存処理を手元の仮の記録領域で動かします。
- `npm run test:vocabulary-stream:browser`：学習方法の2択と独立したスイッチ、英単語限定、両方法の訳の公開順、最大3行・12ボタン、聞き流しの自動進行と再生操作、過去の評価訂正、同じ評価の押し直しによる取り消し、毎日のメニュー、保存失敗、再読み込み、一手戻り、上下スワイプとホイールによる10個前までの移動と最新へ戻る操作、過去を表示中の訂正と聞き流しの自動送り、同じ単語の再出題を確認します。横画面667×375・812×375・932×430とパソコン1366×768を確認します。
- 画面試験は人工データと仮の保存先だけを使用し、開始前に自動読み上げをOFF、全読み上げ対象をOFFにします。音声の取得・再生と、本番の保存先への通信を防ぎます。
- 「前回の続きから」は、ボタンを押した操作の中で先読みの割り当てと評価音の出力を捨て、2台の再生器の許可を準備し、専用の再生器で1.1秒の無音の準備音を自然に終わるまで鳴らします。最初の読み上げはその終了を待ってから始め、端末の音声出力権を取り直して現在のイヤホンへつなぎ直します（v0.421〜v0.423。再生器は作り直さず、単語ごとには鳴らしません。開始時だけ最大約1秒待ちます）。3行の表示と学習記録は保持します。画面試験では、再生許可の準備と準備音が保存通信より前の利用者操作中に行われることも確認します。読み上げが鳴り始めた後に再生位置が進まない時や、端末側で止められた時は、次の単語へ進めずその問題で一時停止し、理由を添えたお知らせを表示します。
- スライドは暗記・聞き流しの両方を、通常設定と「動きを減らす」設定で確認します。移動中の座標が開始位置・完了位置のどちらとも異なることを実測し、音声や保存状態の更新でも同じ行と移動処理が続くことを確認します。

保存窓口の変更を反映する際は、画面の公開前に `worker/wrangler.jsonc` の既存保存処理を更新します。保存形式を追加する変更のため、表の追加や既存の単語集の変更は不要です。
