## 分類基準

- 用語の特定：制度・事件・作品・建造物・宗教などの名称を答える。
- 時期：出来事の年号・年代そのものを答える。年号が手がかりに含まれるだけの問題は含めない。現行データは0問。
- 場所：都市・地域・移動先を答える。地図の空欄6問もここに含める。
- 人物：個人名を答える。複数の君主名を列挙する問題も含める。
- 主体：行動・建国・対立などに関わる王朝・国家・民族・集団を答える。一般名称の定義から用語を答える問題は「用語の特定」とする。
- 原因：理由・背景・目的・きっかけを答える。
- 内容：政策・行動・経緯・具体的な産品や言語などを答える。
- 結果：出来事によって生じた変化や影響を答える。
- 関係：比較・違い・複数の対象の対応関係を答える。
- 逆向きの説明：提示された用語の意味・定義を簡潔に説明する。
- 統合説明：提示された人物・王朝・事件・制度などの概要を、経緯・特徴・業績・影響をまとめて説明する。

説明を求める問題でも、問いが原因や具体的な政策などに絞られている場合は、その内容を優先します。各問には一つの種類を割り当て、問題スタイルの「一問一答」は変更しません。

## 保存と更新

- 章の選択と種類の選択を併用する。表示件数は選択中の章に含まれる種類別の件数。0問の種類も表示し、0問の状態では開始しない。
- 選択は科目別にCloudflareの共通設定へ保存し、暗記・聞き流しの開始と再開に適用する。全解除は未設定と区別する。
- 編集画面から追加した未分類の問題がある場合は「未分類」も表示し、選択できるようにする。現行357問には未分類はない。
- 分類表は `data/source/world-history-so/question-types.json`。問題番号と問題文を明示し、未知の問題や問題文変更を検出した場合は公開前に中断する。追加・変更時は分類表も見直す。
- `npm run preview:types:world-history-so` でCloudflare上の現行問題を直接取得・照合し、`npm run publish:types:world-history-so` で分類だけを更新する。ローカルの単語集は本番への更新元にしない。
- 処理は作業中だけ認証付きの保存窓口をCloudflareへ設置する。現行データを新しい保存先へ登録・照合し、全体索引の版を条件として切り替える。同時編集があれば中断する。最後に作業用の窓口を削除する。
- 旧問題集と旧索引をCloudflareへ残し、作業前の写しも非公開の `.wrangler/so-types/` に保存する。D1の履歴は変更しない。
