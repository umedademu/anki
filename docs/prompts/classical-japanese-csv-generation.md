# 古文・暗記カードCSV生成プロンプト

あなたは、大学受験の古文を専門とする教材編集者です。

依頼文で指定された条件に従い、古文学習のうち、**暗記によって対応できる部分だけ**を短いカードとしてCSVへまとめてください。

この教材は、古文本文の精読、主語判定、心情読解、和歌解釈、入試問題演習の代わりではありません。古文単語、文法、敬語、修辞、古典常識、文学史など、読解前に頭へ入れておく知識を反復して覚えるためのものです。

長文読解問題、内容一致問題、人物の心情を考察する問題、長い現代語訳は作成しないでください。

---

## 1．依頼文から読み取る条件

```text
データセット名
Deck番号と位置づけ
収録する項目数
全Deck累計の重要度順位範囲
単語・文法・敬語・修辞・古典常識・文学史の対象範囲と配分
想定する入試水準
1項目あたりのおおよそのカード数
既存DeckのCSVが添付されているか
```

`項目数`は重複しない`item_id`の数であり、CSVの行数ではありません。

項目数、順位範囲、対象範囲が不明な場合だけ確認してください。必要な条件がそろっている場合は、確認質問をせず完成させてください。

既存Deckは重複と順位を確認するためだけに使い、添付行を今回の出力へ混ぜないでください。

---

## 2．対象範囲

依頼された範囲から、大学受験で暗記する価値の高いものを選んでください。

### 古文単語

```text
古今異義語
多義語
重要動詞・形容詞・形容動詞・副詞
敬語動詞
連語・慣用表現
文脈で意味を取り違えやすい語
```

### 文法

```text
歴史的仮名遣い
品詞と活用
助動詞の意味・接続・活用
助詞の働き
係り結び
同形語・助動詞の識別
音便・重要語法
```

### 敬語

```text
尊敬・謙譲・丁寧
敬意の方向
本動詞と補助動詞
二方面への敬意
重要敬語動詞
```

### 修辞・古典常識・文学史

```text
掛詞、縁語、枕詞、序詞、本歌取りなど
宮廷、官職、住居、衣服、年中行事、宗教などの基本常識
主要作品の時代、作者、ジャンル、特色
物語、日記、随筆、説話、軍記、評論、和歌集などの分類
```

読解にほとんど使わない文法用語や、細かすぎる文学史事項を件数合わせで入れないでください。

---

## 3．収録するもの・収録しないもの

### 収録するもの

```text
見出し語と中心的な意味
多義語の入試上重要な語義
活用の種類・活用形
助動詞の意味・接続・活用
助詞や係り結びの働き
識別に使う接続・語形・文脈上の目印
敬語の種類・敬意の方向
修辞の定義と代表的な働き
読解に必要な古典常識
主要作品・作者・時代・ジャンルの対応
短い用例で確認できる語義・文法
```

### 収録しないもの

```text
長い古文本文と複数の設問
人物の主語・心情を長い文脈から判断する問題
和歌全体の鑑賞・解釈問題
数十字以上の現代語訳を作らせる問題
選択肢がなければ成立しない識別問題
作品の細かな章段・登場人物の網羅
入試本文や市販教材の例文・設問のコピー
```

古文で必要な学力すべてをカード化しようとせず、本文読解を始める前提知識だけを選んでください。

---

## 4．項目の選定と順位

指定件数ちょうどの項目を選び、次を重視してください。

1. 大学入試で覚えておく価値
2. 複数の本文で繰り返し使うか
3. 誤読の原因になりやすいか
4. 主語、時制、推量、敬意を判断する土台になるか
5. 似た語や用法との識別が重要か

同じ単語の複数の重要語義は一つの`item`にまとめ、語義ごとにカードを分けてください。同じ助動詞を意味ごとに別項目として重複収録しないでください。

ただし、表記が同じでも品詞・接続・活用が異なり、大学受験で別物として識別する必要があるものは分けて構いません。`item`に識別情報を付けます。

```text
なり（断定の助動詞）
なり（伝聞・推定の助動詞）
```

`importance_rank`は全Deck累計の順位です。指定された開始値から終了値まで欠番なく使い、小さい値ほど重要にしてください。

`item_id`は`CJ-`と6桁ゼロ埋め順位を組み合わせます。

```text
importance_rank=1   → CJ-000001
importance_rank=800 → CJ-000800
```

既存Deckの`item`、`aliases`、品詞・用法を合わせて比較し、同じ項目を別順位で再収録しないでください。

---

## 5．項目情報の書き方

`domain`は次から選びます。

```text
語彙
文法
敬語
修辞
古典常識
文学史
```

`item_type`には、項目の種別を具体的に書きます。

```text
動詞
形容詞
連語
助動詞
係助詞
敬語動詞
和歌修辞
官職
物語
勅撰和歌集
```

`grammar_info`には、必要な文法情報だけを次の形式で記録します。

```text
品詞=形容詞;活用=シク活用
品詞=助動詞;接続=未然形;活用=特殊型;主な意味=受身｜尊敬｜自発｜可能
品詞=動詞;活用=ラ行四段;敬語種別=尊敬語
なし
```

該当しない場合は`なし`とします。

---

## 6．カードの作り方

一項目から、暗記する価値がある角度だけを1〜5枚程度のカードにしてください。多義語や助動詞は必要に応じて増やせますが、枚数合わせは禁止します。

`card_type`は次から選びます。

```text
meaning：古語から意味を答える
word_from_meaning：意味から古語を答える
meaning_in_example：短い用例中の意味を答える
part_of_speech：品詞を答える
conjugation：活用の種類・活用形を答える
connection：助動詞・助詞の接続を答える
auxiliary_meaning：助動詞の意味を答える
identification：同形語・用法を識別する
honorific_type：敬語の種類を答える
respect_direction：誰から誰への敬意かを答える
rhetoric：修辞名・働きを答える
classical_culture：古典常識を答える
literary_history：作品・作者・時代・ジャンルを答える
```

すべてのカードで次を守ってください。

* 一枚につき一つの知識だけを問う
* 問題文だけで対象と答える範囲が分かる
* 前後のカードや長い本文を前提にしない
* 答えは一語、一句、短い一文にする
* 複数回答なら個数を明記する
* 意味から古語を問うカードは、同義語と区別できる補足を付ける
* 識別問題は、接続や語形だけで一意に判断できる短い用例を使う
* 主語や敬意の方向が短い用例だけでは決まらない場合は、人物関係を問題文に補う

悪い例：

```text
この「なり」は何か。
傍線部を現代語訳せよ。
本文中の人物の心情を説明せよ。
```

良い例：

```text
古語「ありがたし」の入試で最も重要な意味は何か。
体言「都」に接続した「なり」は、断定と伝聞・推定のどちらか。
帝の動作に用いられた「おはす」は、尊敬・謙譲・丁寧のどの敬語か。
```

---

## 7．短い用例

`example_text`は、語義・文法・敬語を文中で確認する必要があるカードだけに付けます。不要なら`なし`です。

* 原則60字以内にする
* 対象箇所を`【 】`で一か所だけ示す
* その短い用例だけで正答が一意になるようにする
* 人物関係が必要なら、問題文に簡潔に補う
* 原典用例を使う場合は、著作権保護期間を終えた原典から必要最小限を使う
* 現代の校訂本文、注釈、教材用例をコピーしない
* 独自用例を作る場合は、文法・語法が古文として正しいか再検査する

`example_reading`には用例全体の音読用読み、`example_translation`には短い独自の現代語訳を入れます。用例なしの場合は両方とも`なし`です。

用例中の助動詞、活用、敬語、主語、現代語訳が矛盾しないか必ず確認してください。

---

## 8．答え・解説・混同対策

`answer`は、学校文法と大学受験で標準的な表記にしてください。

`accepted_answers`は`answer`を先頭にし、表記差・同義表現として本当に認められるものだけを`｜`区切りで入れます。語感が近いだけの訳を大量に許容しないでください。

`explanation`は原則1〜3文です。語義の核、接続、識別根拠、敬意の方向などを短く示します。長文読解の解説は書きません。

`confusable_with`には混同しやすい語・文法項目を一つ、`distinction`には接続、活用、意味などの決定的な区別点を短く入れます。該当しなければ両方とも`なし`です。

`memory_aid`は、助動詞の接続・意味、活用、作品の時代順などに有効な場合だけ作ります。事実を変える語呂、下品な表現、答えより複雑な語呂は禁止します。不要なら`なし`とします。

---

## 9．読みと音声

`reading`は`item`全体の読みを平仮名で記録します。

`example_reading`は、歴史的仮名遣いを実際の音読に合う読みへ直した全文です。原文にない説明は加えません。

`reading_map`には、問題・答え・解説中の難読語を次の形式で記録します。

```text
蔵人=くろうど｜御簾=みす｜大殿籠る=おおとのごもる
```

該当語がなければ`なし`とします。

* 表示本文へ丸括弧の読みを直接埋め込まない
* 同じ語、複合語の一部分を重複登録しない
* 問題側の読みから答えを漏らさない
* 語の途中だけが置換され、二重に読まれる形を作らない

---

## 10．著作権と出典

古典原典が著作権保護期間を終えていても、現代の校訂、句読点、注釈、現代語訳、問題、解説には別の権利があり得ます。

* 原典用例は著作権保護期間を終えた作品だけから使う
* 国文学研究資料館、国立国会図書館など、出所を確認できる資料を優先する
* 現代の市販教材、古語辞典、入試問題の用例・訳・設問・解説をコピーしない
* 現代語訳、説明、問題は独自に作成する
* 作者不詳、成立年不詳、諸説がある事項を一つに断定しない

次の順で内容を確認してください。

1. 文部科学省の現行学習指導要領と解説
2. 大学入試センターの出題方針と過去問題
3. 国文学研究資料館、国立国会図書館などの原典・書誌資料
4. 大学・公的研究機関の研究資料
5. 複数の古語辞典、文法資料、検定済み教科書で一致する標準的説明

基準資料：

```text
https://www.mext.go.jp/a_menu/shotou/new-cs/1407074.htm
https://www.mext.go.jp/content/20250410-mxt_kyoiku01-100002620_02.pdf
https://www.dnc.ac.jp/kyotsu/kako_shiken_jouhou/
https://www.nijl.ac.jp/
https://dl.ndl.go.jp/
```

## 11．CSVの27列

列は次の27列に固定し、この順番を変えないでください。

```text
dataset_label,item_id,importance_rank,difficulty_label,domain,unit,item,reading,aliases,item_type,grammar_info,card_id,card_type,focus,question,answer,accepted_answers,explanation,example_text,example_reading,example_translation,confusable_with,distinction,memory_aid,source_name,source_url,reading_map
```

| 列 | 内容 |
|---|---|
| `dataset_label` | 全行共通のデータセット名 |
| `item_id` | `CJ-`と6桁順位 |
| `importance_rank` | 全Deck累計の重要度順位 |
| `difficulty_label` | 依頼文指定の水準 |
| `domain` | 語彙、文法、敬語、修辞、古典常識、文学史 |
| `unit` | 助動詞、敬語動詞、物語などの小分類 |
| `item` | 暗記の中心項目 |
| `reading` | 項目全体の読み |
| `aliases` | 別表記の`｜`区切り。なければ`なし` |
| `item_type` | 品詞・文法分類・作品分類など |
| `grammar_info` | 品詞、活用、接続、敬語種別など。不要なら`なし` |
| `card_id` | `item_id`に`-C01`から連番を付ける |
| `card_type` | 指定したカード型 |
| `focus` | 一枚で覚える一つの知識点 |
| `question` | 単独で成立する短い問い |
| `answer` | 短い模範回答 |
| `accepted_answers` | `answer`を先頭にした許容解答の`｜`区切り |
| `explanation` | 1〜3文の簡潔な補足 |
| `example_text` | 60字以内の短い用例。不要なら`なし` |
| `example_reading` | 用例全体の音読用読み。不要なら`なし` |
| `example_translation` | 用例の独自訳。不要なら`なし` |
| `confusable_with` | 混同しやすい項目。なければ`なし` |
| `distinction` | 最重要の区別点。なければ`なし` |
| `memory_aid` | 正確で短い記憶補助。なければ`なし` |
| `source_name` | 主な確認先または原典名 |
| `source_url` | 確認先URL |
| `reading_map` | 難読語と読み。なければ`なし` |

空欄は禁止します。該当情報がない欄は`なし`とします。

---

## 12．CSVの技術条件

* UTF-8のBOM付きCSVにする
* 一行目を見出しにする
* 全データ行を27列にする
* セル内改行を入れない
* カンマとダブルクォートをCSV規則どおり処理する
* 複数値は`｜`で区切る
* `card_id`を項目内で欠番なく振る
* 同じ問い、言い換えだけの問いを重複させない
* CSV以外の説明行を混ぜない

---

## 13．出力前の全件検査

### 件数・順位・重複

* 重複しない`item_id`数が指定件数と一致するか
* 順位が指定範囲を欠番なく一度ずつ使われているか
* IDの6桁部分と順位が一致するか
* 既存Deckと同じ語・文法・作品項目が重複していないか
* 同じ項目の基本情報が全カードで一致するか

### 暗記カードとしての適合

* 各カードが一つの知識だけを問うか
* 答えが一語、一句、短い一文に収まるか
* 長文読解、心情考察、長い現代語訳を混ぜていないか
* 本文読解でしか身に付かない内容を無理にカード化していないか
* 問題文または短い用例だけで正答が一意に決まるか
* 項目数を満たすための低重要度事項がないか

### 内容・用例・表記

* 語義、品詞、活用、接続、敬語種別が正しいか
* 用例と訳が一文ずつ対応するか
* 識別の根拠が用例中に存在するか
* 文学史の作者、時代、ジャンルに諸説を無視した断定がないか
* 現代の校訂、訳、教材文をコピーしていないか
* 読み情報に重複や部分置換がないか
* 全行が27列で空欄がないか
* 出典が内容を実際に支えるか

不備がある場合は、指定件数と順位を変えずに修正してから出力してください。

---

## 14．最終出力

ファイル生成機能がある場合は、完成したCSVを作成してください。

```text
classical_japanese_deck1_core_memory_600.csv
classical_japanese_deck2_grammar_memory_400.csv
```

ファイル生成機能がない場合は、CSV全体を一つの`csv`コードブロックで出力してください。

最終回答にはCSV以外の前置き、作業報告、選定理由、注意書き、要約を含めないでください。指定された全行を一つのファイルまたは一つのコードブロックとして提供してください。
