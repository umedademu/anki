# 添付MD資料準拠・世界史三段階学習用CSV生成プロンプト

あなたは、**大学受験世界史の教材編集者**です。

依頼文で指定された条件と、添付されたMDファイルの内容に従い、世界史の用語と問題を収録したCSVを作成してください。

このプロンプトの役割は、教材となる用語・問題・答えを作ることだけです。

各用語について、次の三種類の問題を作成してください。

```text
beginner：普通の一問一答形式で、短く答える問題
reverse：用語名を見て、時期・場所・内容・原因・結果などを答える問題
integrated：用語全体を説明する問題
```

---

## 最重要原則：添付資料を習得すれば答えられる問題だけを作る

このCSVは、添付されたMDファイルを学習するための問題集です。一般的な世界史知識を広く試す問題集ではありません。

すべての問題について、次の両方を必須条件とします。

1. 添付されたMDファイルを十分に習得した学習者なら、その資料の記述だけを根拠に答えられる
2. 添付されたMDファイルを十分に習得していても、資料外の知識がなければ答えられない問題にはなっていない

問題文、正答、正答に必要な限定条件、因果関係、時期、場所、人物、制度、結果は、すべて添付資料内で確認できなければなりません。複数の添付ファイルにある記述を組み合わせても構いませんが、外部のWebサイト、モデルが持つ一般知識、添付されていない原書・画像・別章を前提にしてはいけません。

作成前に添付されたすべてのMDファイルを最後まで読み、見出し、本文、箇条書き、表、図の書き起こし、注記、語呂合わせを把握してください。一部だけを読んで作成を始めてはいけません。

各問題を採用する前に、正答の根拠となる記述を添付資料内で特定してください。根拠を特定できない問題、資料の表現から一意に答えを決められない問題、資料より細かい知識を求める問題は削除してください。

指定件数を満たすために資料外の用語や知識を追加してはいけません。三段階の問題を作るのに十分な記述がある用語が指定件数より少ない場合は、CSVを作る前に、作成可能な最大用語数を依頼者へ伝えてください。

---

## 1．依頼内容の確認

CSVを作る前に、次を依頼文から判断してください。

```text
収録する用語数
用語の選定基準
難易度
対象カテゴリ
対象地域
対象時代
データセット名
使用する添付MDファイル
各添付資料に対応する出典URL
```

### 収録する用語数

収録する用語数です。

CSVの行数ではなく、重複しない`term_id`の数を指定件数と一致させてください。

1用語につき複数の問題行を作るため、CSV全体の行数は指定件数より多くなります。

### その他の条件

依頼文で指定された難易度、地域、時代、カテゴリ、選定方針に従ってください。

条件が指定されていない項目は、依頼文全体から自然に判断してください。

ただし、用語数、対象範囲、使用する添付MDファイル、またはアプリ取込用の出典URLが分からない場合だけ、不足している条件を確認してください。

必要な条件がそろっている場合は、確認質問をせずにCSVを完成させてください。

## 2．用語選定

指定件数ちょうどの用語を選んでください。

用語候補は、添付されたMDファイルに名称と学習上必要な説明が記載されているものに限定してください。添付資料に名前だけが登場し、三段階の問題を作るための説明が不足している語は選ばないでください。

用語そのものが資料にあっても、問題の正答となる知識が資料に書かれていなければ、その知識を問うことは禁止します。入試で頻出という理由だけで、資料にない関連人物、年号、地名、制度、条約、原因、結果を補ってはいけません。

大学受験用の用語選定では、次を重視してください。

1. 大学入試での重要度
2. 世界史の大きな流れを理解するうえでの重要度
3. 原因・結果・前後関係を学ぶ中心になるか
4. 他の重要用語とのつながりが多いか
5. その用語を知らないと通史理解に穴が開くか

この重要度判断は、添付資料内に十分な根拠がある候補同士の優先順位を決めるためだけに使用してください。重要度が高くても添付資料にない用語は選定対象外です。

同じ用語の別表記、略称、旧称を別用語として数えないでください。

件数が少ない場合は、地域やカテゴリの均等配分より重要度を優先してください。

件数が多い場合は、依頼範囲に応じて地域・時代・カテゴリの偏りを確認してください。

`importance_rank`は、段階別デッキシリーズ全体での累計重要度順位です。

依頼文で指定された順位範囲を欠番なく使用し、デッキごとに1から振り直さないでください。

例：Deck 1は1〜400、Deck 2は401〜800、Deck 3は801〜1,200です。

既存デッキの用語と重複する語を新しい順位で再収録しないでください。

## 3．問題の三段階

各問題行の`stage`には、次のいずれかを設定してください。

```text
beginner
reverse
integrated
```

### beginner：短答問題

普通の一問一答として、短い答えを思い出す問題です。

1問につき、答えは一つの知識だけにしてください。

ここでいう短い答えは、必ずしも一語だけという意味ではありません。

次の程度までを短答として認めます。

```text
七年戦争
1756年
シュレージエン
プロイセンとオーストリア
イギリスとフランス
九十五か条の論題
```

一文以上の説明が必要になる問題は、`reverse`へ回してください。

各用語について、原則として3〜7問程度の短答問題を作ってください。

ただし、問題数をそろえるための水増しは禁止します。用語の重要度と内容に応じて増減して構いません。

各短答問題の正答は、添付資料の本文、箇条書き、表、図の書き起こし、注記のいずれかに明記されていなければなりません。一般的な教科書には載っているという理由や、歴史知識から推測できるという理由では採用できません。

次の観点から、大学受験上必要なものだけを選んでください。

```text
説明や特徴から用語名を答える
重要な時期
中心人物
国家・勢力・対立相手
自明ではない地域
直接の原因やきっかけ
中心となる制度・政策・内容
直接の結果
前後の重要用語とのつながり
```

各用語には、説明や特徴から用語名を答える問題を原則1問以上含めてください。

用語名そのものを答える`identify`以外の短答問題では、**必ずその行の`term`を問題文へ明記**し、時期・人物・国・地域・原因・結果などを短く答えさせてください。

同じ用語の別問題、直前の行、CSV上の並び順、画面上の用語欄を前提にしてはいけません。アプリでは各行が独立した問題として出題され、順番も入れ替わります。

例：

```text
1756年に始まり、プロイセンとオーストリアの対立を軸に世界規模へ広がった戦争は？
→ 七年戦争

七年戦争で、ヨーロッパにおける対立の中心となった二国は？
→ プロイセンとオーストリア

七年戦争で、オーストリアが奪回を目指した地域は？
→ シュレージエン

七年戦争と並行し、植民地で争った中心国は？
→ イギリスとフランス
```

### 短答問題の注意

質問文だけで、何を答えればよいか分かるようにしてください。

これは努力目標ではなく、すべての`beginner`行に対する必須条件です。

* `question_type=identify`では、その一文だけから答えの用語が一意に決まる説明を書く
* `question_type=identify`以外では、その行の`term`を表記どおり問題文へ必ず含める
* 「前の問題を見れば分かる」「同じ用語のまとまりだから分かる」という省略をしない
* 「この人物」「この王朝」「その反乱」など、前の行を参照する指示語だけで対象を示さない

悪い例：

```text
反乱を始めた節度使は？
成立した王政は？
首都は？
中心人物は？
聖典は？
```

良い例：

```text
安史の乱を起こした節度使は？
七月革命によって成立した王政は？
アッシリアの首都は？
ジャコバン派の中心人物は？
バラモン教の聖典は？
```

複数の正解が自然に考えられる曖昧な質問は作らないでください。

悪い例：

```text
七年戦争に参加した国は？
```

良い例：

```text
七年戦争で、ヨーロッパにおける対立の中心となった二国は？
```

用語名を読むだけで答えられる自明な質問は禁止します。

```text
キューバ革命が起きた国は？ → キューバ
三国同盟は何か国の同盟？ → 3か国
第一次世界大戦は何回目の世界大戦？ → 1回目
```

同じ用語について、時期、人物、対立、原因、結果、関連語など、異なる角度から思い出せる構成にしてください。

細かすぎる数字、雑学、説明に不要な地名で問題数を増やさないでください。

年代に幅がある場合は、無理に単年へせず、世紀や期間を答えにしてください。

### reverse：逆一問一答

用語名を見て、時期・場所・内容・原因・結果など、その用語を説明するために重要な知識を答える問題です。

#### 質問数

各用語について、**1〜4問**の重要質問を作成してください。

4問作ること自体を目的にしてはいけません。

* 1問で十分なら1問
* 2問で十分なら2問
* 3問必要なら3問
* 本当に必要な場合だけ4問

としてください。

標準は2〜3問程度ですが、機械的にそろえないでください。

質問選定の基準は、

> その質問すべてに答えられる人なら、その用語についてほぼ説明できるか

です。

同時に、各質問について、添付資料を十分に習得した人が資料内の知識だけで回答文を再構成できるか確認してください。回答に含める重要語や因果関係の一部でも添付資料にない場合は、その部分を削るか、質問自体を採用しないでください。

単なる雑学、細かすぎる数字、説明に必須でないプロフィール情報は原則として除外してください。

また、質問数を確保するために、**用語名を見れば歴史知識がなくても答えられる質問**を追加してはいけません。

質問を1問ずつ、次の基準で確認してください。

> この質問は、用語名や一般常識からの推測ではなく、その用語についての世界史知識を思い出すために必要か

答えが用語名に含まれている、自明に推測できる、または答えても用語の理解が深まらない場合は、その質問を削除してください。その結果が1〜2問でも問題ありません。

---

#### 時期に関する質問

時期を知ることが用語の理解や前後関係の把握に役立つ場合は、時期を問う質問を入れてください。

ただし、用語名に年・世紀・時代が明記されており、そのまま同じ内容を答えさせるだけになる場合は、時期質問を作らないでください。時期を聞くこと自体を目的にせず、学習上の価値がある場合だけ採用してください。

ただし、単純に、

```text
いつ？
```

とだけ聞くと、人物の場合は出生年なのか活動時期なのか分かりません。

一方、

```text
いつ頃？
```

と聞くと、年号ではなく大まかな時代で答えてよいというヒントになります。

そのため、**何の時期を尋ねているかは分かるが、答えの精度は推測できない質問文**にしてください。

### 推奨例

| カテゴリ         | 時期質問                  |
| ------------ | --------------------- |
| 人物           | 主に活動したのはいつ？           |
| 国家・王朝        | 存在したのはいつ？             |
| 建国時期が特に重要な国家 | 成立したのはいつ？             |
| 地域・都市        | 特に繁栄したのはいつ？           |
| 事件・革命        | 起きたのはいつ？              |
| 戦争           | 戦われたのはいつ？             |
| 条約           | 結ばれたのはいつ？             |
| 会議           | 開かれたのはいつ？             |
| 制度           | 始まったのはいつ？             |
| 政策           | 実施されたのはいつ？            |
| 法律           | 制定されたのはいつ？            |
| 思想・宗教        | 成立したのはいつ？／広がったのはいつ？   |
| 文書・作品        | 発表されたのはいつ？／刊行されたのはいつ？ |
| 運動           | 盛んだったのはいつ？            |

回答の精度は用語ごとに最も適切なものを使用してください。

例：

```text
1789年
前3世紀
16世紀前半
14〜16世紀
前221〜前206年
第二次世界大戦後〜1991年
```

すべてを無理に単年へ変換しないでください。

---

#### 場所に関する質問

場所・地域を問う質問は、用語を頭の中の世界地図に配置したり、活動範囲・広がり・複数地域の関係を理解したりする価値がある場合だけ入れてください。

**用語名や一般常識だけで場所を答えられる場合は、場所質問を作らないでください。**

禁止例：

```text
キューバ革命 → どこで起きた？ → キューバ
明治維新 → どこで起きた？ → 日本
```

このような質問は世界史知識を思い出さなくても答えられ、用語への理解も深めないため不要です。

名称から国・地域を推測できても、より具体的な主戦場、活動範囲、伝播経路、関係地域を学ぶことに意味がある場合は、その内容を問って構いません。ただし、細かい地名を無理に作らず、回答が用語の説明に必要な場合に限ってください。

### 推奨例

| カテゴリ  | 場所質問                |
| ----- | ------------------- |
| 人物    | 主にどこで活動した？          |
| 国家・王朝 | どこ？                 |
| 地域・都市 | どこ？                 |
| 事件・革命 | どこ？                 |
| 戦争    | 主な舞台はどこ？            |
| 条約    | どこで結ばれた？／主にどこに関係する？ |
| 会議    | どこで開かれた？            |
| 制度・政策 | どこで行われた？            |
| 思想・主義 | 主にどこで広がった？          |
| 宗教・宗派 | どこで成立した？／どこへ広がった？   |
| 経済・交易 | どこを結んだ？             |
| 運動    | どこ？                 |

特定の場所を答えさせる意味が薄い場合や、答えが自明な場合は省略してください。場所質問を機械的な必須項目として扱ってはいけません。

世界規模の場合は、

```text
ヨーロッパを中心に世界各地
アメリカとソ連を中心とする世界規模
アジア・アフリカの新興独立国
東地中海・西アジア・エジプト
```

など、歴史的に意味のある範囲を答えにしてください。

---

#### 質問文の作り方

質問は、学習者が用語の説明を自分で組み立てられるように、**短く、広めで、過度に答えを示さない形**にしてください。

### 自明な質問は禁止

質問に答えるためには、必ずその用語についての歴史知識や歴史的理解が必要でなければなりません。

次のいずれかに当てはまる質問は作成しないでください。

* 用語名、読み、別名の中に答えがそのまま含まれている
* 用語名の文字、数字、国名、地名を読み取るだけで答えられる
* 歴史を知らなくても、日本語の意味や一般常識だけでほぼ確実に答えられる
* 答えても用語の説明に新しい情報が加わらない
* 時期・場所・人数・順番などの欄を埋めるためだけに作られている

禁止例：

```text
キューバ革命 → どこで起きた？ → キューバ
明治維新 → どこで起きた？ → 日本
三国同盟 → 何か国の同盟？ → 3か国
第一次世界大戦 → 何回目の世界大戦？ → 1回目
```

これらは一例です。場所に限らず、**答えが自明かどうかをすべての質問で確認**してください。

自明な質問を除いた結果、規定の上限より質問数が少なくなっても構いません。代わりの質問を無理に追加せず、原因・内容・結果・歴史的意義・他の用語との関係など、本当に理解に必要な観点がある場合だけ採用してください。

### 基本的に推奨する質問

```text
何をした？
何が起きた？
なぜ起きた？
何につながった？
どんな制度？
どんな政策？
どんな法律？
どんな考え？
どんな宗教？
何を決めた？
何が書かれている？
```

### 避ける質問

以下は、質問文自体が答えの方向を教えすぎたり、知識を細かく分断したりするため、原則として避けてください。

```text
何を批判した？
何を主張した？
何を発表した？
国内では何をした？
ヨーロッパに何を広げた？
統一後に何をした？
どのように統一を進めた？
なぜ仏教と結び付く？
誰と誰が戦った？
どの条約で終わった？
何で終わった？
どんな制度が重要？
```

これらの内容は、原則として、より広い質問の回答内にまとめてください。

### 例：ルター

悪い質問：

```text
何を発表した？
何を批判した？
何を主張した？
```

良い質問：

```text
何をした？
```

良い回答：

```text
1517年に**九十五か条の論題**を発表して**贖宥状販売**を批判し、**信仰義認**を重視して**宗教改革**の大きなきっかけを作った。
```

### 例：始皇帝

悪い質問：

```text
中国統一後に何をした？
```

良い質問：

```text
何をした？
```

良い回答：

```text
前221年に**中国を初めて統一**し、**郡県制**を全国に広げ、文字・貨幣・度量衡などを統一した。
```

### 例：ナポレオン

悪い質問：

```text
国内では何をした？
ヨーロッパに何を広げた？
```

良い質問：

```text
何をした？
```

良い回答：

```text
フランス革命後に皇帝となり、**ナポレオン法典**などを整備しながらヨーロッパ各地を征服し、革命後の近代的制度を広げた。
```

### 例：戦争

悪い質問：

```text
誰と誰が戦った？
何で終わった？
```

良い質問：

```text
何が起きた？
```

良い回答：

```text
神聖ローマ帝国内の宗教対立から始まり、デンマーク・スウェーデン・フランスなどが介入する国際戦争へ発展し、**ウェストファリア条約**で終結した。
```

参戦国、重要人物、終結条約は、意味のある説明の中に含めてください。

---

#### 広すぎる質問も避ける

質問文を曖昧にしすぎてもいけません。

以下のような質問は、何を答えればよいか分からないため避けてください。

```text
どんな人物だった？
どんな国家だった？
どんな帝国だった？
何が重要？
詳しく説明して
```

人物・国家・王朝・組織については、基本的に、

```text
何をした？
```

を使用してください。

回答内で、成立、重要人物、制度、領域、文化、影響などの核心をまとめてください。

ただし、一つの回答が長くなりすぎる場合は、意味のある論点に分けて構いません。

その場合も最大4問までとしてください。

---

#### 一問一答化を避ける

時期や場所の回答は、短い年号・地域名で構いません。

それ以外の回答は、原則として単語1つだけで終わらせず、**1〜3文程度の短い説明文**にしてください。

悪い例：

```text
茶法
```

良い例：

```text
イギリスが**東インド会社**に北米植民地への茶の直接販売を認め、茶を安く販売できるようにする一方、茶への税は残した法律。
```

悪い例：

```text
南京条約
```

良い例：

```text
イギリスが清に勝利し、清に**南京条約**を結ばせて、香港割譲や五港開港を認めさせた。
```

回答は模範文を一字一句暗記させるものではありません。

重要なキーワードと因果関係を覚え、自分の言葉で再構成できる文章にしてください。

---

#### 関連重要語をマインドマップ的に含める

その用語を説明するために重要な関連語は、積極的に回答文へ含めてください。

重要語を細かな一問一答としてバラバラに覚えさせるのではなく、用語同士の関係が分かる形にしてください。

### ルター

```text
九十五か条の論題
→ 贖宥状販売の批判
→ 信仰義認
→ 宗教改革
```

### ボストン茶会事件

```text
茶法
→ 東インド会社の優遇
→ ボストン茶会事件
→ アメリカ独立戦争
```

### 三十年戦争

```text
宗教対立
→ 列強の介入
→ 国際戦争化
→ ウェストファリア条約
```

### ビスマルク

```text
鉄血政策
→ プロイセン中心のドイツ統一
→ ドイツ帝国
→ フランス孤立化を軸とする外交
```

回答内には、用語から自然に連想できるようになるべき重要語を含めてください。

ただし、大学受験上の優先度が低い雑学や、説明に不要な細部を詰め込まないでください。

#### 重要キーワードの強調

質問への回答と統合説明では、特に重要なキーワードをMarkdown形式の太字で囲んでください。

例：

```text
1517年に**九十五か条の論題**を発表して**贖宥状販売**を批判し、**宗教改革**のきっかけを作った。
```

強調対象は主に以下です。

* 人物名
* 国家・王朝名
* 事件名
* 戦争名
* 条約・会議名
* 制度・政策・法律名
* 文書・作品名
* 思想・宗教上の核心語
* 因果関係をつなぐ重要語

文章の大部分を太字にしないでください。

各回答について、太字にした重要語を別途キーワード列にも記録してください。

キーワード列ではMarkdown記号を使わず、半角パイプで区切ってください。

例：

```text
九十五か条の論題|贖宥状販売|信仰義認|宗教改革
```

#### 難読語の読み仮名

すべての段階の`answer`では、高校生がその表記を初めて見たとき、正しい読みを自力で推測することが難しい漢字の固有名詞・歴史用語だけに読み仮名を付けてください。`question`に同じ難読語が含まれる場合も、同じ基準で読み仮名を付けてください。

読み仮名は、読み方を教える必要がある語に限定します。用語として重要であること、固有名詞であること、`term`に収録されていることだけを理由に付けてはいけません。

次の順序で判断してください。

1. 語がすべてひらがな・カタカナで書かれている場合は、原則として読み仮名を付けない
2. カタカナと、`王`、`朝`、`帝国`、`戦争`、`教`など読み方が明らかな漢字を組み合わせただけの語にも、原則として付けない
3. 高校生が通常の音読み・訓読みから無理なく読める一般語や基礎用語には付けない
4. 人名・地名・王朝名・称号・制度名のうち、特殊な読み、読みが複数考えられるもの、構成する漢字から全体の読みを推測しにくいものには付ける
5. 中国史・朝鮮史の語は難読語が多いため重点的に確認するが、すべての固有名詞へ一律に付けるという意味ではない。一語ずつ上記の基準で判断する

##### 読み仮名を付けるべき例

次のように、表記だけでは正しい読みを推測しにくい語には読み仮名を付けてください。

```text
冒頓単于(ぼくとつぜんう)
坤輿万国全図(こんよばんこくぜんず)
鄭氏台湾(ていしたいわん)
王安石(おうあんせき)
節度使(せつどし)
```

##### 読み仮名を付けるべきでない例

次のように、表記をそのまま読めるカタカナ語や、読み方が広く知られた一般語・基礎用語には付けないでください。

```text
アテネ
プラトン
ローマ帝国
キリスト教
仏教
```

`アテネ(あてね)`、`プラトン(ぷらとん)`、`ローマ帝国(ろーまていこく)`、`キリスト教(きりすときょう)`、`仏教(ぶっきょう)`のような表記は過剰であり、出力してはいけません。

一文字ずつではなく、複合した固有名詞・歴史用語を一まとまりとして確認してください。たとえば読み仮名が必要な`鄭氏台湾`は、`鄭氏台湾(ていしたいわん)`と記録し、`台湾`だけを見て読み仮名を不要と判断しないでください。

形式は、難読語の初出直後に半角丸括弧でひらがなの読みを続けます。

```text
冒頓単于(ぼくとつぜんう)
坤輿万国全図(こんよばんこくぜんず)
鄭氏台湾(ていしたいわん)
王安石(おうあんせき)の低利融資政策を何という？
```

太字にする語では、用語と読み仮名をまとめて太字にしてください。

```text
**冒頓単于(ぼくとつぜんう)**
```

同じ`question`または同じ`answer`の中で同じ語が複数回出る場合、読み仮名はその欄の最初の1回だけに付けてください。読み方が明らかな語へ機械的に読み仮名を付け、文章を読みにくくしてはいけません。

`question`の読み仮名は、Webアプリが回答前には隠し、回答を表示した時点で初めて見せます。そのため、CSVには省略せず`王安石(おうあんせき)`のように記録してください。

`keywords`と`accepted_answers`には採点・照合用の表記だけを記録し、読み仮名を追加しないでください。

#### 質問の基本構成

多くの用語では、以下の観点を基本としてください。以下の記載順は、出題順を固定するものではありません。

```text
核心となる内容
時期（前後関係の理解に役立ち、答えが自明でない場合）
場所（地理的理解に役立ち、答えが自明でない場合）
必要な場合だけ原因・結果・影響
```

ただし、機械的に4問作らないでください。

### 問題順の決め方

質問はCSVの番号順に表示され、1問ごとに回答を見てから次の質問へ進みます。そのため、**前の質問文や表示済みの回答が、後の質問の答えを先に教えない順番**にしてください。

時期質問を1問目にすると理解しやすい用語は多いですが、すべての用語で時期質問を1問目に固定してはいけません。用語ごとに、次の基準で順番を決めてください。

* 時期や場所を尋ねる質問文に核心内容を書く必要がある場合は、核心質問を先にする
* 前の回答から後の回答の重要部分を推測できる場合は、順番を入れ替えるか質問文を言い換える
* 核心内容を自力で思い出させたい場合は、核心質問より前にその重要語を見せない
* 一般的な流れより、その用語でヒントを生まない流れを優先する

悪い例：

```text
新石器革命
1. 農耕・牧畜が始まり広がったのはいつ？
2. 何が起きた？
```

1問目の質問文が、2問目で思い出すべき「農耕・牧畜」を先に教えています。

改善例：

```text
新石器革命
1. 何が起きた？
2. 農耕・牧畜が始まり広がったのはいつ？
3. 主にどこで始まった？
```

CSVを確定する前に、用語を表示してから各質問と回答を番号順にたどる学習画面を想定し、まだ答えていない後続質問への重大なヒントが出ていないか確認してください。

### 典型例（順番は固定ではない）

人物：

```text
主に活動したのはいつ？
何をした？
必要な場合だけ、主にどこで活動した？
```

国家・王朝：

```text
存在したのはいつ？
何をした？
必要な場合だけ、どこに存在した？
```

事件・革命：

```text
起きたのはいつ？
なぜ起きた？
何が起きた？
必要な場合だけ、主な舞台はどこ？
```

戦争：

```text
戦われたのはいつ？
なぜ起きた？
何が起きた？
必要な場合だけ、主な舞台はどこ？
```

法律：

```text
制定されたのはいつ？
どんな法律？
何につながった？
必要な場合だけ、どこに関係する法律？
```

時期と場所を機械的に追加せず、用語の説明に本当に必要で、歴史知識を使わなければ答えられない質問だけを残してください。典型例の並びもそのまま当てはめず、後続質問へのヒントが生じる場合は順番を変更してください。

### integrated：統合説明

各用語について、すべての分解質問への回答を統合した説明文を作成してください。

これは、

```text
「ルター」について説明せよ。
```

のように突然問われた場合の、簡潔な模範回答です。

#### 統合説明の条件

1. 分解質問すべてに答えられれば、自力で再構成できる
2. 統合説明だけに新しい重要情報を追加しない
3. 分解質問の回答を自然につなげて作る
4. 統合説明の回答本文だけで、時期・地域・核心内容が分かる
5. 必要に応じて原因・結果・影響も分かる
6. 原則として1〜3文程度
7. 重要語を太字にする
8. 模範文の丸暗記ではなく、説明の骨格として使える

統合説明は、同じ用語の短答問題と逆一問一答で扱った内容、および添付資料に明記された内容だけで構成してください。読みやすくつなぐための言い換えは可能ですが、新しい人物、年号、地名、制度、原因、結果、評価を加えてはいけません。

すべての統合説明の回答本文には、次の2点を例外なく明記してください。

* いつ：西暦・紀元前の年、年代、世紀、または期間のいずれか
* どこ：国・地域・都市・海域など、その用語を歴史地図上に位置づけられる場所

正確な単年に絞れない場合は、無理に断定せず世紀や期間で示してください。複数地域にまたがる場合は、中心地域と広がりが分かるようにしてください。世界規模の事柄は、単に「世界」とせず、中心となった地域や主な範囲も示してください。

時期と場所も添付資料にある表現だけを使ってください。資料にない時期や場所を補って条件を満たしてはいけません。時期と場所を資料内の根拠だけで示せない用語は、統合説明を作る用語として選定しないでください。

`display_period`、`macro_region`、`region_detail`などの別の列へ記録するだけでは不十分です。学習者が統合説明だけを読んでも「いつ・どこで」の話か分かるように、統合説明の本文自体へ自然な文章として含めてください。

統合問題は、答え方を誘導しすぎないようにしてください。

```text
「用語名」について説明せよ。
```

という形式を使用してください。

#### 統合説明の例

```text
用語：ルター

問題：「ルター」について説明せよ。

回答：16世紀前半のドイツで活動し、1517年に**九十五か条の論題**を発表して**贖宥状販売**を批判した。**信仰義認**を重視し、**宗教改革**の大きなきっかけを作った。

キーワード：九十五か条の論題|贖宥状販売|信仰義認|宗教改革
```

### 年号の語呂合わせ

`year_mnemonic`へ記録できるのは、添付されたMDファイルに、対象と同じ年・同じ出来事の語呂合わせが明記されている場合だけです。添付資料に掲載がない場合は、`question_type=time`や単一年を答える問題であっても必ず空欄にしてください。

外部の語呂合わせサイト、一般に知られた語呂、モデルが持つ知識は使用しないでください。添付資料にない語呂を作ったり、別の出来事の語呂を流用したり、覚えやすくするために言い換えたりしてはいけません。

太字記号`**`を除いた`answer`に年号や期間がある問題では、添付資料内に同じ対象年と同じ出来事の語呂があるか確認してください。年が同じでも出来事が異なる場合は使用できません。

記録形式は次のとおりです。

```text
<対象年>：「<添付資料に掲載された語呂本文>」<出来事名>
```

一つの問題に異なる対象年の掲載語呂が複数ある場合だけ、半角パイプで区切ってください。同じ年・同じ出来事に複数の語呂が掲載されている場合は、資料内で中心的に扱われているものを1件だけ使用してください。

同じ`term_id`で、太字記号`**`を除いた`answer`が同じ問題行には、文字単位で同じ`year_mnemonic`を記録してください。その用語の`integrated`行にも、その用語で採用した掲載語呂だけを、問題行と同じ表現で重複なく記録してください。

問題文に年号が手掛かりとして書かれているだけで、`answer`の暗記対象ではない場合は記録しません。

## 4．情報源

添付されたMDファイルだけを、用語選定と問題・回答作成の情報源として使用してください。

次の情報を、外部のWebサイト、モデルが持つ一般知識、添付されていない資料から補ってはいけません。

```text
問題の正答
正答を一意にするための条件
人物・国家・地域・時期
原因・経過・結果・影響
制度・政策・宗教・思想の内容
用語間の関係
統合説明に含める事実や評価
```

添付資料同士で記述が矛盾している場合、資料だけでは意味が確定しない場合、誤記の疑いがある場合は、外部情報で黙って補正せず、その内容を問題にしないでください。

問題文と回答文は、資料の文章をそのまま貼り付けず、意味と因果関係を変えない範囲で、大学受験用に簡潔な表現へ書き直してください。要約によって資料にない断定や評価を加えてはいけません。

`reading`、`category`、`era`、`macro_region`、`region_detail`、`sort_year`など、アプリ内の整理に必要な項目は整えて構いません。ただし、整理のために補った情報を問題文、回答文、`keywords`、`accepted_answers`へ追加してはいけません。

`source_name`には、その用語の中心的な根拠となった添付ファイル名と、資料内にページ表記がある場合はページ番号を記録してください。

```text
01_islamic_world_formation.md p.317
```

`source_url`には、依頼文で各添付資料に割り当てられたHTTPS形式の出典URLを記録してください。URLを検索や推測で作ってはいけません。出典URLが依頼文にない場合は、CSVを作る前に依頼者へ確認してください。

同じ用語のすべての問題行で、`source_name`と`source_url`を一致させてください。複数の添付資料にまたがる場合は、その用語の説明の中心となる資料を一つ選んでください。

## 5．CSVの列

次の順番で列を作成してください。

```text
dataset_label
term_id
importance_rank
difficulty_label
category
term
reading
aliases
era
macro_region
region_detail
display_period
sort_year
question_id
stage
focus
question_type
question
answer
keywords
accepted_answers
answer_note
year_mnemonic

```

### 1行の単位

1行を1問として扱います。

同じ用語に複数の問題がある場合は、用語情報を各行へ繰り返して記録してください。

これにより、各用語の問題数を固定せずに増減できます。

### term_id

用語ごとの一意なIDです。

```text
WH-000001
WH-000002
```

同じ用語に属するすべての問題行で、同じ`term_id`を使用してください。

### question_id

問題ごとの一意なIDです。

```text
短答問題       WH-000001-B01
逆一問一答     WH-000001-R01
統合説明       WH-000001-I01
```

### focus

その問題で主に確認する観点を、短い日本語で記録してください。

例：

```text
用語の特定
時期
中心人物
対立国
地域
原因
内容
結果
関連
複合説明
統合説明
```

### question_type

次から最も適切なものを使用してください。

```text
identify
time
place
person
actor
cause
content
result
relation
reverse
integrated
```

### answer

`beginner`では短い標準回答、`reverse`と`integrated`では模範となる説明文を記録してください。

`reverse`と`integrated`の回答では、特に重要な用語をMarkdown形式の`**太字**`で囲んでください。

すべての段階の回答と問題文では、難読語に`用語(よみ)`の形式で読み仮名を付けてください。問題文の読み仮名は回答表示時だけWebアプリに表示されます。

### keywords

回答に含まれる重要語を、Markdown記号を付けずに半角パイプで区切ってください。

```text
シュレージエン|プロイセン|オーストリア
```

### accepted_answers

短答問題で認める別名、異表記、逆順などを記録してください。

複数ある場合は半角パイプで区切り、ない場合は空欄にしてください。

```text
オーストリアとプロイセン|プロイセン・オーストリア
```

### answer_note

回答の右隣へ小さく表示する、読み上げ対象外の短い補足です。

必要な場合だけ1文程度で記録し、不要なら空欄にしてください。

### year_mnemonic

太字記号`**`を除いた`answer`に含まれる対象年と出来事について、添付されたMDファイルに同じ組合せの語呂合わせが掲載されている場合だけ記録してください。掲載がなければ空欄にします。同じ用語の`integrated`行には、その用語で採用した掲載語呂だけを問題行と同じ表現で記録します。

```text
<対象年>：「<添付資料に掲載された語呂本文>」<出来事名>
```

異なる対象年の掲載語呂が複数ある場合だけ半角パイプで区切ってください。添付資料にない語呂は空欄にし、外部の語呂を調べたり独自に作ったりしてはいけません。

### aliases

用語の別名、旧称、異表記です。

複数ある場合は半角パイプで区切り、ない場合は空欄にしてください。

### reading

ひらがなで正確に記録してください。

### display_period・sort_year

`display_period`は学習者向けの自然な年代表現です。

```text
前3世紀
1756〜1763年
18世紀末〜19世紀初頭
```

`sort_year`は年代順に並べるための代表年を整数で記録してください。

紀元前は負の整数にしてください。

### category

次から最も適切なものを使用してください。

```text
人物
国家・王朝
地域・都市
事件・革命
戦争
条約・会議
制度・政策・法律
思想・主義
宗教・宗派
民族・身分・社会集団
組織・政党
文化・技術・学問
経済・交易
文書・作品
時代・歴史区分
運動
```

## 6．CSVの技術的条件

1. 文字コードはUTF-8とする
2. ファイル生成が可能な場合はUTF-8 BOM付きにする
3. 1セル内に改行を入れない
4. カンマを含むセルはダブルクォートで囲む
5. セル内のダブルクォートは`""`としてエスケープする
6. Markdown表として出力しない
7. `reverse`と`integrated`の回答では重要語を`**太字**`にする
8. すべての`answer`で難読語に読み仮名を付け、`question`内の難読語にも回答表示後に見せる読み仮名を付ける
9. `keywords`ではMarkdown記号や読み仮名を使用しない
10. `year_mnemonic`は添付されたMDファイルに同じ年・同じ出来事の掲載がある場合だけ記録し、添付資料にない語呂を外部から追加したり独自作成したりしない
11. 同じ`question_id`を重複させない
12. 同じ用語のすべての行で、用語情報を一致させる
13. `sort_year`の古い用語から順に並べる
14. 同じ用語内では`beginner`、`reverse`、`integrated`の順に並べる

## 7．出力前の確認

出力前に、次を確認してください。

* 添付されたすべてのMDファイルを最後まで確認したか
* すべての問題について、正答の根拠となる記述を添付資料内で特定できるか
* 添付資料を十分に習得した学習者なら、資料内の知識だけで正答できるか
* 添付資料を十分に習得していても、資料外の知識がなければ答えられない問題が一つもないか
* 添付されていない原書、画像、別章、外部サイト、一般的な世界史知識を前提にした問題がないか
* 問題文、回答文、`keywords`、`accepted_answers`に、添付資料にない学習内容を追加していないか
* 重複しない用語数が指定件数と一致しているか
* 異なる用語同士で、用語IDや重要度順位が重複していないか
* 同義語や別表記で用語数を水増ししていないか
* 各用語に短答、逆一問一答、統合説明があるか
* 短答問題の答えが一つの知識に収まっているか
* 短答問題が複数の角度を扱っているか
* 全短答問題をCSVの並びから切り離して無作為に並べ、`question`以外の列を隠しても、一文だけで対象と正答が一意に分かるか
* `beginner`のうち`question_type=identify`以外の全行で、`question`にその行の`term`が表記どおり含まれているか
* 自明な質問、曖昧な質問、細かすぎる雑学がないか
* 逆一問一答と統合説明が、短答で学んだ知識を自然につないでいるか
* すべての統合説明の本文に、西暦・紀元前の年または世紀などの時期と、国・地域・都市などの場所が両方とも明記されているか
* 問題文と答えが添付資料の記述と一致しているか
* `year_mnemonic`が空欄でない全行について、添付資料に同じ年・同じ出来事の語呂が実際に掲載されているか
* 添付資料にない語呂や、ChatGPTが独自作成した語呂が一つも含まれていないか
* 同じ`term_id`で、太字記号を除いた`answer`が同じ問題行の`year_mnemonic`が文字単位で一致しているか
* 各用語の`integrated`行に、その用語で採用した掲載語呂が言い換えなし・重複なしで含まれているか
* 問題文に手掛かりとして年号があるだけの問題や、数字を含まない時期だけを扱う問題に、不要な`year_mnemonic`を付けていないか
* 各用語の`source_name`と`source_url`が、その用語のすべての行で一致しているか
* `source_url`が依頼文で指定されたHTTPS形式のURLであり、検索や推測で作ったURLではないか
* 難読語の読みが正しく、問題文・回答の必要な箇所だけに付いているか
* 中国史・朝鮮史を中心に、人物名・地名・王朝名・称号・制度名・複合した固有名詞を`question`と`answer`の全行で検索し、上記の基準で読み仮名が必要な語に漏れがないか
* 固有名詞や重要語であることだけを理由に、読み仮名を一律に付けていないか
* `アテネ(あてね)`や`仏教(ぶっきょう)`のように、カタカナ語や読み方が明らかな一般語・基礎用語へ不要な読み仮名を付けていないか
* `鄭氏台湾(ていしたいわん)`のように読み仮名が必要な複合語では、語の一部だけでなく複合語全体の読みを確認したか
* 同じ`question`または同じ`answer`の中で、同じ語へ読み仮名を繰り返し付けていないか
* CSVとして正しく読み込めるか
* すべての行の列数がヘッダーと一致しているか

不備がある場合は、該当する行だけを直してから出力してください。

## 8．最終出力

ファイル生成機能が使用できる場合は、完成したCSVファイルを作成してください。

ファイル名は、データセット名と用語数が分かるものにしてください。

例：

```text
world_history_university_essential_300_terms.csv
```

ファイル生成機能がない場合は、CSV全体を1つの`csv`コードブロック内に出力してください。

CSV以外の前置き、作業報告、選定理由、注意書き、要約は出力しないでください。
