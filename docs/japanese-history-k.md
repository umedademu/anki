# 日本史K

日本史の原文に沿って小項目ごとに学ぶ科目。第5章「近代」の第1節「欧米の近代化と日本」全６小項目と第2節「明治時代」全16小項目と第3節「大正時代」の先頭２小項目、第6章「現代」全15小項目を、152学習項目・1262問で収録する。基礎777問、逆向きの説明333問、統合説明152問からなり、世界史と同じ仕組みで習熟度に応じて段階が進む。第5章は24小項目を収録し、残りは20小項目。第6章は完成済み。

## 出題範囲と基準

- 第5章第2節の第13～16小項目と第3節の先頭２小項目は328～340頁の当該本文・関連注記・図表・文献史料を根拠にする。南満州鉄道、関税自主権の完全回復、工場法、女子教育、護憲運動などの関連記述も確認し、講和と国内外の反応、韓国併合と独立運動、中国の革命、産業・貿易と生活の変化、第一次世界大戦と対華要求を学ぶ。同章年表は同じ出来事の時期だけに限って補う。支配や戦争の正当化、民族・技術・人物への賛美、関係者全体の合意という断定、細かな数値、元号と西暦が食い違う国民党成立年、原文外の事件の日付や制度の細部は正答にしない。日本銀行の設立を日清戦争の賠償金の結果とせず、工場法の制定と施行・効果を区別し、足尾鉱毒事件の年表年を公害の発生年とは扱わない。
- 第5章第2節の第７～12小項目は307～327頁の当該本文・関連注記・図表・文献史料を根拠にする。教育勅語や義和団事件などの関連コラム・注記も確認し、帝国憲法と議会の制度、条約改正の経緯、朝鮮をめぐる日清の対立、三国干渉と列強の権益、日英同盟、日露戦争の経過・戦費・非戦論を学ぶ。同章の年表を補う場合は同じ出来事の時期だけに限る。「アジア初の自前の憲法」、教育勅語の徳目の価値評価、国家や戦争の正当化・必然性、戦力や人物への賛美、不確かな軍事史上の断定・二〇三高地占領年、細かな犠牲者数や原文外の条約規定は正答にしない。328頁の南満州鉄道のコラムとポーツマス条約は第13小項目の根拠とする。
- 第5章第2節の先頭６小項目は287～307頁の当該本文・関連注記・図表・文献資料を根拠にする。戊辰戦争と新政府、中央集権化と三大改革、殖産興業と文明開化、文化、外交、自由民権運動を、内容・目的・変化・対立の関係で学ぶ。同じ章の年表は同じ出来事の時期を確認するためだけに使う。文化の時代範囲に限って、290頁の明治改元と336頁の明治時代の終わりを補足根拠にし、個々の作品や人物の活動年を推定しない。日露和親条約の暦対応に疑義のある西暦や、資料中で断定できない科学上の成果・人物の活動年は問わない。領土の正当性、文化の優劣、外交の正当化、細かな人数や金額、現在の事実としての刊行時の現状、資料外の因果や制度の細部は出題しない。
- 第5章の先頭６小項目は271～286頁の当該本文・関連注記・図版説明・文献資料を根拠とする。欧米の市民革命・思想・産業革命・アジア進出と日本の開国を、制度・原因・結果の関係で学ぶ。各小項目の説明量に応じて主題をまとめ、原文にない人物の活動年、条約の細部、別小項目の知識を補わない。人口や被害者数、文化の優劣、原文の政治的評価、疑義のある順序や時期・地域の断定を正答にしない。
- ＧＨＱは原文413～416頁、憲法改正は416～420頁、冷戦は421～426頁、高度経済成長は426～429頁の当該小項目の本文・図版説明・関連注記を範囲とする。五大改革指令は、この小項目に関係する412頁の注記を用いる。同じ第6章の年表は、本文で学ぶ同じ出来事の時期を確認するためだけに用いる。本文と年表で食い違う独立回復の年やＧＮＰ順位は、矛盾する年表行を根拠にしない。独立回復は本文の「翌年四月二十八日」から1952年と確認する。ＧＮＰ順位そのものは出題しない。
- 続く６小項目は429～440頁の当該本文と関連注記・図表を根拠にする。章末年表は同じ出来事の時期確認だけに用いる。戦後文化は放送と主要な受賞、外交は条約・国交と返還、平成初期は民主化・冷戦終結・戦争や紛争・日本の国際支援を中心にする。原文の価値判断や推計被害者数、疑義のある地名・代表権変更・過度に単純化された因果は正答にしない。マルタ島沖の会談は原文表記の「冷戦終結」として扱い、資料にない名称を要求しない。
- 最後の５小項目は440～450頁の当該本文と関連注記・図版を根拠にする。平成期の政権交代・日朝会談、国際協調の制度、震災と延期、経済の変化、退位と改元を中心にする。領土の正当性、政治的評価、今後の予測、書籍刊行時の現状を現在の事実とする問い、原文中で食い違う時期、原文にない災害や式典の細部は出題しない。
- 原文を読んで覚えていれば答えられる問いと解答に限定する。原文にない法律の具体的な条文、指令の発出年月、人物の追加知識は補わない。
- 一問だけを取り出しても、対象の国、時代、制度や出来事が分かる問題文にする。章名、用語の補助欄、前の問題を読んでいる前提にしない。
- 問題文に「原文では」「この章で」「前述」などを用いない。資料から判断させる場合は、判断に必要な引用を問題文内に示す。原文の掲載ページと出典は解説に表示する。
- 名称から答えを推測できる問い、同じ知識を言い換えるだけの問い、細かい数値の暗記を減らす。資料量に応じて関連する用語を同じ学習項目へまとめ、改革の内容・目的・結果・制度の関係を学ぶ。
- 基礎は原則として一つの知識を短く答える。逆向きの説明は、用語から内容や変化を自力で説明する。統合説明は「戦後日本の『用語名』について説明せよ。」など、必要な時代・地域と項目名だけを示す形にし、答える要素を問題文へ列挙しない。
- 統合説明の回答は1～3文とし、時期と対象の国・地域を回答本文に明記する。同じ項目の基礎・逆向きの説明で学んだ内容を結び付け、統合説明で初めて重要な知識を要求しない。

回答の重要語は太字にし、重要語の一覧にも記録する。読みが難しい用語には必要に応じて読みを添える。基礎と逆向きの説明では、個別の補足がある場合を除き、その問の原文根拠を表示し、単元全体の説明を先に見せない。統合説明では学習項目全体の説明と、その問の根拠を表示する。

## 習熟度に応じた出題

開始画面の初期設定は「習熟度に応じて自動」。未学習では基礎のみを出題し、各学習項目の基礎問題を習得すると、その項目の逆向きの説明へ進む。項目内のすべての逆向きの説明を習得してから、統合説明へ進む。ほかの学習項目は自身の習熟度に従う。世界史の共通処理を利用し、正解・難しいの連続評価2回、または簡単の評価で問題を習得したと判定する。復習予定も既存の評価・間隔設定を使う。

未学習の場合、39小項目をすべて選んだ初期設定の1139問に対して最初の出題対象は基礎654問。「すべて選択」の1262問では最初の対象は基礎777問となる。収録数は説明問題も含めた数であり、初回に一斉に出題する数ではない。段階や問題種類を手動で絞った場合は、その選択に従う。「一項目につき一問」も世界史と同じ方式で利用できる。時期問題を除いた設定でも、統合で必要な年は基礎の内容説明または逆向きの説明で既出にする。

世界史SOと同じく、章を選び、その章に属する小項目の問題集を選択する。日本史Kでは、基礎・逆向きの説明・統合説明のすべてで、上部の大きな用語名・読み・段階名を置く枠を表示しない。回答表示後も同じ扱いとする。どの問題文も単独で意味が分かるため、問題文から学習し、回答と解説をその下で確認する。暗記・聞き流し、4段階評価、復習、途中再開は既存の仕組みを使う。日本史と世界史SOとは別の学習履歴を持つ。解説下の長い時期表示も、画面幅に応じて折り返す。

`node scripts/test-japanese-history-k.mjs`で既存ＧＨＱの76問と段階移行を検査する。`npm run test:japanese-history-k:additions`でＧＨＱ以外の38小項目の原文根拠、全項目の段階移行、既存問題・履歴版の保持、登録済み編集の拒否、条件付き切替を検査する。`npm run test:japanese-history-k:browser`で全39小項目の選択・出題・回答・統合説明・保存再開、ＧＨＱの自動移行、上部の用語枠非表示、重要語の太字と狭い画面を確認する。ブラウザー試験は開始前に自動読み上げをOFFにし、音声再生を遮断する。

手元確認用の全科目生成と検査にも日本史Kの全39小項目を含め、世界史SOは追加章を含む全原稿と照合する。試験用の生成は`npm run build:data`、一式の検査は`npm run check`で行う。本番追加には手元の生成結果を代用せず、次の専用処理でCloudflare上の現行問題集へ反映する。

## Cloudflareへの反映

確認は`npm run preview:data:japanese-history-k`、登録は`npm run publish:data:japanese-history-k`で行う。本番の読み書きはCloudflare経由とし、手元の`public/data`は本番の代用にしない。手元の問題原稿は新規問題の作成用とする。

小項目の追加では、Cloudflare上の現行日本史Kの全索引・分割データを取得し、既存の問題集情報・問題・履歴版・科目設定を保持する。新規小項目の原稿だけを生成し、未使用の保存先へ登録・全文照合した後、取得時の全体索引の版を条件に一括で追加する。確認後の既存問題変更や同時編集を検知した場合は中止する。追加済みの小項目は一致確認だけを行い、登録後の本文編集を上書きしない。

追加登録の設定はUTF-8で4000バイト以内ずつに分割してCloudflareへ渡し、保存窓口で復元する。科目や問題集が増えても、一つの設定値の大きさが上限を超えないようにする。

保存窓口は新規の確認済みデータだけを書き込み可能とし、既存データは参照のみとする。切替前の索引をCloudflareに復旧用として残し、処理後に窓口を削除する。他科目・画像・音声・D1の学習記録は変更しない。

ＧＨＱの76問は問題番号`JHK3-...`と履歴版`japanese-history-k-book-06-01-01-v3`を維持する。既存の第6章14小項目は`JHK-06-01-02...`等の問題番号とそれぞれの履歴版v1を保持する。既存の第5章第1節６小項目は`JHK-05-01-01...`等の番号とそれぞれの履歴版v1を保持する。既存の第5章第2節先頭６小項目は`JHK-05-02-01...`等の問題番号とそれぞれの履歴版v1を保持する。既存の第７～12小項目は`JHK-05-02-07...`等の問題番号と履歴版v1を保持する。新規の第13～16小項目と第3節の先頭２小項目は`JHK-05-02-13...`・`JHK-05-03-01...`等の未使用の番号とそれぞれの履歴版v1で開始する。追加に伴って既存33小項目の学習を初期化しない。表記や解説だけの更新では履歴版を維持する。
