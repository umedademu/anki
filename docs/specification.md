# 三段階世界史学習アプリ 仕様書

## 概要

このアプリは、世界史用語を次の三段階で学ぶWebアプリです。

1. 普通の一問一答で、用語に関する個別知識を短く答える
2. 用語名を見て、複数の知識をつないで答える
3. 用語全体を一つの説明としてまとめる

最初から長い説明を求めず、短い答えを複数の角度から習得してから、逆一問一答と統合説明へ進むことを目的とします。

## 提供形態

- パソコンやスマートフォンのブラウザーで利用するWebアプリ
- WebアプリはVercelの`https://anki-ume.vercel.app`で公開する
- 本番の学習データはCloudflare R2の`anki-world-history`から読み込む
- Cloudflareの公開URLは`https://pub-76ffbe2829114a5cbaa433db45872267.r2.dev`とする
- CORSは本番WebアプリのURLからの`GET`と`HEAD`だけを許可する
- `public/data`は手元確認とCloudflare登録用にだけ使用する

## 現在の問題集

- データセット名：大学受験世界史・通史骨格55用語（全300問）
- 用語数：55語
- 総問題数：300問
- 基礎 一問一答：165問（全用語3問ずつ）
- 逆一問一答：80問（用語ごとに1問または2問）
- 統合説明：55問（全用語1問ずつ）

旧「大学受験・最重要」100用語・333問は、元CSVと公開用データの両方から撤廃しています。

## 三段階の出題

### 基礎 一問一答

- 普通の一問一答として問題文だけを表示する
- 回答前は関連する用語名、読み、年代、地域を表示しない
- 答えは、原則として一つの用語・人名・地名・年号などの短答
- 回答表示後に、関連用語、読み、別解、用語ごとの習得状況を表示する
- 同じ用語の基礎問題をすべて習得すると、その用語の逆一問一答を解放する

### 逆一問一答

- 用語名を表示してから「何が起きた？」「何をした？」などの問いを出す
- 時期、場所、原因、内容、結果などをつないだ説明を回答例として表示する
- 同じ用語の逆一問一答をすべて習得すると、その用語の統合説明を解放する

### 統合説明

- 用語名と「〇〇について説明せよ」という問いを表示する
- 基礎と逆一問一答で学んだ要素をまとめた回答例を表示する
- 統合説明を習得すると、その用語を完全習得とする

## 習得の判定

- 答えを表示したあと、利用者が「まだ」または「覚えた」を選ぶ
- 同じ問題で「覚えた」を2回連続で選ぶと、その問題を習得済みにする
- 「まだ」を選ぶと、その問題の連続回数を0へ戻す
- 未習得の問題は、数問の間隔を空けて再出題する
- 問題単位の習得を集計し、用語ごとの現在段階を決める
- 習得済み問題数と完全習得済み用語数を画面上部へ表示する
- 回答表示後に、その用語の「基礎・逆一問一答・統合説明」の習得数を表示する

## 学習記録

- 問題ごとの連続成功回数、回答回数、「覚えた」の選択回数をブラウザー内へ保存する
- ページを閉じたり再読込したりしても、同じ問題集の記録を引き継ぐ
- 問題集の内容が変わった場合は、データの版が変わるため旧記録と混在しない
- 「記録を初期化」から、現在の問題集の記録だけを消せる
- 利用者情報や外部の記録用サーバーは使用しない

## 出題順

- 各用語について、現在解放されている一つの段階だけを出題対象にする
- 初回は55語の基礎問題165問だけが対象となる
- 通常時は、同じ角度の問題が用語順に並ぶよう、問題番号ごとに用語を巡回する
- 問題を習得しても、同じ用語のほかの問題が未習得なら現在段階を続ける
- 一段階をすべて習得した用語だけ、次段階の問題を出題列へ追加する
- シャッフルを有効にすると、現在出題可能な問題の順番を入れ替える
- シャッフルの切替や再読込で、すでに保存した習得記録は失わない

## 画面と操作

- 回答前は「答えを見る」を表示する
- 回答後は「まだ」と「覚えた」を表示する
- キーボードでは、空白またはEnterで答えを表示し、左矢印で「まだ」、右矢印で「覚えた」を選べる
- 高さの低い横向き画面では、画面右半分で答えを表示または「覚えた」、回答後の左半分で「まだ」を選べる
- 縦向きでは、用語・進み具合、問題、回答と習得状況を上から順に表示する
- 大きな横向き画面では、用語・進み具合を左、問題・回答を右へ配置する
- スマートフォンの横向きでは、見出しや余白を縮めて一画面内へ収める
- 回答が長い場合は、表示枠を超えない範囲まで文字を段階的に縮小する

## 元CSV

- 保存場所：`data/source/world-history/world_history_university_core_55_terms_300_questions.csv`
- 文字コード：UTF-8 BOM付き
- 1行を1問として扱う
- 同じ用語の複数行を`term_id`でまとめる
- `stage`の値は`beginner`、`reverse`、`integrated`のいずれかとする
- 問題ごとに一意の`question_id`を持つ
- 同じ用語内では、基礎、逆一問一答、統合説明の順に並べる

### 列構成

元CSVは、問題集生成用プロンプトと同じ次の24列を使用します。

```text
dataset_label
term_id
importance_rank
difficulty_label
category
term
reading
aliases
era
macro_region
region_detail
display_period
sort_year
question_id
stage
focus
question_type
question
answer
keywords
accepted_answers
answer_note
source_name
source_url
```

- `keywords`、`accepted_answers`、`aliases`は、複数値を半角パイプで区切る
- `answer_note`は補足が必要な場合だけ使用する
- 回答内の`**重要語**`は、文字列として直接差し込まず安全な太字要素へ変換する
- 出典名と出典URLは問題ごとに保持する

## Web表示用データ

- `npm run build:data`でCSVからCloudflare登録用データを生成する
- 公開用データ形式は第3版とする
- 300行を55用語へまとめ、各用語内を三段階の問題配列に分ける
- 用語データは50語と5語の2ファイルへ分割する
- 公開用データを作り直す前に、以前の公開用データを削除するため旧用語集は残らない
- 科目情報には総問題数と段階別問題数、習得に必要な連続回数を記録する
- 元CSVと生成後データの問題文、回答、別解、補足、出典まで全件照合する
- 生成した`index.json`と科目情報、2個の分割データを、Cloudflare R2へ同じパスで登録する
- 本番では`public/config.js`に設定したCloudflare公開URLから読み込み、取得に失敗しても`/data`へ切り替えない
- `localhost`と`127.0.0.1`で手元確認するときだけ、明示的に`/data`を使用する

## 自動検査

`npm run check`で次を検査します。

- 画面処理、学習判定処理、変換処理の文法
- 1行1問を用語・段階別にまとめられること
- 短答から逆一問一答、統合説明へ正しく移行すること
- 「まだ」で連続成功回数が戻ること
- 画面で参照する部品がすべて存在すること
- 短答の回答前だけ用語名が非表示になること
- 「まだ」は3問後、「覚えた」1回目は8問後へ重複なく再配置されること
- 学習記録を保存可能な文字列へ変換し、正常な記録と壊れた記録を安全に復元できること
- 本番の読込先がCloudflareで、ローカルデータへの暗黙の切替がないこと
- 55語・300問と段階別件数が元CSVと一致すること
- 生成後の全問題が元CSVと一致すること
- 旧形式の公開用データが残っていないこと
