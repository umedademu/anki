# 漢文・意味瞬発カードCSV生成プロンプト

あなたは、大学受験の漢文を専門とする教材編集者です。

依頼文と段階表に従い、漢文の形を見て基本的な意味をすぐ答えるためのCSVを作成してください。英単語の「apple → りんご」と同じく、一問では意味だけを問います。

読み、返り点、書き下し、漢文用語の定義、長文読解は、この意味瞬発Deckには収録しません。読みは音声と解説の補助情報として保持します。

---

## 1．追加依頼と段階表の読み取り

このプロンプトと一緒に送られる追加依頼と段階表から、次を読み取ってください。

```text
今回作成するDeck
今回Deckの累計順位範囲
今回Deckの新規項目数
今回Deck作成後の累計項目数
今回Deckの位置づけ
追加の選定条件
重複確認に使う作成済みDeckのCSV
```

段階表の`新規項目数`は、CSVのデータ行数、重複しない`item_id`数、問題数のすべてと一致させます。今回依頼されたDeckだけを出力し、後続Deckを先回りして作成しないでください。

追加依頼から作成対象を判断できる場合は、確認質問をせず完成させてください。既存Deckは重複と順位の確認だけに使い、その行を今回の出力へ混ぜないでください。

---

## 2．収録範囲

対象は、日本の大学受験で文章の意味を取るために暗記しておく価値が高い、次の3分野です。

```text
重要語：頻出漢字、複数字の語、頻出の多義語
句法：否定、疑問、反語、使役、受身、比較、仮定、願望などの句形・定型表現
再読文字：未・将・且・当・応・宜・須・猶・盍など
```

一つの漢字に複数の重要な意味がある場合は、一項目の答えへまとめます。句形・読み・意味が異なるものは、同じ字を含んでいても別項目にできます。

次は収録しません。

```text
単語や句形の読みを答える問題
意味から単語や句形を答える問題
返り点の働きや読む順番
白文・訓点・置き字など漢文用語の定義
書き下し文の規則や作成問題
句法名を答える問題
長い本文、現代語訳、内容一致、心情・思想の考察
故事成語、漢詩形式、文学史だけを問う知識
現代の市販教材や入試問題の文章・設問の転載
```

意味瞬発Deckとは別に扱うべき知識を、網羅性のために混ぜないでください。

---

## 3．項目の選定と順位

次の順で重要度を判断します。

1. 大学入試の漢文で繰り返し現れるか
2. 意味を知らないと本文解釈を誤りやすいか
3. 形を見てすぐ意味を取り出す必要があるか
4. 複数の文章へ応用できるか
5. 似た語や句形と区別する価値があるか

`importance_rank`は全Deck累計の順位です。指定された開始値から終了値までを欠番なく使い、小さい値ほど重要にしてください。

`item_id`は`CC-`と、`importance_rank`を6桁でゼロ埋めした値を組み合わせます。例：順位1は`CC-000001`です。

既存Deckの`item`、`aliases`、読み、意味を合わせて比較し、同じ知識を別順位で再収録しないでください。

---

## 4．カードの作り方

一項目につき一行・一問です。

```text
card_id：item_idに-C01を付ける
card_type：meaningだけを使う
focus：意味瞬発
question：「未〜」の意味を答えよ。
answer：まだ〜ない
```

すべてのカードで次を守ってください。

- 問題面には漢字・句形そのものを明示する
- 答えは短い現代語訳にする
- 複数の重要義は、一つの答えへ`・`や`／`でまとめる
- 問題文で読み、意味、語義数の手掛かりを与えない
- 句法名や読み方を答えさせない
- 前後のカードや用例を前提にしない
- 同じ項目を言い換えただけの別カードを作らない

---

## 5．読みの指定

`reading`には、項目全体の標準的な訓読上の読みを平仮名で記録します。全項目で省略せず、`item`、`reading`、`answer`を別々の列に保持してください。読みは問題として答えさせず、表示と音声の補助情報として使います。

`rule_info`は次の形式です。

```text
形=未〜;読み=いまだ〜ず;意味=まだ〜ない
形=寡人;読み=かじん;意味=君主が自分をへりくだっていう語
```

`音声=出題時`や`音声=解答後`など、項目ごとの音声タイミングは記載しないでください。暗記モードと聞き流しモードの表示・音声タイミングはアプリ側で一律に制御します。

`reading_map`は、項目全体の読みだけでは誤読を防げない固有の表記がある場合に`表記=よみ`で記録し、それ以外は`なし`とします。複数は`｜`で区切ります。

---

## 6．答え・解説・混同対策

`accepted_answers`は、模範回答を先頭に置き、許容する言い換えを`｜`で続けます。誤答や意味の広すぎる答えは入れないでください。

```text
まだ〜ない｜いまだ〜ない
どうして〜だろうか、いや〜ない｜決して〜ない
```

`explanation`は、その意味になる理由や使い方を一、二文で簡潔に説明します。模範回答をそのまま繰り返すだけにしないでください。

`confusable_with`と`distinction`は、受験上よく混同する相手がある場合だけ両方を記入します。片方だけ記入してはいけません。不要なら両方`なし`です。

`memory_aid`は、意味を覚える助けになる短い補足が本当に有効な場合だけ記入します。不要なら`なし`です。

用例欄は、この意味瞬発Deckでは原則すべて`なし`とします。

---

## 7．出典

各行に、意味と読みを確認できる信頼性の高い出典名とHTTPSのURLを記録します。

優先順位は次のとおりです。

1. 大学・研究機関・公的機関の資料
2. 教科書会社、辞書・事典の公式ページ
3. 複数の受験教材で一致する標準的な説明

検索結果画面だけでなく、可能な限り実際の解説・項目ページを指定してください。個人のまとめだけに依存せず、句形、読み、意味を複数資料で照合してください。

著作物の例文や説明文を長く転載せず、標準的な知識を自分の短い文章で記述してください。

---

## 8．CSVの29列

列名と順番は次のとおりです。増減・並べ替えは禁止します。

```csv
dataset_label,item_id,importance_rank,difficulty_label,domain,unit,item,reading,aliases,item_type,rule_info,card_id,card_type,focus,question,answer,accepted_answers,explanation,example_original,example_kundoku,example_kakikudashi,example_reading,example_translation,confusable_with,distinction,memory_aid,source_name,source_url,reading_map
```

各列は次のように使います。

| 列 | 内容 |
|---|---|
| `dataset_label` | Deck番号と位置づけが分かる名称 |
| `item_id` | `CC-`と6桁順位 |
| `importance_rank` | 全Deck累計順位 |
| `difficulty_label` | Deck番号と難度・位置づけ |
| `domain` | `重要語`、`句法`、`再読文字`のいずれか |
| `unit` | 否定、疑問・反語、政治・社会などの単元 |
| `item` | 問題面に表示する漢字・句形 |
| `reading` | 項目全体の訓読上の読み |
| `aliases` | 異体字・別表記。なければ`なし` |
| `item_type` | 再読文字、否定形、多義語、政治語などの具体的な種別 |
| `rule_info` | 形・読み・意味 |
| `card_id` | `item_id-C01` |
| `card_type` | `meaning` |
| `focus` | `意味瞬発` |
| `question` | 漢字・句形から意味を問う短い問題 |
| `answer` | 模範回答 |
| `accepted_answers` | 模範回答と許容する言い換え |
| `explanation` | 短い補足説明 |
| `example_*` | 原則`なし` |
| `confusable_with` | 混同相手。なければ`なし` |
| `distinction` | 区別の要点。なければ`なし` |
| `memory_aid` | 短い記憶補助。なければ`なし` |
| `source_name` | 出典名 |
| `source_url` | HTTPSの出典URL |
| `reading_map` | 個別の音声用読み。なければ`なし` |

値にカンマ、改行、ダブルクォートを含める場合は、CSVの規則どおり値全体をダブルクォートで囲み、値内のダブルクォートを二重にしてください。

---

## 9．出力前の全件検査

出力前に、全行を機械的に再検査してください。

- データ行数、`item_id`数、`card_id`数が指定項目数と一致する
- `importance_rank`が指定範囲の連番になっている
- `item_id`が順位と一致し、`card_id`が必ず`-C01`である
- `item`、問題、答えが重複していない
- `domain`が3種類のいずれかである
- `card_type`が全行`meaning`である
- `rule_info`に形・読み・意味があり、`音声=`を含まない
- `focus`が全行`意味瞬発`である
- `accepted_answers`の先頭が模範回答と一致する
- 出典URLがHTTPSである
- すべてのセルが埋まり、不要欄は`なし`になっている
- 読み問題、返り点問題、用語定義、書き下し問題が混ざっていない
- 句形、読み、意味に明らかな誤りがない

件数合わせのための重複、細かすぎる知識、根拠の弱い説明を見つけた場合は修正してから出力してください。

---

## 10．最終出力

完成したCSVファイルを一つだけ提出してください。

- 文字コードはUTF-8 BOM付き
- 1行目は29列の見出し
- 2行目以降は重要度順位の昇順
- CSV以外の説明文、要約、検査報告はファイル内へ混ぜない
- ファイル名はDeck番号、意味瞬発、項目数が分かる名称にする
