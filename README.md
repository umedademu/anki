# Anki

普通の一問一答から始め、用語ごとに「逆一問一答」「統合説明」へ進む、三段階の世界史学習用Webアプリです。

現在のバージョンは`v0.028`です。Web上の変更履歴は`public/changelog.html`で公開します。

## 現在の内容

「大学受験世界史・重要300用語（三段階学習）」の300語・1,770問を収録しています。

- 基礎 一問一答：900問
- 逆一問一答：570問
- 統合説明：300問

最初は短い答えの一問一答だけを出題します。この段階では問題文とは別の用語欄と読みを回答前に表示しません。用語の属性を問う問題など、問題文で対象を指定する必要がある場合は、問題文内に用語名を含みます。

学習を始める前に、大分類の地域、小分類の地域、カテゴリ、問題スタイル、シャッフル、自動読み上げのオン・オフを選べます。問題スタイルは、三段階すべて、通常の一問一答、逆一問一答、統合説明から選択できます。条件を指定しなければ全300語が対象となり、複数の条件を選んだ場合はすべてに一致する用語だけを出題します。

音声は、自然さを優先するAzure音声と、端末内で利用できる日本語音声から選べます。Azure音声は女性4種類、男性3種類から選択でき、端末音声と読み上げ速度を含めて設定ページで試聴・保存できます。音声設定はCloudflareへ保存し、同じアクセスキーを登録した端末間で共有します。共有した端末音声が存在しない端末では、その端末の推奨日本語音声へ自動的に切り替えます。自動読み上げを有効にすると、問題を表示した時点で問題を読み、回答表示後は回答から解説の順に読みます。問題・回答・解説には省スペースの読み上げボタンもあり、それぞれ個別に再生・停止できます。CSVの読み仮名を発音へ利用し、用語の直前にある文章を欠落させない形で、今後追加する問題集にも対応します。

Azure AI Speechの無料枠で文章から動的に生成します。対応する女性声はNanami・Aoi・Mayu・Shiori、男性声はKeita・Daichi・Naokiです。Azureの接続キーはCloudflare Workerの秘密情報としてだけ保存し、ブラウザーやGitへ配りません。同じ文章の生成済み音声は声ごとにR2へ保存して再利用するため、固定MP3を問題集へ事前にひも付ける必要はありません。無料枠超過、通信失敗、生成失敗時には端末音声へ切り替え、学習を止めません。

Anki、更新情報、版番号を含むヘッダーは開始前だけに表示し、学習開始後は問題表示の縦幅を確保するため非表示にします。

スマートフォン横向きでは、Safariによる段落ごとの自動文字拡大を抑えたうえで、回答と統合説明を同じ大きめの文字サイズで表示します。

回答後は、パソコン・スマートフォン縦向き・横向きのすべてで「× 不正解・△ 難しい・○ 正解・◎ 簡単」の4ボタンを横一列に表示します。スマートフォン横向きでは操作用の戻るボタンを表示せず、左半分のタップで一手戻り、右半分のタップで回答表示または「× 不正解」を選びます。

「戻る」は、同じ問題の回答を隠す操作と、前の問題へ戻る操作を一手ずつ行います。4段階評価を越えて戻ると、その評価による習得記録と出題順もCloudflare上を含めて評価前へ戻します。

選択した学習範囲、問題スタイル、シャッフル設定は、学習を開始したあとは変更できません。別の条件で始める場合は、最初の画面を開き直して選択します。

答えを確認したあとに4段階で自己評価します。初期の復習間隔は、不正解1分後、難しい4時間後、正解12時間後、簡単6日後です。難しいまたは正解を2回積み重ねるか、簡単を1回選ぶと、その問題を習得した扱いにします。習得後も問題は消えず、設定した復習時刻に再び出題されます。

同じ用語に属する基礎問題をすべて習得すると逆一問一答をデッキへ追加し、逆一問一答もすべて習得すると統合説明を追加します。後段階の追加後も、基礎を含む解放済みの問題は復習予定に従って出題されます。

学習記録、復習間隔、音声設定、開始前のシャッフルと自動読み上げはCloudflare D1へ保存され、端末をまたいで引き継がれます。利用者登録は行わず、一人用アクセスキーを設定ページで端末に保存します。アクセスキー自体はGitへ記録しません。基礎 一問一答と逆一問一答では、回答に続いてその用語の統合説明を表示します。解説枠の最下部には、年代・大分類・小分類・時代・カテゴリ・学習段階・知識点を小さなハッシュタグ形式で表示し、年代を先頭に置き、音声では読み上げません。回答本文は文字サイズを変えずに太字で表示し、解説中の重要語と見分けやすい色分けも維持します。回答と統合説明では、冒頓単于(ぼくとつぜんう)や鄭氏台湾(ていしたいわん)のような難読語に読み仮名を付けます。複合した固有名詞も一まとまりで全件検査します。問題文に難読語がある場合は回答前には読みを隠し、回答を表示した時点で問題文にも読みを表示します。縦幅を節約するため、回答と統合説明に独立した見出しは付けません。統合説明を読んだだけでは習得には数えません。問題ごとの三段階の習得数欄は表示しません。

## フォルダー構成

- `public`：Web上で公開する学習画面と更新情報ページ
- `public/data`：手元確認とCloudflare登録のためにCSVから生成する分割データ
- `data/source`：科目ごとの元CSV
- `scripts`：元CSVの変換処理と検証処理
- `worker`：Cloudflare D1への学習記録保存と、Azure AI Speechへの安全な接続を行う処理
- `docs`：仕様書、更新情報、問題集生成用プロンプト
- `vercel.json`：Vercelの公開設定

## 学習データを更新する方法

`data/source/world-history`には、現在使用する世界史CSVを1ファイルだけ配置します。そのあと、次の命令でWeb表示用データを作り直して検査します。

```powershell
npm run build:data
npm run check
```

生成後の8ファイルは、Cloudflare R2の`anki-world-history`へ同じフォルダー構成で登録します。本番アプリは次のCloudflare公開URLから学習データを読み込みます。

```text
https://pub-76ffbe2829114a5cbaa433db45872267.r2.dev
```

本番で`public/data`へ暗黙に切り替わる処理はありません。`localhost`または`127.0.0.1`で手元確認するときだけ、`public/data`を`/data`として読み込みます。

## 学習記録のCloudflare保存

学習記録、復習間隔、音声設定、シャッフル、自動読み上げは、Cloudflare D1の`anki-progress`へ、Workerの`anki-progress-api`を通して保存します。同じWorkerがAzure AI Speechへ安全に接続し、生成済み音声をR2の`anki-world-history`内の`/speech-cache`へ保存します。Azureの接続キーはWorkerの秘密情報`AZURE_SPEECH_KEY`、リージョンは`japaneast`として管理します。

```text
https://anki-progress-api.umedademu.workers.dev
```

書き込みにはCloudflare側だけに登録した一人用アクセスキーが必要です。Webアプリでは`/settings.html`を開き、アクセスキーを一度入力して接続します。本番からの通信だけを許可し、アクセスキーはリポジトリや公開用ファイルへ含めません。

## 手元で表示する方法

プロジェクトのフォルダーで次の命令を実行し、ブラウザーで`http://localhost:3000`を開きます。

```powershell
python -m http.server 3000 --directory public
```

## Vercelで公開する方法

Vercelでこの保管場所を取り込み、次の設定を使用します。

- 使用する仕組み：`Other`
- 組み立て命令：空欄
- 公開フォルダー：`public`

公開フォルダーは`vercel.json`にも設定済みです。
