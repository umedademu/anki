# 三段階世界史学習アプリ 仕様書

## 概要

このアプリは、世界史用語を次の三段階で学ぶWebアプリです。

1. 普通の一問一答で、用語に関する個別知識を短く答える
2. 用語名を見て、複数の知識をつないで答える
3. 用語全体を一つの説明としてまとめる

最初から長い説明を求めず、短い答えを複数の角度から習得してから、逆一問一答と統合説明へ進むことを目的とします。

## 提供形態

- 現在のアプリバージョンは`v0.016`とする
- パソコンやスマートフォンのブラウザーで利用するWebアプリ
- WebアプリはVercelの`https://anki-ume.vercel.app`で公開する
- 更新情報は`/changelog.html`で公開する
- 本番の学習データはCloudflare R2の`anki-world-history`から読み込む
- Cloudflareの公開URLは`https://pub-76ffbe2829114a5cbaa433db45872267.r2.dev`とする
- CORSは本番WebアプリのURLからの`GET`と`HEAD`だけを許可する
- `public/data`は手元確認とCloudflare登録用にだけ使用する

## 現在の問題集

- データセット名：大学受験世界史・重要300用語（三段階学習）
- 用語数：300語
- 総問題数：1,770問
- 基礎 一問一答：900問（全用語3問ずつ）
- 逆一問一答：570問（用語ごとに1問または2問）
- 統合説明：300問（全用語1問ずつ）

旧「大学受験・最重要」100用語・333問と「大学受験世界史・通史骨格55用語」55語・300問は、元CSVと公開用データの両方から撤廃しています。

## 学習開始前の条件選択

- 学習データの準備後、問題を表示する前に条件選択画面を表示する
- 大分類の地域、小分類の地域、カテゴリ、問題スタイル、シャッフルのオン・オフを選んでから開始する
- 問題スタイルは、三段階すべて、通常の一問一答、逆一問一答、統合説明から選択する
- 三段階すべてでは従来どおり用語ごとに段階を解放し、個別のスタイルでは前段階の習得状況にかかわらず選んだ問題だけを直接出題する
- 大分類の地域は`macro_region`を「・」で分け、複合地域の用語を各地域から選べるようにする
- 小分類の地域は`region_detail`を使用し、選択した大分類に属する候補だけを表示する
- 大分類を選んでいない間は、小分類の選択欄を無効にする
- カテゴリは`category`の人物、国家・王朝、戦争などを使用する
- 地域とカテゴリを複数指定した場合は、すべての条件に一致する用語だけを出題する
- 条件と問題スタイルに一致する用語数、問題数を開始前に表示する
- 学習範囲、問題スタイル、シャッフルの設定は開始前の画面だけに表示し、学習開始後は変更操作を表示しない
- 別の条件で学習する場合は、最初の画面を開き直して選択する
- 絞り込みを変更しても、同じ問題集の既存の習得記録は引き継ぐ

## 三段階の出題

### 基礎 一問一答

- 普通の一問一答として問題文だけを表示する
- 回答前は、問題文とは別の用語名、読み、年代、地域の欄を表示しない
- 通常の一問一答では、用語名や問題スタイルだけを置く上部枠を表示しない
- 用語の属性を問う問題など、対象の指定が必要な場合は問題文内に用語名を含める
- 答えは、原則として一つの用語・人名・地名・年号などの短答
- 回答表示後に、関連用語、読み、別解、三段階それぞれの習得件数だけを表示する
- 習得件数には、用語名の見出しや現在の連続正解回数に関する案内を付けない
- 同じ用語の基礎問題をすべて習得すると、その用語の逆一問一答を解放する

### 逆一問一答

- 用語名を表示してから「何が起きた？」「何をした？」などの問いを出す
- 時期、場所、原因、内容、結果などをつないだ説明を回答例として表示する
- 同じ用語の逆一問一答をすべて習得すると、その用語の統合説明を解放する

### 統合説明

- 用語名と「〇〇について説明せよ」という問いを表示する
- 基礎と逆一問一答で学んだ要素をまとめた回答例を表示する
- 統合説明を習得すると、その用語を完全習得とする

### 回答後の解説

- 基礎 一問一答と逆一問一答では、答えに続けて同じ用語の統合説明を表示する
- 回答と統合説明には「答え」「解説」などの独立した見出しを表示しない
- 統合説明の問題では、回答との重複を避けるため別の解説欄を表示しない
- 解説の閲覧は接触機会として扱い、統合説明の習得数や連続成功回数には加算しない
- 統合説明段階では、従来どおり回答を見る前に自力で説明する

## 習得の判定

- 答えを表示したあと、利用者が「まだ」または「覚えた」を選ぶ
- 同じ問題で「覚えた」を2回連続で選ぶと、その問題を習得済みにする
- 「まだ」を選ぶと、その問題の連続回数を0へ戻す
- 未習得の問題は、数問の間隔を空けて再出題する
- 問題単位の習得を集計し、用語ごとの現在段階を決める
- 習得済み問題数と完全習得済み用語数を画面上部へ表示する
- 回答表示後に、その用語の「基礎・逆一問一答・統合説明」の習得数を表示する

## 学習記録

- 問題ごとの連続成功回数、回答回数、「覚えた」の選択回数をブラウザー内へ保存する
- ページを閉じたり再読込したりしても、同じ問題集の記録を引き継ぐ
- 問題集の内容が変わった場合は、データの版が変わるため旧記録と混在しない
- 「記録を初期化」から、現在の問題集の記録だけを消せる
- 利用者情報や外部の記録用サーバーは使用しない

## 出題順

- 各用語について、現在解放されている一つの段階だけを出題対象にする
- 初回は300語の基礎問題900問だけが対象となる
- 通常時は、同じ角度の問題が用語順に並ぶよう、問題番号ごとに用語を巡回する
- 問題を習得しても、同じ用語のほかの問題が未習得なら現在段階を続ける
- 一段階をすべて習得した用語だけ、次段階の問題を出題列へ追加する
- シャッフルを有効にすると、現在出題可能な問題の順番を入れ替える
- シャッフルの切替や再読込で、すでに保存した習得記録は失わない

## 画面と操作

- 最初に学習条件を選び、「この条件で開始」を押して学習画面へ進む
- Anki、更新情報、版番号を含むヘッダーは開始前だけに表示する
- 学習開始後と完了画面ではヘッダーを非表示にし、ページ上部の余白も縮める
- パソコンとスマートフォン縦向きでは、回答前に「戻る・進む」を表示する
- パソコンとスマートフォン縦向きでは、回答後に「戻る・まだ・覚えた」を表示する
- 「答えを見る」という名称のボタンは表示しない
- 「戻る」は、回答表示から同じ問題の回答非表示へ戻し、さらに戻すと前の問題へ移る
- 「まだ」「覚えた」を越えて戻る場合は、その評価による連続回数、回答回数、習得数、出題列を評価前へ戻す
- 一手戻しの履歴は学習開始後の現在の回だけで保持し、開始し直した場合は空にする
- 習得数、用語の習得数、この回の残り問題数は、出題番号と分類の行にまとめて表示する
- 学習記録の初期化操作は開始前の条件選択画面だけに表示する
- キーボードでは、左矢印で一手戻り、右矢印で回答表示または「まだ」を選ぶ
- 空白またはEnterは、回答前は回答を表示し、回答後は「覚えた」を選ぶ
- 高さの低い横向き画面では、画面左半分で一手戻り、右半分で回答表示または「まだ」を選ぶ
- 横向き画面では「戻る」「進む」「まだ」のボタンを表示せず、回答後だけ下部に「覚えた」を表示する
- 横向き画面の回答前は操作欄の高さを0にし、問題表示へ縦幅をすべて回す
- 回答表示直後の連続タップで誤って「まだ」にならないよう、右半分の評価受付に短い待ち時間を設ける
- 高さの低い横向き画面では、回答本文と統合説明を同じ大きめの文字サイズで表示する
- 長文に合わせて自動調整する場合も、回答本文と統合説明は15px未満へ縮小しない
- iPhoneのSafariが横向きで段落ごとに文字を自動拡大しないよう、文字サイズの自動調整率を100%へ固定する
- 端末の向きや画面幅にかかわらず、用語・進み具合、問題、回答と習得状況を上から順に表示する
- パソコンを含め、学習画面を左右二列には分けない
- スマートフォンの横向きでは、見出しや余白を縮めて一画面内へ収める
- スマートフォンの横向きでは、上部の用語枠が非表示でも進捗線、問題、回答操作の配置行を固定し、問題欄を潰さない
- 回答が長い場合は、表示枠を超えない範囲まで文字を段階的に縮小する

## 元CSV

- 保存場所：`data/source/world-history/world_history_university_essential_300_terms.csv`
- 文字コード：UTF-8 BOM付き
- 1行を1問として扱う
- 同じ用語の複数行を`term_id`でまとめる
- `stage`の値は`beginner`、`reverse`、`integrated`のいずれかとする
- 問題ごとに一意の`question_id`を持つ
- 同じ用語内では、基礎、逆一問一答、統合説明の順に並べる

### 列構成

元CSVは、問題集生成用プロンプトと同じ次の24列を使用します。

```text
dataset_label
term_id
importance_rank
difficulty_label
category
term
reading
aliases
era
macro_region
region_detail
display_period
sort_year
question_id
stage
focus
question_type
question
answer
keywords
accepted_answers
answer_note
source_name
source_url
```

- `keywords`、`accepted_answers`、`aliases`は、複数値を半角パイプで区切る
- `answer_note`は補足が必要な場合だけ使用する
- 回答内の`**重要語**`は、文字列として直接差し込まず安全な太字要素へ変換する
- 短答・逆一問一答・統合説明の`answer`では、難読語の初出直後に`用語(よみ)`の形式で読み仮名を付ける
- `question`内の難読語にも同じ形式で読み仮名を保持し、回答前は括弧内の読みを隠し、回答表示後に問題文へ表示する
- `keywords`、`accepted_answers`には読み仮名を付けない
- 出典名と出典URLは問題ごとに保持する

## Web表示用データ

- `npm run build:data`でCSVからCloudflare登録用データを生成する
- 公開用データ形式は第3版とする
- 1,770行を300用語へまとめ、各用語内を三段階の問題配列に分ける
- 用語データは50語ずつ6ファイルへ分割する
- 公開用データを作り直す前に、以前の公開用データを削除するため旧用語集は残らない
- 科目情報には総問題数と段階別問題数、習得に必要な連続回数を記録する
- 元CSVと生成後データの問題文、回答、別解、補足、出典まで全件照合する
- 生成した`index.json`と科目情報、6個の分割データを、Cloudflare R2へ同じパスで登録する
- 本番では`public/config.js`に設定したCloudflare公開URLから読み込み、取得に失敗しても`/data`へ切り替えない
- `localhost`と`127.0.0.1`で手元確認するときだけ、明示的に`/data`を使用する

## 自動検査

`npm run check`で次を検査します。

- 画面処理、学習判定処理、変換処理の文法
- 地域、小地域、カテゴリを単独または組み合わせて絞り込めること
- 開始前の条件選択画面、更新情報ページ、版番号が存在すること
- 1行1問を用語・段階別にまとめられること
- 短答から逆一問一答、統合説明へ正しく移行すること
- 基礎と逆一問一答には統合説明を解説として対応付け、統合説明自身には重複表示しないこと
- 「まだ」で連続成功回数が戻ること
- 画面で参照する部品がすべて存在すること
- 短答の回答前だけ、問題文とは別の用語欄と読みが非表示になること
- 「まだ」は3問後、「覚えた」1回目は8問後へ重複なく再配置されること
- 学習記録を保存可能な文字列へ変換し、正常な記録と壊れた記録を安全に復元できること
- 本番の読込先がCloudflareで、ローカルデータへの暗黙の切替がないこと
- 300語・1,770問と段階別件数が元CSVと一致すること
- 生成後の全問題が元CSVと一致すること
- 難読語の読み仮名が問題文と回答に存在し、問題文では回答前だけ隠れること
- キーワード・別解には読み仮名が混入していないこと
- 旧形式の公開用データが残っていないこと
