## 344

### 1　貿易と国際収支

まずは貿易に関する基本用語を覚えてもらおう。

> #### **国際貿易のあり方**
>
> - <span style="color:red">**保護**</span>貿易：国家が<u style="text-decoration-color:red">**輸入を抑える**</u>。／国家が輸出を<ruby>奨励<rt>しょうれい</rt></ruby>する。
>   - **関税障壁**：輸入品に高関税をかける（＝<span style="color:red">**保護関税**</span>）。
>   - <span style="color:red">**非関税障壁**</span>：数量制限、<span style="color:red">**<ruby>為替<rt>かわせ</rt></ruby>制限**</span>　など。
> - <span style="color:red">**自由**</span>貿易：国家からの保護・統制などの<ruby>干渉<rt>かんしょう</rt></ruby>のない貿易。
> - （<span style="color:red">※</span>自由貿易下で成立する国際分業の形）
>   - <span style="color:red">**垂直**</span>的分業➡主に<u style="text-decoration-color:red">**途上国と先進国間**</u>の分業。
>     - **▶一次産品と工業品など**
>   - <span style="color:red">**水平**</span>的分業➡<u style="text-decoration-color:red">**途上国同士や先進国同士**</u>の分業。
>     - **▶一次産品間や工業品間**

## 345

#### ●**国際収支表**…外国とのお金の受け払い。→（受取）：黒字／（支払）：赤字

| 費　目 | 内　容 |
| --- | --- |
| **(a)** <span style="color:red">**経常**</span>**収支** | |
| **貿易・サービス収支** | （貿易収支）：モノの輸出入の差額。<br>（サービス収支）：モノ以外（**輸送費・旅費・保険代・特許使用料**など）。 |
| **第一次所得収支** | 非居住者に支払われる賃金。<br>海外投資で得た収益（**利子・配当**収入も含む）。 |
| **第二次所得収支** | 資本形成（＝建設事業など）以外の移転。<br>（食糧・衣服などの無償援助／国際機関への<ruby>拠出<rt>きょしゅつ</rt></ruby>金／外国人労働者の本国への送金）➡ 見返りなし。<u style="text-decoration-color:red">**あげる・もらう**</u>。 |
| **(b)** <span style="color:red">**資本移転等**</span>**収支** | 資本形成（建設事業など）で「あげる・もらう」（見返りなし）。 |
| **(c)** <span style="color:red">**金融**</span>**収支** | |
| **投資収支** | <u style="text-decoration-color:red">**将来的な見返りを求めての支出**</u>。<br>・（<span style="color:red">**直接投資**</span>）：<u style="text-decoration-color:red">**海外への工場建設**</u>などにかかる費用。<br>・（証券投資）：外国の株や国債購入にかかる費用。<br>・（その他投資）：その他の投資や貸付・借入。 |
| **外貨準備増減** | 国際収支の不均衡の調整用／国内外貨の不足に備える準備金 |
| **金融派生商品** | 「株や為替を“売買する権利”を売買する」等、本来の金融商品から派生した取引での差額。 |
| **(d)** <span style="color:red">**誤差脱漏**</span> | ここまでの収支の誤差。 |

- <span style="color:red">※</span>注意…
  - **金融収支中の費目だけは「**<u style="text-decoration-color:red"><span style="color:red">**黒字と赤字が逆**</span>**になる**</u>**」**。
    - **▶（例）：日本企業が50億円出してタイに工場建設→直接投資で50億円の「黒字」**
  - 「<span style="color:red">**(a) ＋ (b) − (c) ＋ (d) ＝ 0**</span>」になる。

> **【生徒】** 国際収支って何ですか？

**【先生】** 国際収支とは、民間も政府系もすべて含めた、<mark>**外国との間でのお金の受け払い**</mark>だ。基本的には「日本からの<span style="color:red">**支払い＝赤字**</span>／<span style="color:red">**受け取り＝黒字**</span>」と表現する。つまりここでの赤字・黒字は、損得というよりも、「<mark>**お金の向かってゆく方向**</mark>」だね。

> **【生徒】** もうちょっと詳しく教えてください。

**【先生】** 国際収支には「<span style="color:red">**経常収支**</span>」「<span style="color:red">**資本移転等収支**</span>」「<span style="color:red">**金融収支**</span>」「<span style="color:red">**誤差脱漏**</span>」という4つの大きな費目があるんだけど、その中の「経常収支」と「金融収支」の2つは、特に注意が必要だ。

## 346

> **【生徒】** 何に注意するんですか？

**【先生】** まず経常収支で気をつけるべき点は、貿易収支だ。実は日本は、<mark>**1981年から2010年までの間<span style="color:red">30年連続で貿易黒字</span>だった**</mark>んだけど、2008年のリーマン・ショックや2011年の東日本大震災を受けて、2011年からついに<span style="color:red">**貿易収支が赤字**</span>になり、<mark>**その後は黒字と赤字を行き<span style="text-emphasis: filled circle red; -webkit-text-emphasis: filled circle red;">来</span>**</mark>するようになったんだ。

ただし、貿易収支に陰りが出てきたとはいえ、<mark>**プラザ合意での円高をきっかけに「海外への工場移転 → そこからの投資収益」が増え**</mark>、おかげで1986年から今日まで<span style="color:red">**第一次所得収支はずっと黒字**</span>だ。というわけで、経常収支を見る際には、この2点に気をつけてね。

> **【生徒】** なるほど。じゃあ金融収支の方は？

**【先生】** 金融収支の中には「投資収支」「外貨準備増減」「金融派生商品」があるけど、実はこれら<mark>**金融収支に含まれる費目だけは、すべて「<span style="color:red">黒字と赤字が逆になる</span>」**</mark>んだよ。

> **【生徒】** 黒字と赤字が逆？

**【先生】** そう。例えば日本企業が50億円出資してタイに工場を建てたとするでしょ。これ、普通に考えたら「直接投資で50億円の赤字」になるはずなのに、なぜか正解は「<mark>**直接投資で50億円の“黒字”**</mark>」になるんだ。

> **【生徒】** え〜、何でですか？

**【先生】** なぜなら、金融収支は<mark>**「<span style="color:red">資金の流出入</span>」で見るのではなく「資産の増減」で見る**</mark>からだ。つまりこの例の場合なら、「50億円出ていった」ではなく、「50億円分の財産を手に入れた」と考えるわけだね。

> **【生徒】** 他に何か気をつけるべき点はありますか？

**【先生】** うん。実は<span style="color:red">**国際収支は、2014年に大幅に改訂**</span>されたんだ。ずいぶん前の話だからさすがに大丈夫だとは思うけど、もし古い参考書などで勉強した人は間違えないように気をつけて。
