# 日本史K

日本史の原文に沿って小項目ごとに学ぶ科目。第6章「現代」→第1節「昭和時代（戦後）」→「イ ＧＨＱの占領政策」を、16学習項目・94問で収録する。基礎62問、逆向きの説明16問、統合説明16問からなり、世界史と同じ仕組みで習熟度に応じて段階が進む。

## 出題範囲と基準

- 原文413～416頁の本文、図版の説明、関連注記を範囲とする。五大改革指令は、この小項目に関係する412頁の注記を用いる。
- 原文を読んで覚えていれば答えられる問いと解答に限定する。原文にない法律の条文、成立年、人物の追加知識は求めない。
- 一問だけを取り出しても、対象の国、時代、制度や出来事が分かる問題文にする。章名、用語の補助欄、前の問題を読んでいる前提にしない。
- 問題文に「原文では」「この章で」「前述」などを用いない。資料から判断させる場合は、判断に必要な引用を問題文内に示す。原文の掲載ページと出典は解説に表示する。
- 用語の特定だけでなく、主体と対象の区別、改革前後の変化、改革同士の比較、年代順、短い資料からの判断を含める。共通テスト対策として事実の関連付けと資料の読み取りを練習する。
- 基礎は細かい問いに分け、逆向きの説明では用語や制度から特徴を答え、統合説明では複数の事実を結び付ける。どの段階も、答えの根拠を原文の範囲に収める。

各問の解説に、学習する要点と原文のページ・引用を表示する。例えば農地改革では、土地の移動を「不在地主 → 政府 → 小作人」と整理する。義務教育9年は、小学校6年と中学校3年の学制へ結び付ける。労働基準法・労働組合法は、原文に詳しい条文がないため、法律名と労働組合結成との関係を扱う。

## 習熟度に応じた出題

開始画面の初期設定は「習熟度に応じて自動」。未学習では基礎のみを出題し、各学習項目の基礎問題を習得すると、その項目の逆向きの説明へ進む。逆向きの説明を習得すると、統合説明へ進む。他の学習項目は自身の習熟度に従う。世界史の共通処理を利用し、正解・難しいの連続評価2回、または簡単の評価で問題を習得したと判定する。復習予定も既存の評価・間隔設定を使う。

未学習の場合、初期設定の88問に対して最初の出題対象は基礎56問。「すべて選択」の94問では最初の対象は基礎62問となる。88・94は説明問題も含めた収録数であり、初回に一斉に出題する数ではない。段階や問題種類を手動で絞った場合は、その選択に従う。「一項目につき一問」も世界史と同じ方式で利用できる。

世界史SOと同じく、章を選び、その章に属する小項目の問題集を選択する。基礎の問題面では用語名の補助欄を隠し、説明段階では用語を表示する。ただし、どの問題文も補助欄だけに依存しない。暗記・聞き流し、4段階評価、復習、途中再開は既存の仕組みを使う。日本史と世界史SOとは別の学習履歴を持つ。

問題原稿の各問いに固定の番号、学習段階、原文根拠を記録する。新しい問いは未使用の番号を付け、既存の番号を並び順の変更で再割当てしない。生成時に引用が該当ページに存在すること、根拠番号、問題文と番号の重複、各項目の三段階、段階と問題種類の一致を検査する。元資料や別の問題に依存する定型表現も検出する。ページ照合と定型表現の検査だけでは内容の妥当性や独立性を保証できないため、問い・解答も原文と照合して確認する。

`node scripts/test-japanese-history-k.mjs`で原文根拠、94問の構成、自動段階移行、一項目一問、履歴分離、保存の制限を検査する。`npm run test:japanese-history-k:browser`で画面の選択・回答・自動移行・保存・再開と狭い画面を確認する。ブラウザー試験は開始前に自動読み上げをOFFにし、音声再生を遮断する。

## Cloudflareへの反映

確認は`npm run preview:data:japanese-history-k`、登録は`npm run publish:data:japanese-history-k`で行う。本番の読み書きはCloudflare経由とし、手元の`public/data`は本番の代用にしない。手元の問題原稿は新規問題の作成用とする。

今回の改訂では、Cloudflare上の確認済みの旧79問から新94問へ、日本史Kだけを置き換える。旧科目情報の内容識別値を固定し、旧索引と分割データもCloudflareから取得して照合する。新しい分割データと索引を登録・全文照合した後、取得時の全体索引の版を条件に切り替える。旧問題集が確認後に編集されている場合や、全体索引の同時編集がある場合は切替を中止する。他科目の内容・配置・分類・画像・音声・学習記録は維持する。同一内容の登録済みデータは照合だけ行う。

保存窓口は今回の確認済み新データだけの書き込みと旧データの参照を許可し、処理後に削除する。旧問題データと切替前の索引はCloudflareに復旧用として残す。D1の旧学習記録も削除しない。

旧79問は一問ずつ独立した構造だったため、94問への改訂では学習対象の識別番号と履歴版を新しくする。新履歴版は`japanese-history-k-book-06-01-01-v2`。旧履歴版`japanese-history-k-book-06-01-01-v1`の進み方を引き継がず、新しい三段階の学習として開始する。以後、表記や解説だけの更新では新履歴版を維持する。
