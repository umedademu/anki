# 英単語Deck 8

v0.406で、利用者が作成した「東大・最難関大の安全域500語」を英単語のDeck 8へ追加しました。暗記・聞き流し、通常の科目選択と毎日のメニューで、他の英単語デッキと同じ学習方法を使用できます。

- 元原稿：`data/source/english-vocabulary/english_vocabulary_deck8_tokyo_top_university_safety_500.csv`
- 500行の10列形式。単語番号は `EN-003501`〜`EN-004000`、順位は3501〜4000
- 1語から「英語から意味」「意味から英語」「例文から和訳」を各1問ずつ作り、各500問・合計1,500問にする
- 英単語全体はDeck 1〜8の4,000語・12,000問。初期の選択先はDeck 1を保持する
- 新規デッキの履歴版：`english-vocabulary-deck-8-v1`、今回の内容版：`b1b9e930e21a`
- 保存先：Cloudflare R2の `subjects/english-vocabulary/imports/deck-8/b1b9e930e21a/`。50語ずつの分割データ10件と索引1件を登録する

## 点検と補正

500語すべての単語・意味・別解・例文・和訳、必須欄、単語番号・順位の連続、ファイル内の重複を確認しました。既存Deck 1〜7の3,500語はCloudflareから読み、単語・用語番号・問題番号の重複がないことを確認しています。先頭はobjectivity、末尾はreproachです。

`mutagen`（EN-003881）の意味と別解にある「遺伝子変異を引き起こす物質」を「遺伝子変異を引き起こす要因」へ補正しました。例文で扱う紫外線などの物理的な要因も含むためです。[米国立ヒトゲノム研究所の定義](https://www.genome.gov/genetics-glossary/Mutagen)で、化学的・物理的な要因の両方が含まれることを確認しています。別解の「変異原」、英語例文と和訳は保持します。

元原稿との全行・全列の比較で、この1語の意味・別解の2欄だけが異なることを確認しました。他の499行と番号は変更していません。元原稿と同じUTF-8 BOM・LF改行を保ち、端末によって内容版が変わることを防ぎます。Downloads内の元ファイルは変更しません。

- 元ファイルのSHA-256：`f154fcd075a711e53dcb7274c170795862648196b6fd82a9ad200418b1d3a7a0`
- 取り込み原稿のSHA-256：`b1b9e930e21ac43c1f1aec372baf06699d2e4d379b774ec80f30d438652dd916`

## Cloudflareへの追加

`npm run preview:data:english-deck-8`でCloudflare上の現行データを読み、件数と重複を確認します。`npm run publish:data:english-deck-8`で、確認した新規データだけを登録します。

1. Cloudflareの現行索引と既存Deck 1〜7の索引・全分割データを取得して照合値を記録する
2. 一時的なアクセスキーで保護した専用保存窓口を用意し、現行索引が確認時点から変わっていないことを再確認する
3. Deck 8の分割データ10件と索引を登録し、Cloudflareから読み返して全文を照合する
4. 既存データの照合値が一致した場合だけ、現行索引の識別情報を条件に英単語の一覧・件数へDeck 8を追加する
5. 追加後の索引と既存Deck 1〜7を再照合し、作業用保存窓口と一時設定を削除する

既存デッキの本文・番号・履歴版・索引参照先、他科目、画像一覧、音声、D1の学習記録は変更しません。切り替え前の索引はCloudflare上へ復旧用に残します。再実行は登録済み内容が一致する場合だけ何もせず終了し、公開後の本文編集や異なる内容での再登録を拒否します。

## 確認方法

`node scripts/test-english-deck-8.mjs`で全500語・1,500問の原稿照合、三方向の出題と音声内容、補正した意味と別解、段階移行、重複、既存科目の保持、登録失敗・競合・再送・認証を確認します。`npm run check`にも組み込んでいます。

`npm run test:english-deck-8:browser`ではCloudflare上の問題集を読み、8デッキの選択と暗記・聞き流しの三方向を確認します。学習記録の通信だけを試験用の窓口へ送り、利用者の実際の記録を変更しません。自動読み上げは試験開始前にOFFにし、実際の音声は再生しません。本番の接続元制限は保ち、試験用画面へ渡す応答だけを調整します。既存Deck 7も同じ条件で再確認します。

`public/data`に置いた同じデータは手元の検査専用です。本番の単語集の読み込み・保存先には使いません。
