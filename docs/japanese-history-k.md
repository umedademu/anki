# 日本史K

日本史の原文に沿って小項目ごとに学ぶ科目。最初の試作として、第6章「現代」→第1節「昭和時代（戦後）」→「イ ＧＨＱの占領政策」を16学習項目・79問で収録する。

## 出題範囲と基準

- 原文413～416頁の本文、図版の説明、関連注記を範囲とする。五大改革指令は、この小項目に関係する412頁の注記を用いる。
- 原文を読んで覚えていれば答えられる問いと解答に限定する。原文にない法律の条文、成立年、人物の追加知識は求めない。
- 用語の特定だけでなく、主体と対象の区別、改革前後の変化、改革同士の比較、年代順、短い資料からの判断を含める。
- 共通テストに必要な事実の関連付けや資料の読み取りを練習する。形式は既存の一問一答・自己評価であり、試験形式そのものの再現を目的としない。
- 受験上の目的は[大学入試センターの令和9年度問題作成方針](https://www.dnc.ac.jp/albums/abm.php?d=753&f=abm00005361.pdf)の地理歴史に関する方針を参考にした。出題根拠は利用者の原文のみとする。

各問の解説に、学習する要点と原文のページ・引用を表示する。例えば農地改革では、土地の移動を「不在地主 → 政府 → 小作人」と整理する。義務教育9年は、小学校6年と中学校3年の学制へ結び付ける。

問題の種類は、用語14・時期6・場所2・人物2・主体9・原因1・内容15・結果6・関係16・逆向きの説明5・統合説明3。種類を複数選択でき、初期状態では時期6問を除く73問が対象となる。「すべて選択」で79問を学べる。

世界史SOと同じく、章を選び、その章に属する小項目の問題集を選択する。各問は独立して学べ、説明問題も初回から出題する。問題面では用語名の補助欄を隠す。暗記・聞き流し、4段階評価、復習、途中再開は既存の仕組みを使う。日本史と世界史SOとは別の学習履歴を持つ。

79問は79の独立したカードとして保存する。16は元原稿での学習項目数であり、画面の収録数は「79問」とする。

## 原稿と検査

- [問題原稿](../data/source/japanese-history-k/06-01-01.json)
- [原文抜粋](../sources/kokushi/試作/第6章_01_GHQの占領政策_原文抜粋.md)
- [原文目次](../sources/kokushi/目次.md)

問題原稿の各問いに固定の番号と原文根拠を記録する。新しい問いは未使用の番号を付け、既存の番号を並び順の変更で再割当てしない。生成時に引用が該当ページに存在すること、根拠番号、問題文と番号の重複を検査する。ページ照合は引用の存在を保証する検査であり、問い・解答の妥当性も原文を読んで確認する。

`node scripts/test-japanese-history-k.mjs`で原文根拠、出題・評価、章選択、履歴分離、保存の制限を検査する。`npm run test:japanese-history-k:browser`で画面の選択・回答・保存・再開と狭い画面を確認する。ブラウザー試験は開始前に自動読み上げをOFFにし、音声再生を遮断する。

## Cloudflareへの追加

確認は`npm run preview:data:japanese-history-k`、登録は`npm run publish:data:japanese-history-k`で行う。Cloudflareから現行の科目一覧を取得し、新しい分割データと索引を登録・全文照合した後、取得時の版を条件に科目一覧へ追加する。他科目の本文・分類・画像・音声・履歴を変更しない。新科目の履歴版は`japanese-history-k-book-06-01-01-v1`。

保存窓口は今回の確認済み内容だけを許可し、登録後に削除する。同時編集時は索引の切替を中止する。切替前の索引をCloudflareに復旧用として残す。登録済みの科目やデータに違いがあれば再実行で上書きしない。本番の読み書きはCloudflare経由とし、手元の`public/data`は本番の代用にしない。
