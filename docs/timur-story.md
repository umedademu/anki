# ティムールの遠征・実験用の紙芝居

初版：v0.181（2026年9月5日）

人物劇追加：v0.182（2026年9月5日）

地図内の人物画像と移動：v0.183（2026年9月5日）

## 目的と入口

提示されたティムール朝の説明を、地理と出来事の因果関係から理解するためのたたき台。
科目一覧の下の小さなリンクから `/timur-story.html` へ移動する。
既存学習アプリの画面・出題・保存・音声の仕組みから独立しており、科目選択への戻りリンクだけを持つ。

## 操作と表示

- 「次へ」「前へ」、左右矢印キーで一場面ずつ移動。最初の場面では「前へ」を無効にする
- 最終場面のボタンは「最初から」に変わる。右矢印キーだけでは先頭へ循環しない
- 三つの章または13個の場面番号から直接移動できる。現在地は本文・進み具合・場面番号へ反映する
- 「動きをもう一度」は同じ場面の地図と人物の動きを最初から表示する
- 矢印と到達点の輪に加え、人物画像が出発地から遠征先まで移動する。音声や自動の場面送りはない
- 動きを減らす端末設定では静止表示に切り替える
- スマートフォンでは縦配置と場面に合わせた地図の表示範囲を使い、前後ボタンを下端へ追従させる
- 変更後の場面は読み取り支援に通知し、地図にも内容を説明する代替文を付ける
- 進行位置は保存せず、再読み込みすると最初に戻る

## 地図内の人物と移動

地図の下に置いていた人物の舞台は撤去し、既存の地図の中へ人物画像を重ねる。人物は約3頭身の透過PNG。16枚の画像の内容と生成指示は [人物画像の記録](timur-character-images.md) にまとめた。

- 衣装と頭飾りを人物ごとに固定し、平常・笑顔・決意・驚き・落胆・病気の画像を場面に合わせて使う
- 人物の基準位置を地図と共通の緯度・経度で求め、遠征の折れ線に沿ってティムール自身を動かす
- 北方・イラン・デリー・シリアはサマルカンドから出発。コーカサスはイランから、アンカラはバグダード方面から進む
- ダマスクスとバグダードには順番に立ち寄る。到着時に相手の表情を変え、一度立ち止まってから次の町へ向かう。画面にはその時に関係する相手を表示する
- 結婚の場面はサマルカンドで二人が近づいて笑顔になり、ハートを表示する。チンギス＝ハンは地図右上の祖先像で、同時代の対面や所在地を示す印とは区別する
- アンカラではバヤジット1世が落胆した画像に変わり「捕虜」を表示。領地返還では旧支配者が笑顔になる
- 明への計画では二人を接近させない。最後の移動はサマルカンドからオトラルまでに限り、そこで病気の画像へ切り替える
- 最終場面は主要都市と遠征方向を一覧にし、最後の到達点であるオトラルにティムールを置く
- 移動は通常約5秒、二つの町をたどる場面は約7.5秒で終える。画像の読み込み後に開始し、「動きをもう一度」で再表示できる
- 地図の範囲を出発点・経由地・到達点に合わせ、小画面でも人物を収める。名前を読めるよう同じ地点の人物は左右に並べ、都市名は足元の下などへ配置する
- 場面変更・再表示・地図の大きさ変更では前の動きを取り消す。遅れて画像が読み込まれても、前の場面の動きが復活しないようにする
- 端末の動きを減らす設定では、到着位置と最終表情を最初から静止表示する
- 地図内に進行中／到着後の短い説明を表示し、人物群にも代替文を付ける。外見・表情・吹き出しが演出であることはページ下部に明記する

## 地図の範囲と出典

`public/timur-map.svg` は [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/) の公開地図（1:110m、陸地・湖）から、東経20〜125度・北緯10〜58度を切り出した地形概略図。
座標は経度1度を横12、緯度1度を縦15として変換する。投影による距離・面積のゆがみがあり、距離測定には使用しない。
国境は描かない。色は注目地域の位置、矢印は移動の方向を示し、厳密な歴史的国境・領域・行軍路を表さない。
都市の点は緯度経度から置き、広域の支配・一時占領・影響力を本文で区別する。明への矢印は実現しなかった計画として破線で示す。

年次・地名の補助確認：

- [メトロポリタン美術館「ティムール朝の時代」](https://www.metmuseum.org/essays/the-art-of-the-timurid-period-ca-1370-1507)
- [イラン百科事典「オトラル」](https://www.iranicaonline.org/articles/otrar/)

## 編集と確認

- `public/timur-story.html`：ページの構成
- `public/timur-story.css`：専用の見た目・小画面・動きを減らす設定
- `public/timur-story.js`：13場面の本文、都市の座標、注目地域、遠征方向、場面切り替え
- `public/timur-characters.js`：人物画像の選択、地図内での移動、表情切り替え、13場面の人物配置と吹き出し
- `public/images/timur/`：背景が透明な16枚の人物画像
- `public/timur-map.svg`：外部通信なしで表示する地形図
- `scripts/build-timur-map.mjs`：必要な場合だけ地形図を作り直す処理。Natural Earth の公式保管場所から地形図だけを取得する

通常の表示・公開時に地図の再生成は不要。単語集やCloudflareのデータには触れない。
構文・既存機能の確認は `npm run check`、表示確認は無音状態で全13場面の前後移動、場面選択、再表示、最終場面からの再開、狭い画面、動きを減らす設定を対象とする。

### 初版の確認結果

- パソコン幅1280pxとスマートフォン幅390pxで、全13場面の説明・地図・進み具合が一致し、ページが横にはみ出さないことを確認
- 最初の「前へ」の無効化、前後ボタン、左右矢印キー、場面選択、最終場面からの再開、動きの再表示を確認
- 専用ページが音声・動画要素や既存の学習処理を読み込まないことを確認
- 追加処理の構文検査と、音声検査以外の既存検査は通過
- `npm run check` は既存の音声検査 `scripts/test-speech.mjs:502` で停止。変更前の版から音声関係のファイルを別の一時フォルダーへ取り出して実行しても同じ失敗を再現した。音声処理と音声検査の変更は行っていない

### 人物劇追加時の確認結果

- 390px幅で全13場面の人物配置と場面の対応を確認し、横方向のはみ出しがないことを確認。最終場面では三時期のティムールを表示
- 1280px幅で結婚の配置と笑顔への変化、390px幅でアンカラの対決前後の表情と格子の出現、320px幅で最期の場面の配置を確認
- 「動きをもう一度」で表情が変わる前の状態へ戻り、場面番号は変わらないことを確認。最初からの再開と左右矢印キーも確認
- 音声・動画要素を読み込まず、ページに実行時のエラーがないことを確認
- 追加処理の構文検査と、音声以外の既存検査は通過。音声検査は初版と同じ既存の `scripts/test-speech.mjs:502` で停止し、音声処理は今回も変更していない

### 地図内の人物画像と移動の確認結果（v0.183）

- 390px幅で全13場面の人物画像が読み込まれ、地図から人物・名前・吹き出しがはみ出さないことを確認
- 動きを減らす設定を再現した一時的な確認ページで、全13場面が到着位置・最終表情となり、歩く動作が残らないことを確認。確認用ページは公開前に削除
- 通常の表示で北方遠征の出発点と到着点、ダマスクスからバグダードへの移動、オトラルでの停止と病気の画像への切り替えを確認
- 結婚の平常から笑顔への画像変更、左右キーと前後ボタン、移動途中の場面変更、同じ場面の再表示を確認
- 1280px幅と320px幅で人物配置を目視確認し、狭い画面の横方向のはみ出しを修正
- 音声・動画要素は0件。構文検査と既存の全検査（npm run check）は通過。過去の確認で失敗した音声検査も今回は通過し、音声処理の変更は行っていない
