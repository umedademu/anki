# 問題編集画面

## 使い方

各科目の開始画面の「問題を編集」から開きます。アクセスキーは従来の設定ページに登録したものを使用します。オリジナルの貼り付け問題と、音声専用のマインドセットは対象外です。

- 一つのデッキを選んでいた場合はそのデッキを、複数選択していた場合は「学習で選択中のデッキ」を最初に表示します。「すべてのデッキ」で科目全体を検索できます。
- 問題を一行ずつ、所属デッキ・問題文・回答・解説・分類を列として表示します。別画面を開かず、セルを直接編集できます。問題文・回答・用語・解説の検索、分類の絞り込みに対応し、一度に30行を表示します。
- 「行を追加」で表の先頭に空行を追加します。単独表示中のデッキを追加先にし、複数表示中は追加先を選びます。デッキ・問題文・回答がそろうまでは保存せず、入力待ちとして表示します。解説は任意です。
- 「詳細列を表示」で用語・見出し、地域などの分類、問題形式、別の正答、回答の補足、語呂合わせの列を表示します。既存の地図・画像・出典などはそのまま保持します。
- 同じ用語に属する複数問題は用語・分類を共有するため、この部分を変更すると関連する問題にも反映されます。問題文・回答・解説などは選択した問題だけを変更します。
- 所属デッキを変更すると、この一問だけを移動します。用語の番号がデッキ間で重複しないよう、移動先では独立した項目にします。問題番号は変えません。
- 入力を止めて700ミリ秒経過するか、別のセルへ移ると自動保存します。保存ボタンはありません。Tabキーで次のセルへ移動し、セル内で改行も入力できます。日本語の変換中は保存を待機します。
- 保存状況は表の上部にまとめて表示し、行ごとの保存状態列は設けません。保存中も入力でき、後から入力された変更を消さずに順番に保存します。検索・ページ移動をしても未保存の行を保持します。
- 通信に失敗した時は入力内容を残して保存を一時停止します。「保存を再試行」で続けられます。他画面との競合時は入力を控えたうえで再読込します。未保存で画面を離れる場合は保存を試み、保存できなかった場合に確認します。
- 削除前は問題文を表示して確認します。削除後は次の保存まで「削除を元に戻す」を利用できます。他の画面で編集された場合は古い内容で上書きせず、再読込を案内します。
- 表の高さは表示中の行数に合わせて伸び、上下の移動はページ全体のスクロールで行います。横に長い列は行番号を固定したまま表を左右にスクロールできます。スマートフォンでも同じ表で直接編集します。「前へ」「次へ」で表示する30行を切り替えると、表の先頭へ移動します。「開始画面へ戻る」で元の科目の開始設定へ戻ります。

## 保存と学習履歴

読み書きは認証付きの`GET /v1/question-editor?subject=<科目>`と`POST /v1/question-editor`で行います。保存操作は追加・修正・削除・削除の取り消しです。任意の保存先や科目の追加には対応しません。

更新対象のデッキは新しい内容版のフォルダへ200項目ずつ保存します。分割データとデッキ索引をR2から読み返して照合し、最後に全体索引をETagの一致を条件に切り替えます。旧データは残すため、失敗途中のファイルが学習画面から参照されることはありません。内容版のみ更新し、学習履歴版は維持します。削除で空になったデッキにも追加できます。

同じ保存操作の再送は直前の操作番号で判定します。他の保存が確定している場合は競合として扱い、古い入力の自動適用をしません。削除の取り消しはR2に保存した直前の索引を使い、削除後の内容版が一致する場合だけ受け付けます。画像、音声、旧分割データを物理削除する処理はありません。

自動保存は一行ずつ直列に実行し、保存後にCloudflareから取得した内容を未編集のセルへ反映します。セルごとの変更番号を比較することで、送信後の追加入力・元の値への戻しを失わず、同じ用語の分類を別の行の古い値で上書きしないようにします。保存応答が失われた時は同じ操作番号で再送し、保存後の再取得だけが失敗した時は読み直しだけを再試行します。保存後の再取得までの間に他画面の保存があった場合も競合として停止します。

文章の編集・削除はD1の履歴を書き換えません。デッキ移動では問題の識別番号を維持し、元の回答履歴を残して移動先へ複写します。移動先により新しい記録がある場合はそれを保持します。過去の学習時間・日別件数・分類別回答履歴は当時の記録のままです。

別画面で既に開いている学習内容は、その画面を再読込してから新しい問題集へ切り替わります。編集した英単語問題の音声は現在の問題文・回答を使います。

既存CSVから問題集を再生成・置換する運用では、Web上の編集を自動でCSVへ逆反映しません。全体置換前はCloudflareの現行データとの相違を確認し、意図せず編集を消さないようにします。

## 確認方法

`npm run check`で保存処理、履歴の保持、移動、削除と復元、同時更新、再送、認証、英語音声の内容を検証します。

`npm run test:editor:browser`で試験用の架空の問題集を使用して画面操作を確認します。端末にインストール済みのChromeを使用し、必要なら`EDITOR_BROWSER_CHANNEL=msedge`でEdgeへ切り替えます。本番の問題は変更せず、試験開始前から自動読み上げと音声再生を無効化します。画像は`.wrangler/editor-check/`へ保存します。

Cloudflareの条件付き保存の仕様は[公式のR2仕様](https://developers.cloudflare.com/r2/api/workers/workers-api-reference/)を参照。

## 編集画面の行の並び替え（v0.274）

- 現在の行番号列をつまみとして使用し、マウス・タッチ操作で対象行の前後へ移動する。番号列の上下矢印キーでも移動できる。新しい列やボタンは追加しない。
- 行をつまんだまま画面の上下端へ移動するとページ全体が自動スクロールし、表の端で約0.8秒保持すると前後のページへ移る。次のページでは表の先頭、前のページでは表の末尾へ移動する。検索や分類の絞り込み中でも、非表示行の相対順序は維持する。複数デッキの行も移動できるが、所属デッキは変えない。
- 順番は認証付きの既存 `/v1/question-editor` の `reorder` 操作でCloudflare R2の科目一覧の `editorQuestionOrder` へ保存する。編集画面だけの表示順であり、出題順・本文・問題番号・用語構造・所属・履歴版・D1の学習履歴は変更しない。
- 未保存入力・保存処理・エラーがある間は並べ替えを受け付けない。失敗時は保存前の順番を表示し、既存の再試行ボタンから同じ操作番号で再送する。同時編集は全体索引の版で検知する。取り消しキーやタッチ操作の中断では保存しない。
- 追加された問題は保存済みの順番の後ろに表示し、削除された問題の番号は表示時に無視する。端末内やローカル問題集を本番の保存先にしない。

## 学習中の直接編集（v0.275）

- 問題・回答・解説の音声アイコンの隣の鉛筆から、その欄を入力欄へ切り替える。保存・キャンセルが可能。回答と解説の編集は答えを表示した後に使え、解説が空でも追加できる。
- 編集中は音声と聞き流しの進行・学習時計を止め、評価や次の問題への操作を無効にする。保存後も同じ問題を維持し、聞き流しは一時停止のまま利用者が再開する。
- 通常科目は認証付き `/v1/question-editor` から対象問題の最新値と索引版を取得し、`field` 操作で指定された一項目だけをR2へ保存する。同時編集は索引版で検知し、通信失敗時は入力を保持して同じ操作番号で再試行する。問題番号・履歴版・出題待ちの並び・学習履歴は維持する。
- 漢文の意味瞬発の問題面は表示対象の用語・見出しを編集する。解説の明示的な空欄は共通解説へ戻さず、その問題の解説を非表示にする。
- オリジナルは従来の端末保存の例外を維持し、問題本文と内容識別情報だけを更新する。問題番号・履歴版・途中状態は保持し、改行やタブを含む入力は引用符付きのタブ区切りで保存・復元する。Cloudflareへ問題本文は保存しない。
