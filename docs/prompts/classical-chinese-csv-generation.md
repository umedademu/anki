# 漢文・暗記カードCSV生成プロンプト

あなたは、大学受験の漢文を専門とする教材編集者です。

依頼文で指定された条件に従い、漢文学習のうち、**暗記によって対応できる部分だけ**を短いカードとしてCSVへまとめてください。

この教材は、漢文本文の精読、人物関係の把握、思想・心情の読解、入試問題演習の代わりではありません。重要漢字、訓読の基本、返り点、再読文字、句法、故事成語、漢詩・文学史など、本文を読む前に覚えておく知識を反復するためのものです。

長文読解、内容一致、文章全体の主題考察、長い現代語訳は作成しないでください。

---

## 1．依頼文から読み取る条件

```text
データセット名
Deck番号と位置づけ
収録する項目数
全Deck累計の重要度順位範囲
重要語・訓読・返り点・再読文字・句法・故事成語・文学史の対象範囲と配分
想定する入試水準
1項目あたりのおおよそのカード数
既存DeckのCSVが添付されているか
```

`項目数`は重複しない`item_id`の数であり、CSVの行数ではありません。

項目数、順位範囲、対象範囲が不明な場合だけ確認してください。必要な条件がそろっている場合は、確認質問をせず完成させてください。

既存Deckは重複と順位を確認するためだけに使い、添付行を今回の出力へ混ぜないでください。

---

## 2．対象範囲

依頼された範囲から、大学受験で暗記する価値の高いものを選んでください。

### 重要語

```text
現代日本語と意味が異なる漢字
文脈上重要な多義語
重要な人称・指示・疑問語
数量・限定・程度を表す語
頻出の熟語・故事成語
```

### 訓読の基本

```text
返り点
送り仮名
置き字
再読文字
訓読特有の語順
書き下し文の基本表記
```

### 句法

```text
否定
二重否定
部分否定・全部否定
禁止
使役
受身
疑問・反語
比較・選択
限定・累加
仮定
願望・詠嘆
抑揚
その他の大学受験頻出句法
```

### 漢詩・文学史・思想の基礎

```text
漢詩の形式・押韻・対句
主要な詩人・思想家・歴史家
主要作品と時代・ジャンル
諸子百家の基本的な対応
読解に必要な中国史・文化の基礎事項
```

思想内容や文学史の細部を網羅せず、本文を読む前提として覚える価値のある事項を優先してください。

---

## 3．収録するもの・収録しないもの

### 収録するもの

```text
重要漢字の読みと意味
多義語の頻出義
返り点の基本的な読む順序
置き字の読み方・働き
再読文字の読み方・意味
句法の形・読み・意味
紛らわしい句法の区別
短い定型句の書き下しと現代語訳
故事成語の意味と由来の要点
漢詩の形式と用語
主要人物・作品・時代・思想の対応
```

### 収録しないもの

```text
長い漢文本文と複数の設問
文章全体から主語・指示対象を推定する問題
登場人物の心情・行動理由を考察する問題
数十字以上の書き下し・現代語訳
複雑な返り点を初見で処理する演習
選択肢がなければ一意に決まらない句法識別
現代の市販教材・入試問題の例文や設問のコピー
```

漢文で必要な学力すべてをカード化しようとせず、本文読解と問題演習の前提知識だけを選んでください。

---

## 4．項目の選定と順位

指定件数ちょうどの項目を選び、次を重視してください。

1. 大学入試で覚えておく価値
2. 複数の文章で繰り返し現れるか
3. 訓読や現代語訳の誤りを防ぐか
4. 形を見てすぐ意味・読みを取り出す必要があるか
5. 似た句法・漢字との識別が重要か

同じ漢字の重要な複数義は一つの`item`にまとめ、語義ごとにカードを分けてください。同じ句法を用例ごとに別項目として重複収録しないでください。

ただし、同じ文字を含んでも句形・読み・意味が異なり、大学受験で別項目として覚える必要があるものは分けて構いません。`item`に識別情報を付けます。

```text
未〜（いまだ〜ず）
未必〜（いまだかならずしも〜ず）
```

`importance_rank`は全Deck累計の順位です。指定された開始値から終了値まで欠番なく使い、小さい値ほど重要にしてください。

`item_id`は`CC-`と6桁ゼロ埋め順位を組み合わせます。

```text
importance_rank=1   → CC-000001
importance_rank=500 → CC-000500
```

既存Deckの`item`、`aliases`、句形・読み・意味を合わせて比較し、同じ項目を別順位で再収録しないでください。

---

## 5．項目情報の書き方

`domain`は次から選びます。

```text
重要語
訓読
返り点
置き字
再読文字
句法
故事成語
漢詩
文学史
思想・文化
```

`item_type`には、項目の種別を具体的に書きます。

```text
多義語
一二点
置き字
再読文字
否定形
使役形
反語形
四字熟語
七言絶句
思想家
歴史書
```

`rule_info`には、必要な形・読み・意味を次の形式で記録します。

```text
形=未〜;読み=いまだ〜ず;意味=まだ〜ない
形=使A B;読み=AをしてBしむ;意味=AにBさせる
読む順=二→一
なし
```

該当しない場合は`なし`とします。

---

## 6．カードの作り方

一項目から、暗記する価値がある角度だけを1〜5枚程度のカードにしてください。句法や多義語は必要に応じて増やせますが、枚数合わせは禁止します。

`card_type`は次から選びます。

```text
meaning：漢字・句形から意味を答える
term_from_meaning：意味から漢字・句形を答える
reading：訓読上の読みを答える
kundoku_order：返り点の基本的な読む順を答える
okurigana：送り仮名を答える
saidoku：再読文字の最初と二度目の読みを答える
construction：句法名・形・意味を答える
identification：似た句法を識別する
kakikudashi：短い定型句を書き下す
translation：短い定型句を現代語訳する
idiom：故事成語の意味・由来を答える
poetry：漢詩の形式・用語を答える
literary_history：人物・作品・時代・思想を答える
```

すべてのカードで次を守ってください。

* 一枚につき一つの知識だけを問う
* 問題文だけで対象と答える範囲が分かる
* 前後のカードや長い本文を前提にしない
* 答えは一語、一句、短い一文にする
* 複数回答なら個数を明記する
* 句法は、形、読み、意味を一枚に詰め込みすぎず必要に応じて分ける
* 識別問題は短い用例だけで一意に判断できるようにする
* 書き下し・現代語訳は定型を覚えるための短句に限定する

悪い例：

```text
この文を書き下し、現代語訳し、主語を説明せよ。
傍線部はどの句法か。
本文全体の主題は何か。
```

良い例：

```text
再読文字「未」は、最初と二度目にそれぞれどう読むか。
句形「豈〜哉」は、疑問と反語のどちらを表すのが基本か。
「使人行」を使役形として書き下すとどうなるか。
```

---

## 7．短い用例

用例が必要なカードだけ、次の欄を使います。不要ならすべて`なし`です。

```text
example_original：白文または必要最小限の句読点を付けた原文
example_kundoku：返り点・送り仮名を含む訓読用表記
example_kakikudashi：書き下し文
example_reading：書き下し文全体の平仮名読み
example_translation：独自の短い現代語訳
```

次を守ってください。

* 原則として漢字12字以内の定型句または短句にする
* 対象箇所を必要に応じて`【 】`で一か所だけ示す
* その短句だけで正答が一意になるようにする
* 原典を使う場合は、著作権保護期間を終えた原典から必要最小限を使う
* 現代の教材が付けた訓点・送り仮名・訳をコピーしない
* 訓点、書き下し、読み、現代語訳を独自に作成し、相互に照合する
* 書き下し文は歴史的仮名遣いを基本とする
* 同じ原文に複数の標準的訓読がある場合は、大学受験で一般的な形を採用し、別形を`accepted_answers`へ入れる

白文、訓読用表記、書き下し文、現代語訳の間で、否定、使役、受身、疑問・反語、主語・目的語が変わっていないか必ず確認してください。

---

## 8．返り点・再読文字・句法の注意

### 返り点

返り点は、暗記すべき基本規則だけを扱います。

```text
レ点
一二点
上下点
甲乙点
組合せ時の基本的な優先関係
```

複雑な長文を実際に読み下す演習は作りません。記号の文字化で位置関係が不明になる問題も作らないでください。

### 再読文字

最初の読み、二度目の読み、意味を別カードにして構いません。送り仮名、否定との組合せを誤らないでください。

### 句法

次を厳密に区別してください。

```text
疑問と反語
部分否定と全部否定
単純否定と二重否定
禁止と不可能
使役と命令
受身と自発的な訳
比較と選択
限定と累加
```

文脈がなければ疑問・反語などを一意に判断できない用例は、識別カードに使わないでください。

---

## 9．答え・解説・混同対策

`answer`は、学校で用いる訓読法と大学受験で標準的な表記にしてください。

`accepted_answers`は`answer`を先頭にし、送り仮名・仮名遣い・語順の差として本当に認められるものだけを`｜`区切りで入れます。意味が少し似るだけの訳を大量に許容しないでください。

`explanation`は原則1〜3文です。句形、読む順、送り仮名、訳し方の核を短く示します。長文読解の解説は書きません。

`confusable_with`には混同しやすい漢字・句法を一つ、`distinction`には形、読み、否定範囲などの決定的な区別点を短く入れます。該当しなければ両方とも`なし`です。

`memory_aid`は、再読文字、句法、漢詩形式、人物と作品の対応を覚えるのに有効な場合だけ作ります。事実を変える語呂、下品な表現、答えより複雑な語呂は禁止します。不要なら`なし`とします。

---

## 10．読みと音声

`reading`は`item`全体の読みを平仮名で記録します。

`example_reading`は書き下し文全体の音読用読みです。原文にない意味説明を加えないでください。

`reading_map`には、問題・答え・解説中の難読語を次の形式で記録します。

```text
未曾有=みぞう｜諫言=かんげん｜孟軻=もうか
```

該当語がなければ`なし`とします。

* 白文を端末の自動読みへ直接渡す前提にしない
* 書き下し文の音声には`example_reading`を使う前提にする
* 表示本文へ丸括弧の読みを直接埋め込まない
* 同じ語、複合語の一部分を重複登録しない
* 問題側の読みから答えを漏らさない
* 語の途中だけが置換され、二重に読まれる形を作らない

---

## 11．著作権と出典

漢文原典が著作権保護期間を終えていても、現代の校訂、訓点、送り仮名、書き下し文、現代語訳、問題、解説には別の権利があり得ます。

* 原典用例は著作権保護期間を終えた作品だけから使う
* 国立国会図書館、大学・公的研究機関など、出所を確認できる資料を優先する
* 現代の市販教材、辞典、入試問題の訓点・書き下し・訳・設問をコピーしない
* 訓読、書き下し、現代語訳、説明、問題は独自に作成する
* 作者、成立時期、本文異同に諸説がある事項を一つに断定しない

次の順で内容を確認してください。

1. 文部科学省の現行学習指導要領と解説
2. 大学入試センターの出題方針と過去問題
3. 国立国会図書館、大学・公的研究機関の原典・書誌資料
4. 複数の漢和辞典、句法資料、検定済み教科書で一致する標準的説明

基準資料：

```text
https://www.mext.go.jp/a_menu/shotou/new-cs/1407074.htm
https://www.mext.go.jp/content/20250410-mxt_kyoiku01-100002620_02.pdf
https://www.dnc.ac.jp/kyotsu/kako_shiken_jouhou/
https://dl.ndl.go.jp/
```

## 12．CSVの29列

列は次の29列に固定し、この順番を変えないでください。

```text
dataset_label,item_id,importance_rank,difficulty_label,domain,unit,item,reading,aliases,item_type,rule_info,card_id,card_type,focus,question,answer,accepted_answers,explanation,example_original,example_kundoku,example_kakikudashi,example_reading,example_translation,confusable_with,distinction,memory_aid,source_name,source_url,reading_map
```

| 列 | 内容 |
|---|---|
| `dataset_label` | 全行共通のデータセット名 |
| `item_id` | `CC-`と6桁順位 |
| `importance_rank` | 全Deck累計の重要度順位 |
| `difficulty_label` | 依頼文指定の水準 |
| `domain` | 重要語、句法、漢詩などの大分類 |
| `unit` | 否定、再読文字などの小分類 |
| `item` | 暗記の中心項目 |
| `reading` | 項目全体の読み |
| `aliases` | 別表記・別名の`｜`区切り。なければ`なし` |
| `item_type` | 多義語、反語形、思想家などの種別 |
| `rule_info` | 形、読み、意味、読む順。不要なら`なし` |
| `card_id` | `item_id`に`-C01`から連番を付ける |
| `card_type` | 指定したカード型 |
| `focus` | 一枚で覚える一つの知識点 |
| `question` | 単独で成立する短い問い |
| `answer` | 短い模範回答 |
| `accepted_answers` | `answer`を先頭にした許容解答の`｜`区切り |
| `explanation` | 1〜3文の簡潔な補足 |
| `example_original` | 漢字12字以内の原文。不要なら`なし` |
| `example_kundoku` | 訓点・送り仮名付き表記。不要なら`なし` |
| `example_kakikudashi` | 書き下し文。不要なら`なし` |
| `example_reading` | 書き下し文全体の読み。不要なら`なし` |
| `example_translation` | 独自の現代語訳。不要なら`なし` |
| `confusable_with` | 混同しやすい項目。なければ`なし` |
| `distinction` | 最重要の区別点。なければ`なし` |
| `memory_aid` | 正確で短い記憶補助。なければ`なし` |
| `source_name` | 主な確認先または原典名 |
| `source_url` | 確認先URL |
| `reading_map` | 難読語と読み。なければ`なし` |

空欄は禁止します。該当情報がない欄は`なし`とします。

---

## 13．CSVの技術条件

* UTF-8のBOM付きCSVにする
* 一行目を見出しにする
* 全データ行を29列にする
* セル内改行を入れない
* カンマとダブルクォートをCSV規則どおり処理する
* 複数値は`｜`で区切る
* `card_id`を項目内で欠番なく振る
* 同じ問い、言い換えだけの問いを重複させない
* CSV以外の説明行を混ぜない

---

## 14．出力前の全件検査

### 件数・順位・重複

* 重複しない`item_id`数が指定件数と一致するか
* 順位が指定範囲を欠番なく一度ずつ使われているか
* IDの6桁部分と順位が一致するか
* 既存Deckと同じ重要語・句法・作品項目が重複していないか
* 同じ項目の基本情報が全カードで一致するか

### 暗記カードとしての適合

* 各カードが一つの知識だけを問うか
* 答えが一語、一句、短い一文に収まるか
* 長文読解、人物考察、長い書き下し・訳を混ぜていないか
* 本文読解でしか身に付かない内容を無理にカード化していないか
* 問題文または短い用例だけで正答が一意に決まるか
* 項目数を満たすための低重要度事項がないか

### 内容・用例・表記

* 重要語の読みと意味が正しいか
* 返り点の順、送り仮名、再読文字、句法が標準的か
* 白文、訓読用表記、書き下し文、読み、訳が対応するか
* 否定範囲、使役・受身、疑問・反語を取り違えていないか
* 文脈が必要な識別を短句だけで断定していないか
* 現代の校訂、訓点、訳、教材文をコピーしていないか
* 読み情報に重複や部分置換がないか
* 全行が29列で空欄がないか
* 出典が内容を実際に支えるか

不備がある場合は、指定件数と順位を変えずに修正してから出力してください。

---

## 15．最終出力

ファイル生成機能がある場合は、完成したCSVを作成してください。

```text
classical_chinese_deck1_core_memory_400.csv
classical_chinese_deck2_constructions_memory_300.csv
```

ファイル生成機能がない場合は、CSV全体を一つの`csv`コードブロックで出力してください。

最終回答にはCSV以外の前置き、作業報告、選定理由、注意書き、要約を含めないでください。指定された全行を一つのファイルまたは一つのコードブロックとして提供してください。
