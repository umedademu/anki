## 問題を追加する形式

登録用CSVは `data/source/world-history-so/questions.csv` です。見出しは「問題,回答,解説,カテゴリ」で、３列目は「説明」も使用できます。今後は同じファイルに行を追加し、４列目へ分野名を指定します。解説は空欄も使用できますが、問題・回答・カテゴリは必須です。カンマ・改行・引用符を含む値はCSVの引用規則に従います。

３列形式を読み取る関数は取り込み側がカテゴリを指定した場合だけ受け付けます。通常の登録用ファイルは、将来別分野を誤分類しないよう４列形式に統一します。元のダウンロードファイルは変更しません。

## 保存と更新

本番ではCloudflare R2の `anki-world-history` 内の `subjects/world-history-so/` から読み込みます。手元の生成物は検査・登録用であり、本番の読み込み先にはしません。問題ごとの履歴は既存の保存窓口を経由してD1へ保存します。

教科の識別名は `world-history-so`、履歴版は `world-history-so-deck-1-v1` です。問題文から安定した識別番号を作り、行の追加・並べ替え・回答や解説やカテゴリの修正では履歴を維持します。同じ問題文の重複は拒否します。問題文の変更や削除には、旧識別番号からの履歴移行を別途検討する必要があります。登録処理も既存番号の欠落を拒否します。

1. `npm run build:data` と `npm run check` で生成・検査します。
2. `npm run preview:data:world-history-so` でCloudflare上の現在の科目一覧と対象件数を確認します。
3. `npm run publish:data:world-history-so` で世界史SOの分割データ、科目索引、全体索引の順に登録・照合します。

専用の登録処理はCloudflare上の現在の全体索引に世界史SOだけを追加・更新します。他科目の索引、問題、画像、音声、D1の履歴は書き換えません。作業中に全体索引が更新されていた場合は反映を中断します。

## 地図問題

`data/source/world-history-so/question-maps.json`で問題文と図の保存先を対応させ、`maps/`内のSVGを登録します。問題文はCSVと一致させてください。専用の登録処理は地図をCloudflareへ登録・全文照合してから問題と索引を更新します。本番での図の読み込み先もCloudflare R2の`subjects/world-history-so/maps/`です。地図追加時は専用の予行確認・登録処理を使用してください。

### 解答地図の生成

`scripts/create-answer-map.mjs`が出題用SVGの番号と空欄の位置を読み、CSVの回答から文字サイズを調整して解答用SVGを生成します。長いカリフ領の表示は２行にします。`writeSubjectData`で`-answer.svg`を生成し、専用の登録処理が出題用・解答用の両方をCloudflareへ登録・照合します。アプリは回答の表示状態に応じて画像の保存先と説明文を切り替えます。出題用SVGには答えを加えません。
