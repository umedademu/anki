## CSV形式

前回の第22〜24回と同じ10列です。文字コードは **UTF-8（BOM付き）**、区切りはカンマ、改行はCRLF、全フィールドを二重引用符で囲んでいます。1行目がヘッダーで、1問は1行、セル内改行はありません。

| 列名 | 内容 |
|---|---|
| `question_id` | `WH-回-小見出し-連番`。各デッキ内の原文順に採番した一意のID。 |
| `question` | 対象・時代・条件を明示した問題文。 |
| `answer` | 用語や、説明問題の採点に必要な要点。 |
| `explanation` | 添付資料に基づく補足、因果関係、区別するポイント。 |
| `type` | 添付分類表に沿った11種類のうち一つ。 |
| `style` | 全問 `一問一答`。 |
| `source_url` | 全問空欄。 |
| `source_file` | 主な根拠となる添付MDのファイル名。 |
| `source_page` | 主な根拠が載っている印刷ページ番号。 |
| `source_line` | 主な根拠の開始位置に当たる、元のMD内の行番号。 |

前回の列名・列順との一致を確認しました。特定アプリへの実際のインポート動作は検証していません。添付の分類ガイド自体は、CSVのインポート仕様を定めたものではありません。

## 原文順と出典位置

本文・表・「クローズアップ」などのまとめ欄に、主な根拠が登場する順で配列しています。年代順や問題種類順には並べ替えていません。同じ記載位置から複数問を作る場合は、基本事項と理解・比較の問題をまとめています。

資料冒頭の目次や毎ページの柱は、本文の小見出しと区別しました。例えば、第26回415ページ冒頭の三十年戦争の被害や「17世紀の危機」は、第1節に含め、第2節の本文開始はその後の見出しを基準にしています。

第27回導入部（428ページ）にある「環大西洋革命」は、第4節「アメリカ独立革命」の先頭に収録しました。同デッキでも、導入部から本論へという原資料の順序を保っています。

出典行は主な根拠の開始位置です。比較・統合説明や補足では、添付された本文の複数箇所を関連づけている場合があり、表示した1行だけが解答・解説の全根拠という意味ではありません。問題や解説に関連する記述は、その前後や同じ回のまとめ欄にもあります。

## 出題方針

人物と政策、制度・条約の内容、宗派・国家間の対立、革命の原因と結果、産業の相互関係を重視しました。名称を答える問題だけでなく、似た語や出来事を区別する比較問題、短い説明問題も含めています。

主な比較対象は、権利の請願・宣言・章典、長老派・独立派・水平派、プロイセンの同名に近い君主、啓蒙専制君主の農奴政策、三十年戦争・継承戦争・七年戦争の講和、3回のポーランド分割、2回の囲い込み、木綿工業の発明者と機械、1763年と1783年のパリ条約、連合規約と合衆国憲法などです。

各問は単独でも解けるようにしています。同じ事実が異なる回で再登場する場合は、その回の文脈に沿って再び扱うことがあります。したがって、全体で意味の重なる問題を完全に除いたデータではありません。

## 資料の扱い・注意点

内容の根拠は添付MDです。外部の教科書・ウェブサイトによる史実の校訂や、添付範囲にない知識の追加は行っていません。語呂合わせ、学習価値の小さい逸話、文字起こしだけでは意味が明確でない部分は原則として出題対象から外しました。地図画像にない位置を推測して穴埋めする問題も作成していません。

第27回439ページのまとめ欄の表題には、独立戦争本文とは一致しない年代表記があります。その表題の年代は採用せず、戦争や宣言の各項目・本文に記された年月を用いています。

第26回418ページでは、ヨーゼフ2世の改革に関する「有償」の対象の表現が本文とまとめ欄で異なります。有償対象を特定する問題は設けず、人格的自由の承認と、他の君主の農奴政策との違いを中心に出題しました。解説で賦役労働に触れた部分は本文の表現に基づいています。

共通テストの高得点を目指すための知識・理解の確認用です。この3回分で世界史全範囲を網羅するものではなく、得点を保証するものでもありません。資料読解や選択肢の判定は、別に実際の問題演習で確認してください。
