# Anki

最初に科目を選び、世界史、日本史、英単語、地理、政治・経済、生物基礎、地学基礎を科目別に学ぶWebアプリです。

現在のバージョンは`v0.094`です。Web上の変更履歴は`public/changelog.html`で公開します。

最後に選んだ科目、科目ごとの複数Deckと学習方法、Deckごとの地域・カテゴリ・問題スタイル・出題量、シャッフル、自動読み上げはCloudflare D1へ保存します。次回にその科目を選ぶと最後に使った開始画面を同じ条件で復元し、同じアクセスキーを使う別端末にも引き継ぎます。

アプリの起動時と上部の「Anki」ロゴを押したときは、前回の科目へ自動移動せず必ず科目選択画面を表示します。保存済みの開始設定は維持し、科目を選んだ後の学習範囲画面へ復元します。

聞き流しは対象問題を一通り読み終えると自動的に終了し、用語数・問題数・学習時間を示す結果画面へ移ります。そのまま先頭へ戻って2周目を始めることはありません。結果画面では開始画面へ戻れるほか、スマートフォンの左半分タップまたはキーボードの左矢印で最後の問題の回答表示へ1手戻れます。

## フォルダー構成

- `public`：Web上で公開する学習画面と更新情報ページ
- `public/data`：手元確認とCloudflare登録のためにCSVから生成する分割データ
- `data/source`：科目ごとの元CSVと関連画像の正本
- `scripts`：元CSVの変換処理と検証処理
- `worker`：Cloudflare D1への学習記録保存と、Azure AI Speechへの安全な接続を行う処理
- `docs`：仕様書、更新情報、問題集生成用プロンプト
- `vercel.json`：Vercelの公開設定

## 学習データを更新する方法

`data/source/world-history`にはDeckごとの世界史CSV、`data/source/japanese-history`にはDeckごとの日本史CSV、`data/source/english-vocabulary`にはDeckごとの英単語CSV、`data/source/geography`にはDeckごとの地理CSV、`data/source/politics-economics`にはDeckごとの政治・経済CSV、`data/source/biology-basics`にはDeckごとの生物基礎CSV、`data/source/earth-science-basics`にはDeckごとの地学基礎CSVを配置します。英単語CSVは1語1行の10列形式、地理CSVは1カード1行の29列形式、政治・経済CSVは1カード1行の30列形式、生物基礎CSVは1カード1行の25列形式、地学基礎CSVは1カード1行の27列形式を使用します。そのあと、次の命令でWeb表示用データを作り直して検査します。

ChatGPTで新しい問題集CSVを作る場合は、世界史では`docs/prompts/world-history-csv-generation.md`、日本史では`docs/prompts/japanese-history-csv-generation.md`、英単語では`docs/prompts/english-vocabulary-csv-generation.md`、地理では`docs/prompts/geography-csv-generation.md`、政治・経済では`docs/prompts/politics-economics-csv-generation.md`、生物基礎では`docs/prompts/biology-basics-csv-generation.md`、地学基礎では`docs/prompts/earth-science-basics-csv-generation.md`を依頼文と一緒に渡します。段階表と今回作成する項目数は依頼文へ直接記載し、Deck 2以降を作る場合は重複確認のために作成済みの全DeckのCSVも添付します。世界史と日本史は同じ25列の三段階形式、英単語は10列形式から三方向、地理は29列形式、政治・経済は30列形式、生物基礎は25列形式、地学基礎は27列形式の暗記カードとして変換します。

今後追加する科目には、科目ごとの暗記に適した列構成を使う次の生成用プロンプトを準備しています。

- 古文：`docs/prompts/classical-japanese-csv-generation.md`
- 漢文：`docs/prompts/classical-chinese-csv-generation.md`

この2科目では、勉強全体をアプリ内で再現せず、暗記によって対応できる用語、意味、働き、位置、順序、句法、識別点などだけを短いカードにします。長文読解や心情考察などは生成対象に含めません。Deck数、各Deckの新規項目数、累計順位、位置づけ、具体的な収録単元・分野・地域・配分はプロンプトへ固定せず、作成時に一緒に送る段階表と追加依頼から読み取ります。追加の範囲指定がなければ、ChatGPTが大学受験での重要度から収録内容を判断します。現時点ではこの2科目はプロンプトだけを準備しており、Webアプリの科目選択、変換処理、学習データはまだ追加していません。

世界史・日本史の既存語呂を「語呂合わせマスター」と照合するときは、予行表示後に反映用の命令を実行します。この処理はCloudflare上の現行デッキを読み、同じ年号・同じ出来事だけを元CSVへ反映します。

```powershell
npm run sync:mnemonics:goroawase-master
npm run sync:mnemonics:goroawase-master:apply
```

```powershell
npm run build:data
npm run check
npm run audit:speech:cloudflare
```

`audit:speech:cloudflare`は、Cloudflare上の世界史・日本史の全デッキを読み、問題・回答・解説・語呂合わせの読み上げ用文章を全件検査します。学習データへの書き込みは行いません。

生成後は`npm run preview:data:cloudflare`で置換対象を確認し、`npm run replace:data:cloudflare`で全デッキをCloudflare R2の`anki-world-history`へ登録します。この処理は登録済みの同一画像を再送せず、新しい画像・分割データ・索引を登録して内容を照合した後だけ、旧問題集にしかないデータを削除します。`speech-cache`の音声とD1の学習履歴には触れません。本番アプリは次のCloudflare公開URLから学習データを読み込みます。

```text
https://pub-76ffbe2829114a5cbaa433db45872267.r2.dev
```

本番で`public/data`へ暗黙に切り替わる処理はありません。`localhost`または`127.0.0.1`で手元確認するときだけ、`public/data`を`/data`として読み込みます。

## 学習記録のCloudflare保存

問題ごとの正誤記録、日別の学習記録、復習間隔、音声設定、シャッフル、自動読み上げ、科目別の自動音声対象は、Cloudflare D1の`anki-progress`へ、Workerの`anki-progress-api`を通して保存します。同じWorkerがAzure AI Speechへ安全に接続し、生成済み音声をR2の`anki-world-history`内の`/speech-cache`へ保存します。Azureの接続キーはWorkerの秘密情報`AZURE_SPEECH_KEY`、リージョンは`japaneast`として管理します。

```text
https://anki-progress-api.umedademu.workers.dev
```

書き込みにはCloudflare側だけに登録した一人用アクセスキーが必要です。Webアプリでは`/settings.html`を開き、アクセスキーを一度入力して接続します。本番からの通信だけを許可し、アクセスキーはリポジトリや公開用ファイルへ含めません。

## 手元で表示する方法

プロジェクトのフォルダーで次の命令を実行し、ブラウザーで`http://localhost:3000`を開きます。

```powershell
python -m http.server 3000 --directory public
```

## Vercelで公開する方法

Vercelでこの保管場所を取り込み、次の設定を使用します。

- 使用する仕組み：`Other`
- 組み立て命令：空欄
- 公開フォルダー：`public`

公開フォルダーは`vercel.json`にも設定済みです。
