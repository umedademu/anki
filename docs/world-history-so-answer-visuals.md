# 世界史SOの解答用の地図・関連画像（v0.258）

第6章「イスラーム世界」の全357問の回答で地理関係を確認できるようにする。通常の351問には解答用の地図を追加し、既存の穴埋め地図6問は従来の出題用・解答用の切り替えを維持する。建築物・人物など46問には、既存の世界史等で利用している関連画像を添える。v0.259以降に追加した他章はこの地理対応表の対象外とし、別章に同じ背景地図を割り当てない。画像未登録の問題は地図枠を表示しない。

## 表示

- 回答のすぐ下に地図を大きく置き、解説と関連画像はその後へ置く。
- 通常の問題では回答前に地図も関連画像も出さず、画像の保存先・代替説明・場所一覧も消去する。穴埋め地図問題は出題図を表示する。
- 問題が変わった時、科目や画面を移動した時、問題数の上限へ達した時は拡大画面も閉じる。
- 赤い印は注目する場所、灰色は比較用の場所、青い線は川。広域図の四角で拡大対象の位置を示す。
- 王朝の印は主要拠点を示し、領土境界を表さない。同じ都市を拠点とする王朝は同じ位置にまとめ、個々の王朝と時期は「場所の説明・王朝の時期」に残す。地方の点線は範囲の目安。川は流路の概略。
- 地図を押すと拡大画面を開く。拡大・縮小・全体表示・閉じる操作と、携帯画面での上下左右の移動に対応する。地図の操作で回答評価や次問への移動を起こさない。
- 通信失敗時も学習を続けられ、回答側に再読込ボタンを表示する。

## 地理情報の作成

基図は別プロジェクト `C:/Users/USER/Desktop/W-History/public/islamic-world-map.svg` を取り込んだ `data/source/world-history-so/answer-visuals/base-map.svg`。Natural Earthの海岸線・湖岸を基にする。利用条件は [Natural Earth公式](https://www.naturalearthdata.com/about/terms-of-use/) を参照する。W-History側のファイルは変更しない。

`scripts/world-history-so-atlas.mjs` に都市・主要拠点の座標、地方の目安、川の概略、比較用の場所と説明を管理する。第20・21回の本文とW-Historyの各地域図を参考にした。現代の国境を歴史上の国境として表示しない。地図の範囲外を含む遠征全体や王朝の領土の変遷は表現しない。

回答・問題・解説の順に地名候補を評価し、最大7か所の注目場所と4か所の比較場所を選ぶ。長い固有名を先に照合し、「後ウマイヤ朝」に「ウマイヤ朝」、「マンサブダール」に「ブダ」を誤対応させない。ホラズムとホラーサーン、三カリフ、中央アジアの三ハン国、都の移動などは問題別の明示的な対応で地理関係を優先する。直接の地名がない宗教概念などには、その学習範囲の背景地図を表示する。

`scripts/world-history-so-answer-visuals.mjs` が必要範囲を切り出し、同一点の統合、文字の重なり回避、拡大範囲を示す広域図を含むSVGを生成する。関連画像はCloudflareの現行 `term-images.json` にある説明・作者・利用条件をそのまま利用する。問題ごとの対応を `data/source/world-history-so/answer-visuals/coverage.json` に記録する。

## Cloudflareでの更新

1. `npm run preview:visuals:world-history-so` でCloudflareの現行問題・画像一覧を読み取り、地図を `.wrangler/so-answer-visuals/` へ生成する。これは確認用の出力であり、本番の読み込み先ではない。
2. 生成した地図・対応一覧を確認し、`npm run test:visuals:browser` と `npm run check` を実行する。ブラウザー試験では開始前に自動読み上げをOFFにし、音声の再生を止める。
3. `npm run publish:visuals:world-history-so` で認証付きの一時保存窓口からR2の現行データを読み直す。地図を登録・全文照合後、問題集・既存画像一覧・解答画像一覧の取得時の版が維持されていることを確認して解答画像一覧だけを切り替える。旧一覧はR2の `answer-visuals/history/` へ保存する。作業後は一時窓口を削除する。

本番の一覧は `subjects/world-history-so/answer-visuals/index.json`、地図は同じ配下の `maps/<内容から作った名前>.svg` に置く。すべてCloudflare R2から読み込む。関連写真も既存のR2画像を参照する。問題本文・番号・パート分け・問題集の版・全体索引・他科目の画像一覧・D1の学習記録は更新しない。地図を更新する時も旧画像は削除しない。

問題を編集・追加して対象地名が変わった場合は、この専用手順で地図一覧も更新する。地図の割り当ては問題番号単位であり、通常の問題登録とは独立している。
