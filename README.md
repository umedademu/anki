# Anki

最初に科目を選び、世界史、日本史、英単語、地理、政治・経済、生物基礎、地学基礎、古文（国語）、漢文（国語）を科目別に学ぶWebアプリです。

現在のバージョンは`v0.167`です。Web上の変更履歴は`public/changelog.html`で公開します。

最後に選んだ科目、科目ごとの複数Deckと学習方法、Deckごとの地域・カテゴリ・問題スタイル・出題量、シャッフルはCloudflare D1へ保存します。次回にその科目を選ぶと最後に使った開始画面を同じ条件で復元し、同じアクセスキーを使う別端末にも引き継ぎます。暗記モードの自動読み上げは全科目で常にオンです。

アプリの起動時と上部の「Anki」ロゴを押したときは、前回の科目へ自動移動せず必ず科目選択画面を表示します。保存済みの開始設定は維持し、科目を選んだ後の学習範囲画面へ復元します。スマートフォン横向きでは科目選択画面を上下に動かし、毎日の学習メニューと科目一覧の下部まで確認・選択できます。

### 毎日の学習メニュー

科目選択画面から、科目と問題数、動画視聴を並べた毎日のメニューを順番に進められます。科目学習ではDeck、学習方法、絞り込み、出題量、シャッフルを始める直前の通常の開始画面で選びます。ここで変えた開始設定は通常の科目選択から始めた場合と共通です。

科目選択画面の「今日の学習量」で、全科目の目標問題数を0.1倍から3倍まで0.05刻みで一括調整できます。100問なら0.1倍で10問、0.15倍で15問、0.5倍で50問、0.75倍で75問、2倍で200問、3倍で300問になります。端数は最も近い整数とし、最低1問は残します。選んだ倍率は進行中のメニューにも反映してCloudflareへ保存し、動画の本数は変更しません。

同じ場所の「今日は動画をスキップ」をONにすると、毎日のメニュー内の未視聴動画をすべて飛ばして科目学習だけを進められます。進行中のメニューにも直ちに反映してCloudflareへ保存します。動画を視聴済みにはせず、OFFへ戻すと未視聴動画が再びメニューの対象になります。

科目を自由に選ぶ一覧には「動画をランダム再生」も表示します。毎日のメニューを進めずに登録動画を1本再生でき、見終えた後は別の動画を続けて選べます。抽選順は毎日のメニューと共有し、登録動画を一巡するまで同じ動画を重ねません。

初期メニューは、世界史、英単語、地理、古文、日本史、政治・経済、英単語、世界史、地学基礎、地理、日本史、英単語、地理、漢文、世界史、日本史、生物基礎、地理、英単語、日本史、英単語、世界史の22学習項目で、すべて100問です。各学習項目の直後には動画項目を1件ずつ配置します。設定ページでは科目と動画項目の追加、複製、削除、並べ替え、問題数変更、動画URLの登録・削除ができ、保存後に1番から始める次のメニューへ反映します。進行中のメニューは開始時の内容を維持します。

ただし、動画機能の追加前から続いていて動画項目が1件もない進行中メニューは、学習項目の識別番号と並びが現在の設定にすべて一致する場合だけ、達成数・評価回数・学習時間を保ったまま設定済みの動画を補います。次の学習が未着手なら直前に置かれた動画から再開し、着手済みならその学習を巻き戻しません。

動画項目では登録動画を一巡するまで重複なくランダムに選び、全動画の視聴後に次の周を混ぜ直します。周の境目でも同じ動画を連続させず、抽選の残り順、最後の動画、視聴済み状態はCloudflareへ保存して端末間で共有します。初期状態では指定された世界史の動画27本を収録し、URL登録時にYouTubeから題名を自動取得します。動画再生画面はスマートフォン横向きでも上下に動かせるため、動画の下にある操作まで確認できます。

各項目では、暗記モードの「難しい・正解・簡単」と、聞き流しで回答まで完了した回数を1問として加えます。「不正解」は加算せず、その後の再出題で正答側を選ぶと加算します。同じ問題を意図して復習した場合も回答ごとに加算しますが、通信再送は同じ回答として扱い二重計上しません。現在の条件で出せる問題が目標数より先に尽きた場合は、残りの問題数を示して開始画面へ戻し、別のDeckや学習方法を選んで続けます。目標数へ達した時点から初期値10分以内に復習予定の問題があれば、未出題問題へは進まず、待機画面を挟まず追加の復習としてすぐに出題し、すべて終えた後に結果を一度だけ表示します。対象問題は目標達成時点で確定し、猶予は設定ページで0分から1440分まで変更してCloudflareへ保存・端末間共有できます。結果には進めた問題数、その科目の学習時間、メニュー全体の進捗、不正解・難しい・正解・簡単を選んだ回数を表示します。確認画面では次の科目へ進むか、トップへ戻って後から続けるかを選べます。

メニューの進み方はCloudflareへ保存します。日本時間の午前4時を越えた時は、前回の続きから今日の学習として進めるか、1番から新しく始めるかを選べます。続きから始める操作を先頭の目立つボタン、1番からやり直す操作を後ろの控えめなボタンとして表示します。一手戻しでは、その問題のメニュー件数もCloudflare上で同時に取り消します。

## 学習データを更新する方法

`data/source/world-history`にはDeckごとの世界史CSV、`data/source/japanese-history`にはDeckごとの日本史CSV、`data/source/english-vocabulary`にはDeckごとの英単語CSV、`data/source/geography`にはDeckごとの地理CSV、`data/source/politics-economics`にはDeckごとの政治・経済CSV、`data/source/biology-basics`にはDeckごとの生物基礎CSV、`data/source/earth-science-basics`にはDeckごとの地学基礎CSV、`data/source/classical-japanese`にはDeckごとの古文CSV、`data/source/classical-chinese`にはDeckごとの漢文CSVを配置します。英単語CSVは1語1行の10列形式、地理と漢文のCSVは1カード1行の29列形式、政治・経済CSVは1カード1行の30列形式、生物基礎CSVは1カード1行の25列形式、地学基礎と古文のCSVは1カード1行の27列形式を使用します。そのあと、次の命令でWeb表示用データを作り直して検査します。

ChatGPTで新しい問題集CSVを作る場合は、世界史では`docs/prompts/world-history-csv-generation.md`、日本史では`docs/prompts/japanese-history-csv-generation.md`、英単語では`docs/prompts/english-vocabulary-csv-generation.md`、地理では`docs/prompts/geography-csv-generation.md`、政治・経済では`docs/prompts/politics-economics-csv-generation.md`、生物基礎では`docs/prompts/biology-basics-csv-generation.md`、地学基礎では`docs/prompts/earth-science-basics-csv-generation.md`、古文では`docs/prompts/classical-japanese-csv-generation.md`、漢文では`docs/prompts/classical-chinese-csv-generation.md`を依頼文と一緒に渡します。段階表と今回作成する項目数は依頼文へ直接記載し、Deck 2以降を作る場合は重複確認のために作成済みの全DeckのCSVも添付します。世界史と日本史は同じ25列の三段階形式、英単語は10列形式から三方向、地理と漢文は29列形式、政治・経済は30列形式、生物基礎は25列形式、地学基礎と古文は27列形式の暗記カードとして変換します。

古文と漢文では、勉強全体をアプリ内で再現せず、暗記によって対応できる単語・文法・句法・訓読・古典常識などだけを短いカードにします。長文読解や心情考察などは生成対象に含めません。

世界史・日本史の語呂を許可済み3サイトと照合するときは、予行表示後に反映用の命令を実行します。この処理はCloudflare上の現行デッキを読み、同じ年・同じ出来事の掲載語呂だけを元CSVへ反映します。同一年の複数候補は品質比較で1件に絞り、サイトにない既存語呂は削除します。

```powershell
npm run sync:mnemonics:approved-sites
npm run sync:mnemonics:approved-sites:apply
```

```powershell
npm run build:data
npm run check
npm run audit:speech:cloudflare
npm run audit:answer-notes:cloudflare
```

`audit:speech:cloudflare`は、Cloudflare上の世界史・日本史の全デッキを読み、問題・回答・語呂合わせの読み上げ用文章を全件検査します。`audit:answer-notes:cloudflare`は全科目の回答補足を数え、末尾へ調べたい文を加えた場合は一致する科目・デッキ・問題番号も表示します。どちらも学習データへの書き込みは行いません。

生成後は`npm run preview:data:cloudflare`で置換対象を確認し、`npm run replace:data:cloudflare`で全デッキをCloudflare R2の`anki-world-history`へ登録します。この処理は登録済みの同一画像を再送せず、新しい画像・分割データ・索引を登録して内容を照合した後だけ、旧問題集にしかないデータを削除します。`speech-cache`の読み上げ音声、`rating-sounds`の登録評価音、D1の学習履歴には触れません。本番アプリは次のCloudflare公開URLから学習データを読み込みます。

```text
https://pub-76ffbe2829114a5cbaa433db45872267.r2.dev
```

本番で`public/data`へ暗黙に切り替わる処理はありません。`localhost`または`127.0.0.1`で手元確認するときだけ、`public/data`を`/data`として読み込みます。

## 学習記録のCloudflare保存

問題ごとの正誤記録、日別の学習記録、毎日の学習メニューの学習量倍率と動画スキップ設定、復習間隔、音声設定、シャッフル、科目別の自動音声対象は、Cloudflare D1の`anki-progress`へ、Workerの`anki-progress-api`を通して保存します。同じWorkerがAzure AI Speechへ安全に接続し、生成済み音声をR2の`anki-world-history`内の`/speech-cache`へ保存します。Azureの接続キーはWorkerの秘密情報`AZURE_SPEECH_KEY`、リージョンは`japaneast`として管理します。

```text
https://anki-progress-api.umedademu.workers.dev
```

書き込みにはCloudflare側だけに登録した一人用アクセスキーが必要です。Webアプリでは`/settings.html`を開き、アクセスキーを一度入力して接続します。本番からの通信だけを許可し、アクセスキーはリポジトリや公開用ファイルへ含めません。

## 手元で表示する方法

プロジェクトのフォルダーで次の命令を実行し、ブラウザーで`http://localhost:3000`を開きます。

```powershell
python -m http.server 3000 --directory public
```

## Vercelで公開する方法

Vercelでこの保管場所を取り込み、次の設定を使用します。

- 使用する仕組み：`Other`
- 組み立て命令：空欄
- 公開フォルダー：`public`

公開フォルダーは`vercel.json`にも設定済みです。
