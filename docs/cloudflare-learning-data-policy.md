# 単語集のCloudflare利用方針

単語集の読み込みと書き込みは、必ずCloudflare経由で行います。

リポジトリ内の`public/data`や、Webアプリと同じ場所にある`/data`は手元の動作確認にだけ使用し、本番の単語集の読み書きには使用しません。

Cloudflareの接続先や操作方法が分からない場合は、ローカルの単語集で代用せず、必要な情報を利用者へ確認します。

## 学習記録と共通設定

- 世界史、日本史、英単語、地理、政治・経済、生物基礎、地学基礎、古文、漢文を含む問題集本体はR2の`anki-world-history`から科目別に読み込む
- 問題集に関連画像が用意されている場合は、画像、説明、作者、利用条件もR2の`anki-world-history`から読み込む
- 関連画像一覧は問題CSVと分け、画像追加だけでは問題集の版と学習履歴の保存範囲を変更しない
- 画像一覧には用語の標準画像と問題ごとの固定画像を記録し、同じ用語でも問いの内容に応じて画像を切り替える
- 問題ごとの評価、復習予定日時、習得済み状態、進行中の一周と4段階評価ごとの回数、毎日の学習メニューと進み方・学習量倍率・動画スキップ設定・項目ごとの4段階評価回数・目標達成後の復習猶予、メニュー動画一覧と抽選状態、学習時間、1問ごとの学習時間上限、復習間隔、音声設定、評価音の割り当てと音量、聞き流しの回答待ち時間と次の問題までの間隔、開始前の全選択項目、科目別の自動音声対象はD1の`anki-progress`へ保存する
- 最後の科目、科目ごとの複数Deckと学習方法、Deckごとの地域・カテゴリ・問題スタイル・出題量、シャッフルを開始前の共通設定として保存し、次回の開始画面と別端末へ復元する。暗記モードの自動読み上げは保存済みの旧設定にかかわらず常にオンとして扱う。ただし漢文の意味瞬発問題の問題面は無音とする
- 毎日の学習メニューは科目と目標問題数、ランダム動画視聴の並びを保存し、Deckや学習方法は既存の開始前共通設定をそのまま使用する
- 毎日の学習メニューの学習量倍率は0.1倍から3倍まで0.05刻みで保存し、各科目の元の目標問題数と倍率適用後の目標問題数を進行中メニューへ保持する。動画項目の本数は倍率で変更しない
- 倍率変更は進行中メニューにも同じCloudflare保存で反映し、倍率を下げた時も既に達成した件数は保持して、後から倍率を上げ直した時に再利用する
- 動画スキップ設定は開始前の共通設定と進行中メニューへ保存する。ONの間は未視聴動画を完了扱いで飛ばすが視聴済み状態は変更せず、OFFへ戻した時は未視聴動画を再び対象にする
- 動画一覧はYouTubeの動画番号、題名、投稿元を保存し、ブラウザーからYouTubeへ直接情報取得せず、保存窓口がURLを検査して題名を取得する
- 動画の抽選は登録動画を一巡するまで重複させず、全件消化後に混ぜ直す。次の周の先頭が直前の動画と同じ場合は別動画と入れ替え、残りの動画番号と最後の動画番号をD1へ保存する
- 科目選択からのランダム再生も毎日の学習メニューと同じ動画抽選状態を使用し、選ばれた動画を残り順から除く。ただし進行中メニューの現在位置、動画割り当て、完了状態は変更しない
- 進行中の毎日の学習メニューは開始時の項目一覧、学習日、現在位置、動画スキップ設定、動画項目へ割り当てた動画、項目ごとの達成数・学習時間・4段階評価回数を保存し、設定ページで並びを変更しても次に1番から始めるまでは書き換えない。ただし科目選択画面の学習量倍率と動画スキップ設定は進行中メニューへ反映する
- 動画機能追加前から続く動画0件の進行中メニューは、学習項目の識別番号と並びが現在設定と完全に一致する場合だけ動画項目を補い、達成数、4段階評価回数、学習時間を維持してD1へ保存する
- 問題ごとの記録はDeckごとの安定した学習履歴版`version`を保存範囲に含め、別の問題集と混在させない
- CSV内容の更新検知には`contentVersion`を使用し、語呂合わせ・表記・解説などを更新しても`version`は変えず、既存の学習履歴を維持する
- 問題IDの意味や学習対象を互換性なく変更するときだけ新しい`version`を割り当て、科目・Deck追加時も既存Deckの`version`を維持する
- WebアプリからD1へ直接接続せず、`anki-progress-api`を通して読み書きする
- 利用者が登録する評価音はMP3・WAV・M4Aの5秒以内・2MB以下に限定し、`anki-world-history`内の`rating-sounds`へ4段階別に保存する
- 評価音の登録・取得・削除は`anki-progress-api`と一人用アクセスキーを必須とし、R2の公開URLから直接読み書きしない
- 評価音を差し替えた時はD1の割り当てを新しい保存先へ更新してから旧音声を削除し、D1の更新失敗時は新しい音声を削除して元の割り当てを維持する
- 保存窓口は一人用アクセスキーで保護し、キーはGitや公開ファイルへ書かない
- CORSは本番Webアプリ`https://anki-ume.vercel.app`だけを許可する
- 端末内にはアクセスキーと、Cloudflareから取得した音声設定・評価音の一時的な写しだけを置き、学習記録と共通設定の正本はCloudflareとする
- 一手戻しと記録初期化もCloudflare上の記録へ反映する
- 進行中の一周は選択したDeckの組合せごとに一つ保存し、暗記・聞き流しで出題順、現在位置、未出題問題、再出題待ちを共有する。端末内の一時保存を正本にしない
- 完了した周回は選択したDeckの組合せと一周ごとの識別情報をD1へ保存し、暗記・聞き流しで共通の周回数として数える。`v0.160`より前の周回数は既存記録から推測しない
- 同じ一周の完了を再送しても重複登録せず、完了直後に一手戻りした場合は進行中の一周の復元と同時に該当する完了記録を削除する
- 聞き流しの最後の問題完了時は日別件数の追加と途中記録の削除を同時に確定し、完了済みの一周を「前回の続きから」に残さない
- 複数Deckをまとめて学習する場合も、問題ごとの評価と復習予定は問題が所属するDeckの学習履歴版へ保存する
- 日別件数と学習時間は問題が所属するDeck名で保存し、組合せ用の途中記録とは保存先を分ける
- 「はじめから」は暗記・聞き流しで共有する途中記録を置き換え、問題ごとの評価と復習予定は削除しない。新しい一周には未回答問題と現在復習時刻を迎えた問題だけを含め、未来に復習予定がある回答済み問題は含めない
- 暗記モードの評価確定と、聞き流しの回答完了または任意評価の確定を1問として、科目、Deck、学習方法を含む日別学習記録をD1へ保存する。聞き流しで評価した場合も1件だけ保存する
- 4段階評価を選んだ回答は、不正解・難しい・正解・簡単の種類と、その時点の大分類・小分類・カテゴリ・問題形式を回答ごとにD1へ保存し、科目別の苦手分析に使用する
- 更新前を含む問題別記録は、D1の総回答回数と不正解以外の回数から正確な不正解回数を求め、R2上の現在の問題分類へ照合して全期間の不正解率分析に使用する
- 更新前の難しい・正解・簡単は問題別の最終状態から推測せず、不正解以外としてまとめる。現在のR2問題集へ照合できない古い問題番号も分類を推測せず対象外件数として表示する
- 毎日の学習メニュー中の回答は、問題別記録または聞き流しの日別記録と同じ通信で進み方と項目ごとの学習時間も保存する。不正解は達成数へ加算せず、難しい・正解・簡単と評価なしの聞き流し完了は同じ問題の再回答でも1問として加算する
- 意図した再回答は回答ごとに異なる識別情報で保存し、同じ回答の通信再送は同じ識別情報のまま処理して達成数と日別件数の二重計上を防ぐ
- 日別学習記録の学習日はCloudflareでの保存時刻から日本時間の午前4時区切りで決め、端末が送る日時には依存しない
- 学習時間も科目、Deck、学習方法、問題を含む独立した識別情報でD1へ保存し、日本時間の午前4時区切りで集計する
- 同じ問題画面の時間はCloudflareに保存した1秒から3600秒の共通上限までとし、同じ識別情報の再送時は最大秒数だけを保存して二重計上を防ぐ
- 一手戻りで問題完了の日別記録を取り消しても、実際に経過した学習時間は削除しない
- 暗記モードの評価確定を戻した時と、聞き流しで次の問題から前の問題へ戻った時は、対応する日別学習記録、進行中の一巡、毎日の学習メニューの件数をCloudflare上で同時に戻す。聞き流しで任意評価を確定していた場合は問題別記録も同時に評価前へ戻す
- 問題別記録の初期化では日別学習記録を削除しない
- 問題集を更新するときは、新しい画像・分割データを登録・照合し、Deck索引、画像一覧、全体索引の順に各段階を登録・照合した後だけ、旧問題集にしかない索引・分割データ・関連画像を削除する
- 画像一覧に同じ内容識別名がある登録済み画像は再送せず、新規画像と問題集データだけを更新する
- 公開URLからの照合は取得間隔を空けて回数制限時に再試行し、画像・分割データの登録後に照合だけが中断した場合は`--resume-after-asset-upload`で照合段階から再開する
- 同じバケツの`speech-cache`、`rating-sounds`とD1の学習履歴は削除対象に含めない
- 世界史・日本史語呂を許可済み3サイトと照合するときは、`npm run sync:mnemonics:approved-sites`でCloudflare上の現行デッキを読み、同じ年・同じ出来事の掲載候補だけを確認する
- 同一年の複数候補は自然さ、覚えやすさ、出来事との結び付き、短さで1件に絞り、サイトにない語呂を削除する反映は`npm run sync:mnemonics:approved-sites:apply`で行う。その後に通常の生成・検査・Cloudflare置換を行う
- `npm run preview:data:cloudflare`で件数を確認してから、`npm run replace:data:cloudflare`で置換する

## 音声読み上げ

- 自然さを優先する音声は`anki-progress-api`からAzure AI Speechを呼び出して生成する
- Azureの接続キーはCloudflare Workerの秘密情報`AZURE_SPEECH_KEY`としてだけ保存し、ブラウザーやGitへ含めない
- Azureのリージョンは`japaneast`とし、許可した日本語音声7種類と英語音声4種類だけを使用する
- 生成済み音声は文章とAzure音声の組み合わせごとに分けて保存する
- 音声生成も一人用アクセスキーで保護し、本番Webアプリ以外からの通信を許可しない
- 生成済み音声はR2の`anki-world-history`内の`speech-cache`へ保存し、同じ文章では再生成しない
- 無料枠超過、通信失敗、生成失敗時は、利用者が設定した端末音声へ切り替える
- 優先音声、Azure音声、端末音声、速度はD1へ保存し、同じアクセスキーを登録した端末間で共有する
- 世界史の問題・回答・語呂合わせ・解説と、英単語の英語・日本語・例文英語・例文日本語のオン・オフは科目別にD1へ保存し、次回の学習と別端末へ共有する
- 日本語音声と英語音声を別々に保存し、文章の言語に応じて自動的に読み分ける
- 共有された端末音声が現在の端末に存在しない場合は、言語ごとに端末の推奨音声へ切り替える
- 世界史・日本史の読み上げを全件確認するときは、`npm run audit:speech:cloudflare`でCloudflare上の現行デッキを読み、問題・回答・語呂合わせを検査する。回答横の表示専用補足は音声検査へ含めない
- 全科目の回答補足を確認するときは、`npm run audit:answer-notes:cloudflare`でCloudflare上の現行デッキを読み、科目別の問題数と補足文数を検査する。命令の末尾へ文を加えた場合は、その文を含む問題も特定する
