# Anki

最初に科目を選び、世界史と英単語を段階的に学ぶWebアプリです。

現在のバージョンは`v0.052`です。Web上の変更履歴は`public/changelog.html`で公開します。

## 現在の内容

最初に世界史または英単語を選び、その後の開始画面で学習するデッキを1冊選びます。

### 世界史

- Deck 1：400語・2,782問（基礎1,200、逆一問一答1,182、統合説明400）
- Deck 2：400語・2,400問（基礎1,200、逆一問一答800、統合説明400）
- 合計：800語・5,182問
- 数字を含む時期問題1,561問（789用語）と、別形式で単一年・年月・年月日だけを答える問題には、回答後に必ず年号の語呂合わせを表示
- 期間は開始点と終了点、複数年は各年を結び付け、世界史全体で2,360問・798種類の語呂合わせを収録
- 語呂合わせは回答の直後、解説の前に独立して読み上げ、解説を読まない「聞き流し」でも読み上げる

### 英単語

- Deck 1「基礎確認500語」：500語・1,500問
- 1語ごとに「英語から意味」「意味から英語」「例文から和訳」の3問を自動生成
- 回答後に品詞、別解、例文、例文和訳を表示

Deck 1とDeck 2は別の版として扱うため、Deck 1の既存学習履歴を維持したままDeck 2を追加できます。評価、復習予定、記録の初期化も選択中のデッキだけを対象にします。

最初は短い答えの一問一答だけを出題します。この段階では問題文とは別の用語欄と読みを回答前に表示しません。用語名そのものを答える問題以外は、前後の問題を見なくても一文だけで対象が分かるよう、問題文内に必ず用語名を含めます。

世界史ではデッキ、地域、カテゴリ、問題スタイルを選べます。英単語ではデッキ、品詞、英語から意味・意味から英語・例文から和訳の出題方向を選べます。どちらもシャッフルと自動読み上げを開始前に設定できます。

開始画面では、4段階で自己評価する「暗記モード」と、音声を繰り返す「聞き流し」の2種類を選べます。学習中の自動音声欄では、世界史は問題・回答・語呂合わせ・解説、英単語は英語・日本語・例文英語・例文日本語を個別にオン・オフできます。初期状態では世界史の解説と英単語の例文を読みません。切替はその場で以降の問題へ反映し、Cloudflareへ保存して次回の学習や同じアクセスキーを使う別端末にも引き継ぎます。問題自体が例文の場合は同じ文章を重複して読みません。聞き流しでは現在の解放状況と復習予定を暗記モードと同じように判定し、復習時刻を迎えた問題だけを繰り返します。聞くだけでは評価や復習予定を変更しません。問題を読み終えてから回答を読み始めるまでの時間は設定ページで0秒から60秒まで設定でき、Cloudflareへ保存して端末間で共有します。

音声は、日本語と英語のAzure音声または端末音声をそれぞれ選べます。英単語では英語・日本語・例文英語・例文日本語を4種類の独立した読み上げ対象として扱い、回答後はそれぞれ個別に再生できます。英単語と英語例文はJenny・Guy・Sonia・Ryanなどの英語音声、日本語訳と世界史はNanami・Aoi・Keitaなどの日本語音声で自動的に読み分けます。0.70倍から3.00倍までの速度を設定でき、音声設定はCloudflareへ保存して端末間で共有します。

Azure AI Speechの無料枠で文章から動的に生成します。Azureの接続キーはCloudflare Workerの秘密情報としてだけ保存し、ブラウザーやGitへ配りません。同じ文章の生成済み音声は声ごとにR2へ保存して再利用するため、単語ごとの固定MP3は不要です。無料枠超過、通信失敗、生成失敗時には同じ言語の端末音声へ切り替えます。

Anki、更新情報、版番号を含むヘッダーは開始前だけに表示し、学習開始後は問題表示の縦幅を確保するため非表示にします。

スマートフォン横向きでは、Safariによる段落ごとの自動文字拡大を抑えたうえで、世界史の回答と統合説明を同じ大きめの文字サイズで表示します。英単語では問題と回答をさらに約1.5倍へ拡大し、別解・品詞・英語例文・日本語訳も従来の問題・回答と同程度の大きさで表示します。

回答後は、パソコン・スマートフォン縦向き・横向きのすべてで「× 不正解・△ 難しい・○ 正解・◎ 簡単」の4ボタンを横一列に表示します。スマートフォン横向きでは操作用の戻るボタンを表示せず、左半分のタップで一手戻り、右半分のタップで回答表示または「× 不正解」を選びます。

「戻る」は、同じ問題の回答を隠す操作と、前の問題へ戻る操作を一手ずつ行います。4段階評価を越えて戻ると、その評価による習得記録と出題順もCloudflare上を含めて評価前へ戻します。

選択した学習範囲、問題スタイル、シャッフル設定は、学習を開始したあとは変更できません。別の条件で始める場合は、最初の画面を開き直して選択します。

答えを確認したあとに4段階で自己評価します。初期の復習間隔は、不正解1分後、難しい4時間後、正解12時間後、簡単6日後です。難しいまたは正解を2回積み重ねるか、簡単を1回選ぶと、その問題を習得した扱いにします。習得後も問題は消えず、設定した復習時刻に再び出題されます。

同じ用語に属する基礎問題をすべて習得すると逆一問一答をデッキへ追加し、逆一問一答もすべて習得すると統合説明を追加します。後段階の追加後も、基礎を含む解放済みの問題は復習予定に従って出題されます。

学習記録、復習間隔、音声設定、開始前のシャッフルと自動読み上げ、科目別の自動音声対象はCloudflare D1へ保存され、端末をまたいで引き継がれます。利用者登録は行わず、一人用アクセスキーを設定ページで端末に保存します。アクセスキー自体はGitへ記録しません。基礎 一問一答と逆一問一答では、回答に続いてその用語の統合説明を表示します。解説枠の最下部には、年代・大分類・小分類・時代・カテゴリ・学習段階・知識点を小さなハッシュタグ形式で表示し、年代を先頭に置き、音声では読み上げません。回答本文は文字サイズを変えずに太字で表示し、解説中の重要語と見分けやすい色分けも維持します。回答と統合説明では、冒頓単于(ぼくとつぜんう)や鄭氏台湾(ていしたいわん)のような難読語に読み仮名を付けます。複合した固有名詞も一まとまりで全件検査します。問題文に難読語がある場合は回答前には読みを隠し、回答を表示した時点で問題文にも読みを表示します。縦幅を節約するため、回答と統合説明に独立した見出しは付けません。統合説明を読んだだけでは習得には数えません。問題ごとの三段階の習得数欄は表示しません。

関連画像は問題集と分離した任意データとして扱います。Deck 1・Deck 2の800語すべてに標準画像を割り当て、人物・場所・作品などを問う問題では問題内容に応じた画像へ切り替えます。追加時には標準画像と問題別画像を全件見直し、同音異義語や別人物などの明確な取り違えを除外します。画像は暗記モードと聞き流しで回答後の解説欄内へ表示し、音声では読み上げません。画像がない場合や取得に失敗した場合も、問題・回答・解説・年号の語呂合わせだけで学習を続けます。

## フォルダー構成

- `public`：Web上で公開する学習画面と更新情報ページ
- `public/data`：手元確認とCloudflare登録のためにCSVから生成する分割データ
- `data/source`：科目ごとの元CSVと関連画像の正本
- `scripts`：元CSVの変換処理と検証処理
- `worker`：Cloudflare D1への学習記録保存と、Azure AI Speechへの安全な接続を行う処理
- `docs`：仕様書、更新情報、問題集生成用プロンプト
- `vercel.json`：Vercelの公開設定

## 学習データを更新する方法

`data/source/world-history`にはDeckごとの世界史CSV、`data/source/english-vocabulary`にはDeckごとの英単語CSVを配置します。英単語CSVは1語1行の10列形式を使用します。そのあと、次の命令でWeb表示用データを作り直して検査します。

ChatGPTで新しい問題集CSVを作る場合は、世界史では`docs/prompts/world-history-csv-generation.md`、英単語では`docs/prompts/english-vocabulary-csv-generation.md`を依頼文と一緒に渡します。英単語のDeck 2以降を作る場合は、重複確認のために作成済みの全DeckのCSVも添付します。

```powershell
npm run build:data
npm run check
```

生成後は`npm run preview:data:cloudflare`で置換対象を確認し、`npm run replace:data:cloudflare`で全デッキをCloudflare R2の`anki-world-history`へ登録します。この処理は登録済みの同一画像を再送せず、新しい画像・分割データ・索引を登録して内容を照合した後だけ、旧問題集にしかないデータを削除します。`speech-cache`の音声とD1の学習履歴には触れません。本番アプリは次のCloudflare公開URLから学習データを読み込みます。

```text
https://pub-76ffbe2829114a5cbaa433db45872267.r2.dev
```

本番で`public/data`へ暗黙に切り替わる処理はありません。`localhost`または`127.0.0.1`で手元確認するときだけ、`public/data`を`/data`として読み込みます。

## 学習記録のCloudflare保存

学習記録、復習間隔、音声設定、シャッフル、自動読み上げ、科目別の自動音声対象は、Cloudflare D1の`anki-progress`へ、Workerの`anki-progress-api`を通して保存します。同じWorkerがAzure AI Speechへ安全に接続し、生成済み音声をR2の`anki-world-history`内の`/speech-cache`へ保存します。Azureの接続キーはWorkerの秘密情報`AZURE_SPEECH_KEY`、リージョンは`japaneast`として管理します。

```text
https://anki-progress-api.umedademu.workers.dev
```

書き込みにはCloudflare側だけに登録した一人用アクセスキーが必要です。Webアプリでは`/settings.html`を開き、アクセスキーを一度入力して接続します。本番からの通信だけを許可し、アクセスキーはリポジトリや公開用ファイルへ含めません。

## 手元で表示する方法

プロジェクトのフォルダーで次の命令を実行し、ブラウザーで`http://localhost:3000`を開きます。

```powershell
python -m http.server 3000 --directory public
```

## Vercelで公開する方法

Vercelでこの保管場所を取り込み、次の設定を使用します。

- 使用する仕組み：`Other`
- 組み立て命令：空欄
- 公開フォルダー：`public`

公開フォルダーは`vercel.json`にも設定済みです。
