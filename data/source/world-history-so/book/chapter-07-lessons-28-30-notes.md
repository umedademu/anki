## CSV形式

前回の第22〜24回・第25〜27回と同じ10列・同じ列順です。UTF-8（BOM付き）、カンマ区切り、CRLF改行、全フィールドを二重引用符で囲む形式です。1行目がヘッダーで、1問は1行、セル内改行はありません。

| 列名 | 内容 |
|---|---|
| `question_id` | `WH-回-小見出し-連番`。原文順の一意のID。 |
| `question` | 単独でも対象・条件が分かる問題文。 |
| `answer` | 用語、または説明問題の解答に必要な要点。 |
| `explanation` | 添付資料に基づく補足や、区別するポイント。 |
| `type` | 添付分類表に沿った11種類のうち一つ。 |
| `style` | 全問 `一問一答`。 |
| `source_url` | 全問空欄。 |
| `source_file` | 主な根拠となる元のMDファイル名。 |
| `source_page` | 主な根拠が記載されている印刷ページ。 |
| `source_line` | 主な根拠の位置に当たる、元のMD内の1始まりの行番号。 |

前回CSVとの列名・列順の一致を確認しました。特定の学習アプリへの実際のインポート動作は検証していません。添付の問題種類ガイド自体は、アプリのCSVインポート仕様書ではありません。

## 原文順と小見出しの区切り

各デッキ内では、主な根拠となる本文・年表・表の出典行番号順に並べています。年代順・種類順への並べ替えはしていません。同じ行から複数問を作る場合は、基本事項と関連する説明・比較をまとめています。

冒頭の「クローズアップ」が後の小見出しの内容も先取りしている場合は、問う内容に合うデッキへ配属しました。そのため、第28回の第2節には446ページの年表、第4節には452ページの年表、第29回の第3節には465ページの年表を主な出典とする問題が先頭にあります。年表の後に、それぞれの本文の問題が続きます。

ページの柱や繰り返し見出しを、新しい本文の始まりとはみなしていません。例えば、第30回475ページ冒頭のシノワズリは「文学・芸術」に、477ページのルソーの続きと『百科全書』は「政治思想」に収録しました。478ページの科学者一覧表は「自然科学・科学技術」に含め、その後から「哲学」としています。

`source_line` は主な出典の代表位置です。問題文の条件・解説・比較・統合説明には、同じ回の別の段落や年表・一覧表の記述も用いる場合があります。表示した1行だけに、解答・解説の根拠がすべて収まっているという意味ではありません。

## 出題方針

第28回は、旧体制の身分構造、全国三部会から各議会への移行、党派・支持層・選挙制度の違い、民衆運動、封建的特権廃止の段階、恐怖政治の機関と終結を重点化しています。

第29回は、総裁政府・統領政府・第一帝政の違い、国内改革、遠征と条約、大陸封鎖令、自由主義・国民主義、プロイセン改革、ロシア遠征から二度の失脚までの流れを扱っています。

第30回は、人物と著作・作品・業績の対応、政治や社会と文化の関係、バロックとロココ、王権神授説・社会契約説・啓蒙思想、経験論・合理論・ドイツ観念論の区別を扱っています。本文だけでなく、人物一覧表・哲学一覧表にだけ載っている情報も収録しました。

## 資料の扱いと出題上の留保

根拠は今回の添付MDと、前から添付されている分類表・目次です。外部サイト・教科書による史実の校訂、添付範囲にない人物・作品・学説の追加は行っていません。用語・別名は資料の表記に沿っていますが、書名の括弧などの表記はCSV内で整理しています。

語呂合わせ、学習上の優先度の低い逸話、人物への評価、想像上の発言や比喩は、原則として史実の断定問題にはしていません。資料の解釈を直接問う場合には「資料では」などと明示しています。画像がない地図・絵画について、文字起こしだけから位置や画面の詳細を推測する問題は設けていません。

特に、次の点では出題する要素を限定しています。

- 第28回の対オーストリア宣戦と国際戦争の拡大は、年表にある1792年の宣戦と1793年の第1回対仏大同盟を区別しました。各国が同時に参戦したと断定する問題や、同盟参加国の完全な列挙問題は設けていません。教会財産国有化についても、正確な実施年ではなく目的・アッシニア紙幣・聖職者の扱いを中心に問います。
- 第29回461ページのダヴィドの作品は、作品名と作者の対応を出題しました。同じ段落の第1次イタリア遠征と作品の場面・年を結びつける問題は設けていません。469ページの「イタリア人の祖国ドイツ」という記載も、そのまま暗記させたり、別の文に黙って置換したりせず、国名の組合せを問う対象から外しました。
- 第30回のエスコリアル宮殿は、資料の建設者・所在地との対応を問いますが、様式分類そのものは出題していません。シェーンブルン宮殿は、本文が区別している外観と内装の様式をそのまま分けて扱います。
- 帰納法・演繹法は、比喩だけでなく末尾の比較表の定義を用いています。『実践理性批判』など、本文に詳細な学説の説明がないものは、資料にある著作名や位置づけにとどめ、内容を外部知識で補っていません。

共通テストの高得点を目指すための知識・理解の確認用です。この3回分で世界史全範囲を網羅するものではなく、得点を保証するものでもありません。資料読解や選択肢判定は、実際の問題演習で別に確認してください。
