# 学習データのCloudflare運用方針

## 結論

本番のWebアプリは、学習データをCloudflareから読み込みます。

リポジトリ内の`public/data`や、Webアプリと同じ場所にある`/data`を本番の正式な読込先にはしません。

## データ更新の完了条件

問題集の更新は、次のすべてが終わった時点で完了とします。

1. 新しい元CSVを`data/source`内の適切な場所へ保存する
2. 新しいCSVからWeb表示用データを生成し、件数と内容を検査する
3. Cloudflare上の旧問題集を撤廃する
4. Cloudflareへ新しいWeb表示用データを登録する
5. Webアプリの読込先がCloudflareの公開先になっていることを確認する
6. 実際のWebアプリからCloudflare上の新しい問題集を取得し、用語数・問題数・出題内容を確認する

リポジトリ内のデータだけを置き換えた状態や、手元の`/data`から表示できただけの状態は、完了ではありません。

## 手元のデータの位置づけ

`public/data`は、次の目的に限って使用します。

- 生成されたデータの内容確認
- 自動検査
- Cloudflareへ登録するデータの準備
- 手元での一時的な動作確認

手元での確認時に`/data`を使用しても、本番用の設定を`/data`へ変更したままにしないでください。

## 接続情報が不明な場合

Cloudflareの公開URL、バケット名、登録方法、認証方法などが分からない場合は、推測で別の読込方法へ変更しません。

必要な情報を利用者へ確認し、Cloudflare上の正確な対象を特定してから更新します。

## 変更時の確認事項

- 旧問題集のファイルがCloudflare上に残っていないか
- 科目一覧が新しい問題集だけを参照しているか
- 用語数と問題数が元CSVと一致しているか
- Webアプリの通信先がCloudflareになっているか
- Webアプリが手元の`/data`へ意図せず切り替わっていないか
- Cloudflareから取得できない場合に、古い問題集を黙って表示していないか
