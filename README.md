# Anki

最初に科目を選び、世界史・日本史・英単語を段階的に学ぶWebアプリです。

現在のバージョンは`v0.075`です。Web上の変更履歴は`public/changelog.html`で公開します。

最後に選んだ科目、科目ごとのDeckと学習方法、Deckごとの地域・カテゴリ・問題スタイル・出題量、シャッフル、自動読み上げはCloudflare D1へ保存します。次回は最後に使った開始画面を同じ条件で復元し、同じアクセスキーを使う別端末にも引き継ぎます。

## 現在の内容

最初に世界史・日本史・英単語から科目を選び、その後の開始画面で学習するデッキを1冊選びます。

### 世界史

- Deck 1：400語・2,782問（基礎1,200、逆一問一答1,182、統合説明400）
- Deck 2：400語・2,400問（基礎1,200、逆一問一答800、統合説明400）
- Deck 3：400語・2,400問（基礎1,200、逆一問一答800、統合説明400）
- 合計：1,200語・7,582問
- 数字を含む時期問題2,341問（1,179用語）と、別形式で単一年・年月・年月日だけを答える問題に年号の語呂合わせを収録。同じ用語の年号以外を答える問題でも、統合説明に収録済みの語呂を回答後に表示
- 期間は開始点と終了点、複数年は各年を結び付け、世界史全体で3,530問・1,188種類の語呂合わせを収録
- 「語呂合わせマスター」と年号・出来事が一致する世界史38語では、同サイトの分かりやすい語呂を優先
- 語呂合わせは回答の直後、解説の前に独立して読み上げ、見出し・対象年・数字対応の注記を除いた語呂本文と出来事名だけを読む

### 日本史

- Deck 1「日本史の最重要骨格400語」：400語・2,800問（短答1,200、逆一問一答1,200、統合説明400）
- 年号語呂合わせを604問に収録し、同じ用語の年号以外を答える問題を含む回答後の表示と読み上げに対応
- 「語呂合わせマスター」と年号・出来事が一致する日本史8語では、同サイトの分かりやすい語呂を優先
- 431点の関連画像を全400語・2,800問へ固定し、人物・場所・文書などでは問題内容に応じた画像へ切り替え
- 世界史とは別の版番号と学習履歴として保存

### 英単語

- Deck 1「基礎確認500語」：500語・1,500問
- Deck 2「受験基礎500語」：500語・1,500問
- Deck 3「共通テスト基礎500語」：500語・1,500問
- 合計：1,500語・4,500問
- 1語ごとに「英語から意味」「意味から英語」「例文から和訳」の3問を自動生成
- 回答後に品詞、別解、例文、例文和訳を表示

各Deckは別の版として扱うため、既存の学習履歴を維持したまま新しいDeckを追加できます。評価、復習予定、記録の初期化も選択中のデッキだけを対象にします。

最初は短い答えの一問一答だけを出題します。この段階では問題文とは別の用語欄と読みを回答前に表示しません。用語名そのものを答える問題以外は、前後の問題を見なくても一文だけで対象が分かるよう、問題文内に必ず用語名を含めます。

世界史と日本史ではデッキ、地域、カテゴリ、問題スタイルに加え、対象の全問題を出すか、1項目につき復習対象から1問だけを出すかを選べます。1項目1問では、苦手な問題、回答回数の少ない問題、長く出ていない問題を順に優先し、条件が同じ場合だけ無作為に選びます。英単語ではこの出題量選択を表示せず、デッキ、品詞、英語から意味・意味から英語・例文から和訳の出題方向を選べます。いずれもシャッフルと自動読み上げを開始前に設定できます。

開始画面では、4段階で自己評価する「暗記モード」と、音声を繰り返す「聞き流し」の2種類を選べます。学習中は、問題や回答の横にある既存のスピーカーボタン自体で読み上げ対象をオン・オフします。世界史・日本史は問題・回答・語呂合わせ・解説、英単語は英語・日本語・例文英語・例文日本語を個別に切り替えられます。初期状態では世界史・日本史の解説と英単語の例文を読みません。オンは「🔊」、オフは「🔇」で表示し、オフにした項目はその場で停止して次の問題以降も読みません。切替状態はCloudflareへ保存し、次回の学習や同じアクセスキーを使う別端末にも引き継ぎます。問題自体が例文の場合は同じ文章を重複して読みません。聞き流しでは現在の解放状況と復習予定を暗記モードと同じように判定し、復習時刻を迎えた問題だけを繰り返します。聞くだけでは評価や復習予定を変更しません。問題を読み終えてから回答を読み始めるまでの時間は設定ページで0秒から60秒まで設定でき、Cloudflareへ保存して端末間で共有します。0秒では待機用の処理を挟まず、自然音声は現在のパーツを再生している間に回答側と次の問題を先読みします。問題・回答・語呂合わせ・解説などの音声パーツは結合せず、従来どおり独立したまま順番に再生します。

暗記モードと聞き流しの途中位置・出題順は別々にCloudflareへ保存します。「前回の続きから」は開始画面で選んでいるモードの続きだけを再開し、「はじめから」も選択中のモードだけを先頭へ戻します。もう一方のモードの続きは維持します。問題ごとの評価・習得状態・復習予定は共通で、聞き流しでは変更しません。

聞き流しにも「戻る」を表示し、1問ではなく1手ずつ戻ります。回答を表示している時は同じ問題の回答非表示へ戻り、次の問題へ進んだ後は前の問題の回答表示へ戻ります。その問題の一巡件数と日別学習記録も同時に取り消します。スマートフォン横向きでは画面左半分の操作で同じように戻ります。

ヘッダーの「学習記録」では、解いた問題数を日ごとに、科目・デッキ・暗記モード・聞き流し別で確認できます。日本時間の午前4時を日付の切り替わりとし、午前3時59分までは前日の学習としてCloudflareへ保存します。暗記モードは4段階評価を選んだ時、聞き流しは回答まで読み終えた時を1問とし、一手戻りで問題の完了を取り消した場合は、どちらのモードでも日別件数から取り消します。この記録は`v0.071`公開後の学習から蓄積します。

一周の問題数が多い場合も、現在位置と日別件数は通常のCloudflare通信で保存します。通信に失敗した聞き流しはその場で停止し、「再開」を押すと同じ問題の保存からやり直すため、次の問題へ未保存のまま進みません。

音声は、日本語と英語のAzure音声または端末音声をそれぞれ選べます。英単語では英語・日本語・例文英語・例文日本語を4種類の独立した読み上げ対象として扱い、回答後の既存スピーカーボタンで各項目の継続的なオン・オフを切り替えます。英単語と英語例文はJenny・Guy・Sonia・Ryanなどの英語音声、日本語訳と世界史・日本史はNanami・Aoi・Keitaなどの日本語音声で自動的に読み分けます。世界史・日本史では選択中のデッキにある用語名と読みを一まとまりで置き換えるため、「アフリカの年(あふりかのとし)」や「承久の乱(じょうきゅうのらん)」のように用語内へ助詞があっても一部を二重に読みません。日本語訳中の「～」と「〜」は単語の代入位置を表す省略記号として音声から除き、「～まで」は「まで」、「～から」は「から」と読みます。0.70倍から3.00倍までの速度を設定でき、音声設定はCloudflareへ保存して端末間で共有します。

Azure AI Speechの無料枠で文章から動的に生成します。Azureの接続キーはCloudflare Workerの秘密情報としてだけ保存し、ブラウザーやGitへ配りません。同じ文章の生成済み音声は声ごとにR2へ保存して再利用するため、単語ごとの固定MP3は不要です。無料枠超過、通信失敗、生成失敗時には同じ言語の端末音声へ切り替えます。

Anki、更新情報、版番号を含むヘッダーは開始前だけに表示し、学習開始後は問題表示の縦幅を確保するため非表示にします。

学習中のデッキ名は、問題上部の習得数・完全習得数・残り問題数と同じ行・同じ文字サイズで表示します。長いデッキ名はその行の中で省略し、専用の行を増やしません。

スマートフォン横向きでは、Safariによる段落ごとの自動文字拡大を抑えたうえで、世界史・日本史の回答と統合説明を同じ大きめの文字サイズで表示します。英単語では問題と回答をさらに約1.5倍へ拡大し、別解・品詞・英語例文・日本語訳も従来の問題・回答と同程度の大きさで表示します。

回答後は、パソコン・スマートフォン縦向き・横向きのすべてで「× 不正解・△ 難しい・○ 正解・◎ 簡単」の4ボタンを横一列に表示します。スマートフォン横向きでは操作用の戻るボタンを表示せず、左半分のタップで一手戻り、右半分のタップで回答表示または「× 不正解」を選びます。

「戻る」は、同じ問題の回答を隠す操作と、前の問題へ戻る操作を一手ずつ行います。4段階評価を越えて戻ると、その評価による習得記録と出題順もCloudflare上を含めて評価前へ戻します。

選択した学習範囲、問題スタイル、出題量、シャッフル設定は、学習を開始したあとは変更できません。別の条件で始める場合は、最初の画面を開き直して選択します。

答えを確認したあとに4段階で自己評価します。初期の復習間隔は、不正解1分後、難しい4時間後、正解12時間後、簡単6日後です。難しいまたは正解を2回積み重ねるか、簡単を1回選ぶと、その問題を習得した扱いにします。習得後も問題は消えず、設定した復習時刻に再び出題されます。

同じ用語に属する基礎問題をすべて習得すると逆一問一答をデッキへ追加し、逆一問一答もすべて習得すると統合説明を追加します。後段階の追加後も、基礎を含む解放済みの問題は復習予定に従って出題されます。

学習記録、復習間隔、音声設定、開始前のシャッフルと自動読み上げ、科目別の自動音声対象はCloudflare D1へ保存され、端末をまたいで引き継がれます。利用者登録は行わず、一人用アクセスキーを設定ページで端末に保存します。アクセスキー自体はGitへ記録しません。基礎 一問一答と逆一問一答では、回答に続いてその用語の統合説明を表示します。解説枠の最下部には、年代・大分類・小分類・時代・カテゴリ・学習段階・知識点を小さなハッシュタグ形式で表示し、年代を先頭に置き、音声では読み上げません。回答本文は文字サイズを変えずに太字で表示し、解説中の重要語と見分けやすい色分けも維持します。回答と統合説明では、冒頓単于(ぼくとつぜんう)や鄭氏台湾(ていしたいわん)のような難読語に読み仮名を付けます。複合した固有名詞も一まとまりで全件検査します。問題文に難読語がある場合は回答前には読みを隠し、回答を表示した時点で問題文にも読みを表示します。縦幅を節約するため、回答と統合説明に独立した見出しは付けません。統合説明を読んだだけでは習得には数えません。問題ごとの三段階の習得数欄は表示しません。

関連画像は問題集と分離した任意データとして扱います。世界史Deck 1〜3の1,200語と日本史Deck 1の400語すべてに標準画像を割り当て、人物・場所・作品などを問う問題では問題内容に応じた画像へ切り替えます。追加時には標準画像と問題別画像を全件見直し、同音異義語や別人物などの明確な取り違えを除外します。画像は暗記モードと聞き流しで回答後の解説欄内へ表示し、押しても外部サイトへ移動しません。画像は音声で読み上げません。画像がない場合や取得に失敗した場合も、問題・回答・解説・年号の語呂合わせだけで学習を続けます。

## フォルダー構成

- `public`：Web上で公開する学習画面と更新情報ページ
- `public/data`：手元確認とCloudflare登録のためにCSVから生成する分割データ
- `data/source`：科目ごとの元CSVと関連画像の正本
- `scripts`：元CSVの変換処理と検証処理
- `worker`：Cloudflare D1への学習記録保存と、Azure AI Speechへの安全な接続を行う処理
- `docs`：仕様書、更新情報、問題集生成用プロンプト
- `vercel.json`：Vercelの公開設定

## 学習データを更新する方法

`data/source/world-history`にはDeckごとの世界史CSV、`data/source/japanese-history`にはDeckごとの日本史CSV、`data/source/english-vocabulary`にはDeckごとの英単語CSVを配置します。英単語CSVは1語1行の10列形式を使用します。そのあと、次の命令でWeb表示用データを作り直して検査します。

ChatGPTで新しい問題集CSVを作る場合は、世界史では`docs/prompts/world-history-csv-generation.md`、日本史では`docs/prompts/japanese-history-csv-generation.md`、英単語では`docs/prompts/english-vocabulary-csv-generation.md`を依頼文と一緒に渡します。段階表と今回作成する語数は依頼文へ直接記載し、Deck 2以降を作る場合は重複確認のために作成済みの全DeckのCSVも添付します。世界史と日本史は同じ25列の三段階形式で変換し、英単語は10列形式から三方向の問題を生成します。

今後追加する科目には、科目ごとの暗記に適した列構成を使う次の生成用プロンプトを準備しています。

- 生物基礎：`docs/prompts/biology-basics-csv-generation.md`
- 地学基礎：`docs/prompts/earth-science-basics-csv-generation.md`
- 地理：`docs/prompts/geography-csv-generation.md`
- 政治・経済：`docs/prompts/politics-economics-csv-generation.md`
- 古文：`docs/prompts/classical-japanese-csv-generation.md`
- 漢文：`docs/prompts/classical-chinese-csv-generation.md`

この6科目では、勉強全体をアプリ内で再現せず、暗記によって対応できる用語、意味、働き、位置、順序、句法、識別点などだけを短いカードにします。実験考察、初見資料の分析、政策論述、長文読解などは生成対象に含めません。Deck数、各Deckの新規項目数、累計順位、位置づけ、具体的な収録単元・分野・地域・配分はプロンプトへ固定せず、作成時に一緒に送る段階表と追加依頼から読み取ります。追加の範囲指定がなければ、ChatGPTが大学受験での重要度から収録内容を判断します。現時点ではプロンプトだけを準備しており、Webアプリの科目選択、変換処理、学習データはまだ追加していません。

世界史・日本史の既存語呂を「語呂合わせマスター」と照合するときは、予行表示後に反映用の命令を実行します。この処理はCloudflare上の現行デッキを読み、同じ年号・同じ出来事だけを元CSVへ反映します。

```powershell
npm run sync:mnemonics:goroawase-master
npm run sync:mnemonics:goroawase-master:apply
```

```powershell
npm run build:data
npm run check
npm run audit:speech:cloudflare
```

`audit:speech:cloudflare`は、Cloudflare上の世界史・日本史の全デッキを読み、問題・回答・解説・語呂合わせの読み上げ用文章を全件検査します。学習データへの書き込みは行いません。

生成後は`npm run preview:data:cloudflare`で置換対象を確認し、`npm run replace:data:cloudflare`で全デッキをCloudflare R2の`anki-world-history`へ登録します。この処理は登録済みの同一画像を再送せず、新しい画像・分割データ・索引を登録して内容を照合した後だけ、旧問題集にしかないデータを削除します。`speech-cache`の音声とD1の学習履歴には触れません。本番アプリは次のCloudflare公開URLから学習データを読み込みます。

```text
https://pub-76ffbe2829114a5cbaa433db45872267.r2.dev
```

本番で`public/data`へ暗黙に切り替わる処理はありません。`localhost`または`127.0.0.1`で手元確認するときだけ、`public/data`を`/data`として読み込みます。

## 学習記録のCloudflare保存

問題ごとの正誤記録、日別の学習記録、復習間隔、音声設定、シャッフル、自動読み上げ、科目別の自動音声対象は、Cloudflare D1の`anki-progress`へ、Workerの`anki-progress-api`を通して保存します。同じWorkerがAzure AI Speechへ安全に接続し、生成済み音声をR2の`anki-world-history`内の`/speech-cache`へ保存します。Azureの接続キーはWorkerの秘密情報`AZURE_SPEECH_KEY`、リージョンは`japaneast`として管理します。

```text
https://anki-progress-api.umedademu.workers.dev
```

書き込みにはCloudflare側だけに登録した一人用アクセスキーが必要です。Webアプリでは`/settings.html`を開き、アクセスキーを一度入力して接続します。本番からの通信だけを許可し、アクセスキーはリポジトリや公開用ファイルへ含めません。

## 手元で表示する方法

プロジェクトのフォルダーで次の命令を実行し、ブラウザーで`http://localhost:3000`を開きます。


## Vercelで公開する方法

Vercelでこの保管場所を取り込み、次の設定を使用します。

- 使用する仕組み：`Other`
- 組み立て命令：空欄
- 公開フォルダー：`public`

公開フォルダーは`vercel.json`にも設定済みです。
