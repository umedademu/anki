# サファヴィー朝・地図の紙芝居

追加版：v0.185（2026年9月5日）

## 目的と入口

教科書写真3枚のサファヴィー朝の本文を、地図と短い説明でたどる独立した試作ページ。
科目選択の下と、ティムールの遠征・死後の続編の小さなリンクから `/safavid-story.html` を開く。
今回は利用者の指定によりドット絵・人物画像を使用せず、SVGの地図・矢印・都市の印・色分けで表現する。
無音で、自動の場面送り、学習データの取得、学習履歴や設定の読み書きを行わない。
写真3枚目の「オスマン帝国」は次節の見出しのみのため、その節の教材は今回含めない。

## 内容上の補足

- 国教化は1501年に始まり、住民への定着は長期の過程。1510年の東方での勝利後に初めて国教にしたとは説明しない
- シャーはイランの伝統的な王の称号。宗教教団から王朝への移行と結び付けて説明
- キジルバシュをすべて廃止したとはせず、グラーム・火器部隊によって依存を減らしたと説明
- タブリーズの占領は一時的。バグダードも1624年の奪回後、1638年に再びオスマン帝国の支配下に入る
- 反撃と国内政策は同時期に進むため、10場面目で1598年ごろへ戻ることを明記
- アルメニア人の強制移住と商業保護の両面を記す。新ジュルファを拠点とした交易を説明
- 17世紀全体を戦争のない時代とはせず、後半の比較的長い安定期と区別
- 衰退を大西洋交易だけで説明せず、財政・統治・反乱などが重なったと説明
- 都市人口・順位には推計の幅があるため、「50万人超」や世界順位を確定値として載せない
- 1722年は首都陥落、1736年は王朝交代。侵入したギルザイ系勢力と1747年のドゥッラーニー朝を区別
- カージャール朝とドゥッラーニー朝の領域を現在の国境と同一視しない

## 表示と操作

基図は既存の `timur-map.svg`。海岸線は共通で、国境を表示しない。
緯度経度から同じ投影方法で都市・経路を配置し、画面の大きさに合わせて余白を確保する。
都市名同士の重なりを避け、位置をずらした地名は都市の点と引き出し線で結ぶ。
進軍は赤、相手の進軍は青灰色、移動は緑、交易は金色の点線。動く点と伸びる矢印で方向を示す。
王の広場は地図上のイスファハーンと線で結んだ配置図で、北にバザール、西に王宮、東と南にモスクを示す。
前後ボタン、左右キー、三つの章、20個の番号から場面を選択できる。
「動きをもう一度」で同じ場面を再生し、場面変更・再表示・画面サイズ変更では古い動きを停止する。
端末の動きを減らす設定では、最終状態をすぐに表示する。

## 動作確認

- `npm run check` が全項目で通過。構文、既存の音声・学習時間・予定・分析・通信・画面構成・データ整合を含む
- 幅320の画面で全20場面を確認。地名同士の重なり、地図やページからの横方向のはみ出し、座標の異常がないことを確認
- 動きを減らす設定では全20場面が最終状態で静止表示されることを確認
- 通常の画面と幅390の画面で、移動途中・到着後・動きの再表示・途中で場面を切り替える操作を確認
- チャルディラーンでは両軍の到着後にタブリーズへの矢印が伸びる順序を確認。交易が金色の点線になることも目視確認
- 王の広場の配置図、左右キー・章の選択・場面番号・最終場面から先頭への戻りを確認
- 既存のティムール死後の紙芝居との相互リンクを確認。新ページに人物画像・音声・動画の要素や、音声を起動する処理がないことを確認し、試験中は無音
- 20場面の場所・地域の参照、経路の数値、矢印の開始・終了順序を確認
