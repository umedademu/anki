# 英単語の3語表示

## 利用方法と表示

英単語の開始画面で、学習方法は「暗記モード」「聞き流し」の2つから選び、その下の「3語表示」スイッチをオン・オフにします。「暗記モード＋3語表示」「聞き流し＋3語表示」のどちらも選べます。他の科目にはこのスイッチを表示しません。

- 英語から日本語の意味を答える問題だけを対象にし、左に英単語、右に日本語訳を配置します。
- 最初は英単語だけを表示します。暗記モードでは「答えを表示」を押すと右側へ日本語訳を出し、評価できるようになります。聞き流しでは既存の回答待ち時間と読み上げの進行に合わせて訳を表示します。
- 各単語の下に「不正解・難しい・正解・簡単」の4つのボタンを置きます。訳の公開前もボタンは表示し、操作だけ無効にします。
- 暗記モードでは評価すると、聞き流しでは自動で次の問題へ進むと、新しい単語を最上段へ追加し、前の単語を下へ移動します。直近3回分を表示し、上から4番目以降の表示は画面から外します。学習記録は消しません。
- 開始直後は1行、次は2行、その後は3行と12個の評価ボタンになります。
- 例文、品詞などの補足、解説、画像は表示しません。自動音声も英単語と日本語の意味だけを対象にします。
- スマートフォン横画面を最優先にし、パソコンでも操作できます。長い単語や訳は各欄の中で上下に動かして確認できます。縦画面への個別最適化は行いません。

## 評価の訂正と再開

下に残った単語は4つのボタンで評価を訂正できます。聞き流しで評価せず進んだ単語にも、表示されている間は後から評価できます。選択中の評価には枠を付けます。訂正しても現在の問題や訳の公開状態は変えず、回答した回数と日時も増やしません。評価の内訳、習得状態、復習予定、不正解の再出題、指定問題数の達成数、毎日のメニューの達成数を合わせて修正します。同じ単語が再び上に表示された場合、その古い表示の評価は無効にして新しい学習記録の上書きを防ぎます。

「一手戻る」は答えの公開と現在の回答を一手ずつ取り消します。聞き流しでは再生・一時停止・次へも操作できます。過去行の評価を訂正した場合は、その前の一手戻りの履歴を区切り、確定した訂正を古い状態で上書きしません。

3語表示のオン・オフを学習方法と独立してCloudflareへ保存します。直近3行、公開済みの訳、評価も途中記録へ保存し、開始画面からの再開と学習画面の再読み込みで復元できます。別の学習方法へ切り替えてもスイッチの選択を保持し、既存の共通の一周と学習記録を利用します。表示行は切り替え後の学習方法で新たに積み上げ、前の方法の回答履歴を変更しません。聞き流しの過去行の評価は自動進行と順番に保存し、正常時は再生を続けます。保存に失敗した場合は表示・評価・進行・毎日のメニューを操作前へ戻し、未保存のまま進むことを防ぎます。

## 保存と確認

問題集は既存のCloudflare R2から取得し、学習記録はCloudflare D1へ保存します。学習記録上の方法は選択した暗記モードまたは聞き流しのまま、開始設定と途中記録に3語表示のオン・オフを保存します。過去行の評価訂正では同じ学習方法の既存の回答履歴を更新し、回答履歴を追加しません。単語集本体や他科目は変更しません。

- `node scripts/test-vocabulary-stream-persistence.mjs`：開始設定・3行の途中記録・不正な修正の拒否・回答履歴訂正を確認します。
- `npm run test:vocabulary-stream:browser`：学習方法の2択と独立したスイッチ、英単語限定、両方法の訳の公開順、最大3行・12ボタン、聞き流しの自動進行と再生操作、過去の評価訂正、毎日のメニュー、保存失敗、再読み込み、一手戻り、同じ単語の再出題を確認します。横画面667×375・812×375・932×430とパソコン1366×768を確認します。
- 画面試験は人工データと仮の保存先だけを使用し、開始前に自動読み上げをOFF、全読み上げ対象をOFFにします。音声の取得・再生と、本番の保存先への通信を防ぎます。

保存窓口の変更を反映する際は、画面の公開前に `worker/wrangler.jsonc` の既存保存処理を更新します。保存形式を追加する変更のため、表の追加や既存の単語集の変更は不要です。
