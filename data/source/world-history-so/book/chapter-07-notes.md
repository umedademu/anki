## CSV形式

文字コードは **UTF-8（BOM付き）**、区切りはカンマ、改行はCRLFです。全フィールドを二重引用符で囲み、1行目をヘッダー、2行目以降を問題データとしています。1問は1行で、セル内の改行はありません。

添付の `world-history-so-question-types(4).md` は問題の分類基準・既存問題一覧であり、CSVの列構成は指定されていません。そのため、今回は次の10列を使用しています。特定アプリの既存インポート仕様との互換性は検証していません。

| 列名 | 内容 |
|---|---|
| `question_id` | 一意の問題ID。`WH-回-小見出し-連番`。各ファイル内の原文順に採番。 |
| `question` | 問題文。単独で出題できるよう、対象・時代・条件を明示。 |
| `answer` | 解答。説明問題は採点に必要な要点を短く記載。 |
| `explanation` | 原資料に基づく補足、因果関係、混同を避けるポイント。 |
| `type` | 添付分類表に沿う11種類のうち1つ。 |
| `style` | 全問 `一問一答`。 |
| `source_url` | 全問空欄。 |
| `source_file` | 根拠となる添付MDファイル名。 |
| `source_page` | 主な出題箇所がある原資料の印刷ページ番号。 |
| `source_line` | 主な出題箇所の、元のMDファイル内の行番号。 |

## 問題の配列と出典

本文・表・まとめ欄など、主な根拠となる記載が原資料に登場する順で並べています。年号順や問題種類順には並べ替えていません。冒頭の「クローズアップ」などに先に登場する事項は、その記載位置を基準にしています。同じ箇所を根拠とする複数問は、基本事項から区別・理解を確認する問いへ配置しています。

各ページ上部の柱・ヘッダーを、次の小見出しの本文開始と誤認しないように分割しました。例えば第22回353ページ冒頭のラファエロと大聖堂の記述は「イタリア＝ルネサンス」、第24回385ページ冒頭の絶対王政の一般論は「イタリア戦争と主権国家の形成」に含めています。

出典ページ・MD行番号は、問題を作る主な根拠の開始位置です。比較・統合説明や解説では、同じ添付資料中の複数箇所を合わせて要点を整理している場合があり、当該1行だけで全内容を示すものではありません。出典URLはすべて空欄です。

## 出題方針

用語・人物・場所・重要年代に加え、原因・経緯・影響・比較を確認する問題を収録しました。作品と作者、航海者と航路、宗派と教義、法令と制定者、独立宣言と独立承認など、混同しやすい対応関係を重視しています。同じ事項を別の方向から問う問題や、別の回の説明で再登場する事項も含めています。

原資料の表記・説明を基礎とし、添付されていない範囲の知識や、資料にない人名・年号を追加して網羅したものではありません。外部資料による史実の校訂は行っていません。本文に説明のない図・地図について、見えていない位置関係を推測する問題は作成していません。

共通テストでの高得点を目指すための知識・理解の確認用ですが、この3回分だけで世界史全範囲をカバーするものではなく、得点を保証するものでもありません。資料読解・選択肢判定・時間配分は、別に問題演習で確認する必要があります。
